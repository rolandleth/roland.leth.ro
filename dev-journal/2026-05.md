## Learnings

- **Server components don't invoke their child components synchronously** — `<PostForm initialData={...} />` is `React.createElement(PostForm, props)`, not a render. Assert on element `props`, not `vi.fn()` mock calls. [source](dev-journal/2026-05-07.md)
- **`vi.mock` factories hoist above top-level `const`** — referencing a `vi.fn()` declared at module scope inside a factory fails with a hoisting error. Inline the mock or use `vi.hoisted`. [source](dev-journal/2026-05-07.md)
- **`vi.resetAllMocks` clears `mockReturnValue` set in `vi.mock` factories** — rebind in `beforeEach` after `resetAllMocks`. Hit twice this month (sitemap + bulk route). [source](dev-journal/2026-05-11.md), [source](dev-journal/2026-05-15.md)
- **`vi.mock` with `...actual` doesn't rewrite intra-module references** — if helper `foo` calls another export `bar` of the same module, mocking `bar` does NOT redirect `foo`'s internal call; the `...actual` exports retain lexical bindings to the real `bar`. Mitigation: design helpers to take dependencies as explicit args (this is why `isFutureDatetime(datetime, now)` has `now` required), or mock the consuming function. [source](dev-journal/2026-05-17.md)
- **`role="alert"` already implies assertive live-region** — stacking `aria-live="polite"` is contradictory. [source](dev-journal/2026-05-07.md)
- **Schema-level slug validation catches a class of failures the unique constraint can't articulate** — `min(1)` is necessary but not sufficient. Any derived-field-from-input pattern (slug from title, hash from body) should refine at the schema, not trust the derivation downstream. [source](dev-journal/2026-05-11.md)
- **For unique-constraint filters in cached fetchers**: the original "capture `now` inside the cached fn" approach (2026-05-11) was reversed on 2026-05-14 — push the time-dependent comparison *out* of the cached function and into the wrapper that reads from it; cache becomes time-independent, wrapper handles fresh `now` per request. [source](dev-journal/2026-05-14.md)
- **Don't trust a test that passes because the mock skipped a filter** — when refactoring a filter from DB-side to JS-side, audit tests that depend on the filter being a no-op. [source](dev-journal/2026-05-14.md)
- **A test you wrote can expose a real implementation gap** — the unmount-after-resolve test in 2026-05-13 was meant to pin behavior assumed correct; instead it surfaced a real cleanup bug. When a test premise that "should pass with the current implementation" fails, first hypothesis should be "implementation has a gap," not "test is wrong." [source](dev-journal/2026-05-13.md)
- **Concrete trigger conditions in watch-outs do their job** — the 2026-05-12 watch-out about new pages adding their own `<main>` had an explicit trigger; the 2026-05-13 review fired on a *pre-existing* page the hoist sweep missed. Will keep writing watch-outs with explicit triggers, not just "revisit later." [source](dev-journal/2026-05-13.md)
- **Discriminant unions land cheap when callers destructure just the shared discriminator** — `{ ok: true } | { ok: false; reason: ... }` widened `useOptimisticMutation`'s return; both existing callers continue to destructure just `ok` (`boolean` on the union). Rule of three doesn't apply when the abstraction extension is invisible to existing consumers. [source](dev-journal/2026-05-13.md)
- **App Router `<Link>` prefetches on viewport entry, not just hover** — N edit links on a dashboard fires N background RSC fetches, each running its target page's server code. `prefetch={false}` per-link is the lever. [source](dev-journal/2026-05-14.md)
- **`@upstash/ratelimit` handles TTL automatically** — `PEXPIRE currentKey, window*2+1000`. For `slidingWindow(5, "15 m")`, each bucket gets ~30min TTL. GDPR retention is library-default. [source](dev-journal/2026-05-14.md)
- **IPv4 plain-hash reversibility** — keyspace ~4B; `SHA-256(ip)` is brute-forceable in minutes. HMAC with a server-held secret is the cheap fix; secret doesn't enable reversal (HMAC is one-way), blocks rainbow-table precomputation. [source](dev-journal/2026-05-14.md)
- **`null` vs `undefined` is a context call, not a global rule** — CLAUDE.md prefers `null` checks in TS, but that's about object shapes (intentional absence in a record). Function return values feeding React props or Next `Metadata` fields should return `undefined` — those types are written `T | undefined`, drops `?? undefined` boilerplate. [source](dev-journal/2026-05-12.md)
- **Single `<main>` per document is the App Router convention** — multiple `<main>` is invalid HTML5; layout-owned `<main>` with pages rendering plain wrappers is the structural norm. [source](dev-journal/2026-05-12.md)
- **`sonarjs/cognitive-complexity` (limit 15)** — bites when concentrating route-handler logic. Extract per-file loops and side-effect emitters into named helpers; the rule passes and readability improves. [source](dev-journal/2026-05-17.md)
- **Required typed fields propagate cleanly through tsc** — adding `batchId: string | null` to `AdminAuditPayload` surfaced as type errors on every one of the 7 single-row callers, making "did I miss a site?" trivial. Worth using proactively when extending shared payload shapes. [source](dev-journal/2026-05-17.md)
- **Phase-aligned commits require intermediate-state authoring for files that span phases** — `PostsTab.tsx` participated in commits 1 and 2; `bulk/route.ts` participated in commits 3 and 5. The cleanest path: stage commit N's version of the file, commit, then edit to commit N+1's version. Backup-to-`/tmp` is the failsafe when reverting via `git checkout HEAD --` between phases. [source](dev-journal/2026-05-17.md)
- **`cd` mid-session with relative hook paths breaks tool access** — changing the working directory while a session is active can cause `.claude/hooks/` relative paths to resolve incorrectly, blocking further tool calls. Never `cd` away from the project root during an active session. [source](dev-journal/2026-05-18.md)
- **`summary IS NULL` rows must be backfilled before a `NOT NULL` schema migration** — Prisma's `db:push` does not apply migrations with backfills; any existing NULL row breaks the push immediately. Always commit a backfill snippet alongside the schema change or run the backfill interactively before `db:push`. [source](dev-journal/2026-05-18.md)
- **`setupUser({ delay: null })` is the v14 recommended config for non-interactive test contexts** — eliminates artificial inter-event delay; ~47% speedup in this codebase with no semantic loss for non-keyboard-interaction tests. [source](dev-journal/2026-05-18.md)
