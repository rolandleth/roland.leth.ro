## Learnings

- **Testing** — write the test from the logic, not the code (catches impl gaps); a `textContent` assertion can pass via an unrelated mechanism (JSON-LD); `AnimatePresence` keeps a dialog mounted through exit (assert cleanup side effects); eslint caching masks failures (scope conclusions to touched files). [source](dev-journal/2026-07-05.md), [source](dev-journal/2026-07-07.md)
- **Next.js caching** — `revalidateTag` busts the Full Route Cache too (static pages needed no edit-flow change); a tag is only as surgical as its granularity; `unstable_cache` stores `null` forever with tags fixed at write time — throw a miss and translate at the boundary, never return "not found" from inside. [source](dev-journal/2026-07-07.md), [source](dev-journal/2026-07-17.md)
- **Gestures** — framer's `onDragEnd` can't gate the browser's post-drag `click` (deferred via `frame.postRender`); a `key` on a container remounts its whole subtree (dangerous around a framer-`MotionValue` child). [source](dev-journal/2026-07-08.md)
- **Idempotent normalizers make good validators** — `x === normalize(x)` is a free "is-canonical" predicate; collapsed three slug cases into one comparison, and reusing `setFrontmatterSlug` as the drift check can't diverge from the write path. [source](dev-journal/2026-07-16.md), [source](dev-journal/2026-07-17.md)
- **Copy-adapting a pipeline invites drift; migrate data vs enforce rules are separate** — the admin route silently reverted to title-derivation after being hand-copied; sharing the pipeline killed the class of bug. Fixing the data (`init-post-slugs`) doesn't remove the need for the rule that keeps every later write correct. [source](dev-journal/2026-07-16.md)
- **Check importer write semantics before designing relations** — `import-projects.ts`'s delete-then-create would have cascade-nuked guides via an FK; caught by reading the script first. Guides reference projects by slug string, not FK. [source](dev-journal/2026-07-17.md)
- **`postDatetimeToISO` builds a local Date** — fine for string-datetime posts, a latent day-shift for a real `DateTime` column; reach for a UTC constructor when the value lands in a DB column. [source](dev-journal/2026-07-17.md)
- **The tree can change mid-conversation** — the revalidate route gained guides handling between read and edit (a parallel session's merge). Re-read load-bearing code before editing when a parallel session exists. [source](dev-journal/2026-07-17.md)
- **A constraint confirmed can collapse a "design decision" into a clean fix** — the folder-move fix looked hard until the parser was found to skip any guide whose folder lacks an `index.md`, removing the unresolvable-folder edge. Read the constraints before declaring scope. Also: not every review finding is a fix (verify before "fixing" — the P2002 message was a false positive). [source](dev-journal/2026-07-18.md)

### Watch-outs & Tech Debt

- **Miss-stampede: detail 404s never cached** — self-healing, but a slug-enumerating crawler hits Postgres per request; the bot short-circuit only catches known-bad shapes. Revisit when prod DB metrics show probe traffic reaching the DB; add a short-TTL negative cache then. [first flagged: 2026-07-17]
- **Admin body search is a seq scan** — `listGuidesForAdmin`/`listPostsForAdmin` `contains`+insensitive, no trigram/GIN index; revisit at ~thousands of rows (needs a migration + `pg_trgm`). [first flagged: 2026-07-18]
- **Cross-table slug race unenforced at the DB** — a guide and topic can concurrently claim one slug (app-checked via `findSlugOwner`); a P2002 is therefore always same-table. Revisit if write concurrency rises. [first flagged: 2026-07-18]
- **`atomicWrite` not power-loss durable** — no fsync by design; a torn write can't happen, a lost one self-heals on re-run. [first flagged: 2026-07-18]
- **Guide `publishedAt` has two write paths** — importer reads it from the filename and re-syncs on `--overwrite`; admin stamps once. A filename rename silently moves the date. [first flagged: 2026-07-17]
- **Guides don't infer `published` from date; null `publishedAt` = live** — an imported guide is always `published: true`; a future date only schedules it. Watch when adding admin-created guides that skip the filename path. [first flagged: 2026-07-17]
- **FKs to `Project` are a trap** — `import-projects.ts` replaces a project wholesale; guides deliberately reference by `projectSlug` string. Revisit if the project importer moves to upsert-in-place. [first flagged: 2026-07-17]
- **`init-post-slugs`/`import-posts` need prod `DATABASE_URL`** — local Postgres.app rejects `trust` auth; use `vercel env pull` before a real run. First `db:import-posts` without a prior slug init rewrites every file. [first flagged: 2026-07-16]
- **`llms.txt` / `.md` route dual cache staleness** — route-level `s-maxage` outlives the tag-backed data cache bust; resolve together. [first flagged: 2026-07-05]
- **Gallery: gesture bugs not reproducible in jsdom; stage ratio hardcoded `aspect-[1270/760]`** — fixes covered by proxy guards; revisit the ratio if a project stages non-1270×760 shots. [first flagged: 2026-07-08]
- **`yarn build` unverifiable locally** — sandbox can't reach Google Fonts; local gate is `tsc` + tests + lint on touched files. [first flagged: 2026-07-07]
