## Learnings

- **Write the test from the logic, and it catches the impl gap** — the empty-string price bug surfaced only because the test asserted intended behavior rather than mirroring the code. [source](dev-journal/2026-07-05.md)
- **A `textContent` assertion can pass via an unrelated mechanism** — when the same string is embedded elsewhere (JSON-LD here), the test proves nothing about the code path it names. [source](dev-journal/2026-07-05.md)
- **Next.js dynamic segments can't carry a file extension** — `[slug].md` is invalid; a *dynamic* slug + extension always needs a rewrite, confirmed against official docs. [source](dev-journal/2026-07-06.md)
- **`postDatetimeToISO` normalizes to UTC** — a test hardcoding a wall-clock ISO string fails on a non-UTC machine; derive the expectation from the formatter instead. [source](dev-journal/2026-07-06.md)
- **eslint caching masks failures** — `yarn lint` reported clean early in a session, then surfaced 20 pre-existing errors once the cache invalidated; scope lint conclusions to touched files. [source](dev-journal/2026-07-07.md)
- **`revalidateTag` busts the Full Route Cache, not just the Data Cache** — it invalidates every prerendered page whose render read that tag, which is why making pages static needed no edit-flow rework. [source](dev-journal/2026-07-07.md)
- **`revalidateTag` is only as coarse as the tag** — a tag shared by aggregate + detail caches means one bust regenerates both; per-item tags are what make revalidation surgical. [source](dev-journal/2026-07-07.md)
- **ISR 0-reads / N-writes is a signature of blind regeneration** — a route written but never read is being regenerated with no consumer, usually from over-broad tag invalidation. [source](dev-journal/2026-07-07.md)
- **Framer's `onDragEnd` can't gate the browser's post-drag `click`** — it's deferred via `frame.postRender`, landing a frame after `pointerup`/`click`; for click-vs-drag suppression, read the raw pointer instead. [source](dev-journal/2026-07-08.md)
- **A `key` on a container remounts its entire subtree** — dangerous when a stateful child (a carousel holding framer `MotionValue`s) sits inside a per-item-keyed panel. [source](dev-journal/2026-07-08.md)
- **Idempotent normalizers make good validators** — when a canonicalizer is idempotent, `x === normalize(x)` is a free "is-canonical" predicate. [source](dev-journal/2026-07-16.md)
- **Copy-adapting a gate pipeline invites drift** — the admin bulk route had been hand-copied from `parsePostFiles`; when the slug rule changed, only the script got it. [source](dev-journal/2026-07-16.md)
- **Verify examples before citing them** — a claim that Linear files essays under "guides" was pattern-matched, not known, and shrank on verification. [source](dev-journal/2026-07-17.md)
- **`unstable_cache` stores `null` like any value, forever, with tags fixed at write time** — never return "not found" from inside a cached callback unless a pinned miss is acceptable; throw and translate at the boundary. [source](dev-journal/2026-07-17.md)
- **List-works/detail-404s is a precise diagnostic** — the slug is the only term that round-trips through the URL, so that split accuses the slug bytes or the detail cache, and acquits section/published/datetime. [source](dev-journal/2026-07-17.md)
- **A tool that drops input while reporting success poisons its own incident history** — the revalidate endpoint's silent-skip made "bust failed" and "bust never ran" indistinguishable retroactively. [source](dev-journal/2026-07-17.md)
- **"Corruption case" was really the *ambiguous* case** — a title-match-at-different-datetime is identical data for a legitimate re-date and a title reuse; the right framing is refuse-and-report, not "detect corruption." [source](dev-journal/2026-07-17.md)
- **"I/O isn't billed" doesn't mean "move work to the DB"** — Fluid not charging for DB await time is real, but DB compute/connections are a separate, more fragile meter and an unbounded-bot exposure. [source](dev-journal/2026-07-17.md)
- **Middleware runs on 100% of matched requests, including CDN-cached hits** — why middleware CPU dominates function CPU on a static-heavy site. [source](dev-journal/2026-07-17.md)
- **Not every review finding is a fix** — of 6 skipped findings in one session, one was a false positive, two were better solved differently, three were cost/benefit no-gos; verifying a claim beats reflexively "fixing" it. [source](dev-journal/2026-07-18.md)
- **Verify challenged facts against the source, don't defend from memory** — re-checking the IndexNow FAQ after being challenged (and reporting that the info held, with the reason) was the right move over restating the claim. [source](dev-journal/2026-07-19.md)

- **Verify subagent findings that turn on exact control flow** — two of three review analyzers made confident claims about `proxy.ts`; one was wrong, and contradicted its own gatherer. The disagreement was the signal; an unchallenged analyzer would have written a fabricated auth defect into a file that becomes trusted context. [source](dev-journal/2026-07-20.md)
- **Cognitive-complexity lint errors are usually a real signal** — the extraction that satisfied the linter also removed a duplicated check between two code paths; suppressing it would have kept both problems. [source](dev-journal/2026-07-20.md)
- **Don't route file edits through the shell when a dedicated tool exists** — reaching for `perl -pi` over `Edit` with `replace_all` is invisible, unreviewable, and against project rules. [source](dev-journal/2026-07-20.md)
- **"Correct today" and "structurally sound" are different claims** — advice to leave middleware-only auth alone changed once the framework version and vendor guidance were checked; worth separating those axes explicitly when answering a security question. [source](dev-journal/2026-07-20.md)

### Watch-outs & Tech Debt

- **Middleware is the sole auth boundary for all 12 admin routes** — no route does its own session check. Vendor guidance is that middleware shouldn't be the sole authorization boundary, and the pattern was bypassable framework-wide in CVE-2025-29927 (patched 14.2.25 / 15.2.3; this repo is on Next 16.2.10, so not exposed). Trigger: an admin route with irreversible external side effects, or a Next major upgrade. [first flagged: 2026-07-20]
- **IndexNow key-path coupling** — the route folder name `src/app/indexnow-key.txt/` and the `keyLocation` template in the submit route both hardcode `indexnow-key.txt`; renaming one breaks verification. [first flagged: 2026-07-19]
- **`getSiteUrl()` origin drives what gets submitted to IndexNow** — if prod ever resolves to the `*.vercel.app` host, IndexNow would index vercel URLs. [first flagged: 2026-07-19]
- **IndexNow submit has no throttle, deliberately** — buttons disable in flight, but two completed runs back-to-back resubmit the whole sitemap. Trigger: IndexNow rate-limiting the host, or the sitemap growing past one 10k batch. [first flagged: 2026-07-20]
- **`describeKeyProblem` returns user-facing copy** — the 503 body, the dry-run warning, and two tests assert its wording; rewording is a four-site change. Coupling is intentional so warning and error can't drift. [first flagged: 2026-07-20]
