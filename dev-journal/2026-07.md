## Learnings

- **Write the test from the logic** — the empty-string price bug surfaced only because the test asserted intended behaviour rather than mirroring the code. Direct validation of the no-silent-suppression / test-from-logic rule. [source](dev-journal/2026-07-05.md)
- **`AnimatePresence` keeps a dialog mounted through its exit animation** — asserting `queryByRole("dialog")` is gone after `isOpen=false` fails. Assert side effects that run on effect cleanup (focus restore, `overflow` restore) instead of DOM removal. [source](dev-journal/2026-07-05.md)
- **A `textContent` assertion can pass via an unrelated mechanism** — when the same string is embedded in JSON-LD, the assertion proves nothing about the code path it names. Assert the specific mechanism (structured log), not incidental text. [source](dev-journal/2026-07-05.md)
