## Themes

- **Static rendering sweep** — every marketing/content page flipped from dynamic (`ƒ`) to static (`○`/`●`) by removing two dynamic deps: `cookies()` (theme) replaced with a `ThemeScript` inline pre-paint script + localStorage, and `headers()` (canonical origin) replaced with `getSiteUrl()` from `NEXT_PUBLIC_SITE_URL`. Pages now hit the Full Route Cache (CDN-served, zero server CPU per request). [dev-journal/2026-07-07.md](dev-journal/2026-07-07.md)
- **Project gallery: continuous cross-section lightbox with hand-rolled gesture engine** — flattened all section images into one ordered strip; implemented focal-anchored zoom, pan clamp, and double-tap toggle in `src/lib/client/zoom.ts`; split gesture engines (carousel uses framer-motion `drag`, lightbox hand-rolls pointer events for pinch/pan/swipe arbitration). Two non-obvious bugs hit: framer's `onDragEnd` fires post-`click` (can't gate click suppression from it), and a `key` on the panel container remounted the carousel mid-swipe. Both fixed via raw pointer arbitration and stable panel identity. [dev-journal/2026-07-07.md](dev-journal/2026-07-07.md), [dev-journal/2026-07-08.md](dev-journal/2026-07-08.md)
- **Cache revalidation precision** — post-edit rewrites ballooned from per-post to section-wide and needed two passes to fix: (1) tag split on `loadPost` (coarse `blog-{section}` → per-slug `post-{section}-{slug}` + shared `post-pages`); (2) admin `RevalidatePanel` so the import script (direct Prisma) can trigger Next.js tag busts. Cross-cut: the `.md` route and `llms.txt` share the same dual-cache-layer staleness problem and should be resolved together. [dev-journal/2026-07-07.md](dev-journal/2026-07-07.md)

## Learnings

- **Write the test from the logic — it catches the impl gap** — empty-string price bug surfaced only because the test asserted intended behaviour rather than mirroring the code. [source](dev-journal/2026-07-05.md)
- **`AnimatePresence` keeps a dialog mounted through exit animation** — assert side effects on cleanup (focus restore, `overflow` restore) instead of DOM removal. [source](dev-journal/2026-07-05.md)
- **A `textContent` assertion can pass via an unrelated mechanism** — when the same string is embedded in JSON-LD, the test proves nothing about the code path it names. Assert the specific mechanism. [source](dev-journal/2026-07-05.md)
- **Next.js dynamic segments can't carry a file extension** — `[slug].md` is not valid; brackets must wrap the entire folder name. A dynamic slug + extension always needs a rewrite. [source](dev-journal/2026-07-06.md)
- **`page.tsx` and `route.ts` cannot share a route-segment path** — build-time conflict. [source](dev-journal/2026-07-06.md)
- **`revalidateTag` busts the Full Route Cache, not just the Data Cache** — making pages static needed no edit-flow changes; the tag wiring already propagates to prerendered pages via on-demand ISR. [source](dev-journal/2026-07-07.md)
- **`○` vs `●` is cosmetic** — both prerender to CDN-served HTML; `●` just means a `[param]` route enumerated by `generateStaticParams`. [source](dev-journal/2026-07-07.md)
- **Special files vs Route Handlers** — `robots.ts`/`sitemap.ts` prerender by default; arbitrary `route.ts` handlers are dynamic by default (need `force-static`). [source](dev-journal/2026-07-07.md)
- **ISR 0-reads / N-writes = blind regeneration** — a route written but never read is being regenerated with no consumer; signature of over-broad tag invalidation. [source](dev-journal/2026-07-07.md)
- **`revalidateTag` is only as coarse as the tag** — a tag shared by aggregate + detail caches busts both; per-item vs shared tags makes revalidation surgical. [source](dev-journal/2026-07-07.md)
- **App Router prefetch is heavier for static routes** — a `<Link>` to a static route prefetches the full page; `prefetch={false}` on public cards is the lever if ISR reads balloon. [source](dev-journal/2026-07-07.md)
- **Framer's `onDragEnd` can't gate the browser's post-drag `click`** — it's deferred via `frame.postRender`, landing a frame after `pointerup`/`click`. For click-vs-drag suppression, read raw pointer at `pointerdown`/`pointerup`. [source](dev-journal/2026-07-08.md)
- **A `key` on a container remounts its entire subtree** — dangerous when a stateful/continuous child (carousel holding framer `MotionValue`s) sits inside a per-section-keyed panel. [source](dev-journal/2026-07-08.md)
- **eslint caching masks failures** — scope lint conclusions to files you touched (`grep` the log for your paths) before claiming clean. [source](dev-journal/2026-07-07.md)
- **`aspect-ratio` + `max-height` compose cleanly for "hug but stay bounded"** — the box takes `width/ratio` until the cap wins; `object-contain` absorbs any mismatch. [source](dev-journal/2026-07-08.md)
