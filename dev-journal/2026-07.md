## Learnings

- **Framer-motion's `onDragEnd` fires a frame late** — via `frame.postRender`, after the browser's click — never gate click-vs-drag suppression on it; use raw `pointerdown`/`pointerup` instead. [source](dev-journal/2026-07-08.md)
- **A `key` on a container remounts its entire subtree** — dangerous when a stateful/continuous child (framer `MotionValue`s) sits inside a per-section-keyed panel. [source](dev-journal/2026-07-08.md)
- **Next.js dynamic route segments can't carry a file extension**, and a `route.ts` can't share a path with a `page.tsx` — confirmed against official docs before building the `.md` export route. [source](dev-journal/2026-07-06.md)
- **Next's `alternates` metadata is replace-not-merge per route segment** — a deeper segment that sets its own `alternates` silently wipes an inherited default (e.g. feed autodiscovery). [source](dev-journal/2026-07-24.md)
- **Idempotent normalizers make good validators** — `createSlug(x) === x` is a free "is-canonical" predicate, collapsing three slug states into one comparison. [source](dev-journal/2026-07-16.md)
- **Copy-adapting a shared pipeline invites silent drift** — the admin bulk-import route had been hand-copied from `parsePostFiles` and quietly regressed when the slug rule changed elsewhere; sharing the pipeline removed the bug class. [source](dev-journal/2026-07-16.md)
- **`unstable_cache` stores `null` like any value, forever, with tags fixed at write time** — never return "not found" from inside a cached callback; throw and translate at the boundary. [source](dev-journal/2026-07-17.md)
- **A contract test can be structurally blind and still look thorough** — a pre-existing proxy test asserted every admin path is gated but called `proxy()` directly, presuming the request reached the middleware, which is exactly what the matcher decides. Verified the new guard by deliberately breaking it first. [source](dev-journal/2026-07-26.md)
- **Verify subagent findings that turn on exact control flow before writing them up** — two of three review analyzers made confident, opposite claims about the same code; the disagreement itself was the signal. [source](dev-journal/2026-07-20.md)
- **"I/O isn't billed" doesn't mean "move work to the DB"** — Fluid compute not charging for DB await time doesn't make Postgres a free CPU offload; it's a separate, more fragile meter with a DoS-amplification downside. [source](dev-journal/2026-07-17.md)
- **"Correct today" and "structurally sound" are different claims** — initial advice to leave middleware-only admin gating alone reversed once the framework version and CVE precedent were checked; the change was fact-driven, not pushback-driven. [source](dev-journal/2026-07-20.md)
- **Not every review finding is a fix** — of 6 skipped findings in one pass, one was a false positive, two were better solved a different way, three were genuine cost/benefit no-gos; verifying a claim beats reflexively fixing it. [source](dev-journal/2026-07-18.md)
