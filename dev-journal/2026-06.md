## Learnings

- **HMAC for per-IP bucketing** — hash the IP against a server-side secret to avoid logging raw IPs (PII); the bucket key is opaque; the same IP hashes identically across calls, giving stable per-IP rate limiting without storing the IP. [source](dev-journal/2026-06-10.md)
- **Content-addressed blobs + orphan pruning** — content-addressed keys give automatic CDN cache-busting when content changes and reuse when it doesn't; pairing with post-import orphan pruning keeps storage from growing unboundedly on edits. [source](dev-journal/2026-06-13.md)
- **DI BlobStore interface for testability** — extracting the I/O-free logic (`contentHashFor`, `blobKeyFor`, `keyPathFor`) into `projectImport.ts` and the I/O shell into `blobSync.ts` with a `BlobStore` interface means the shell is unit-testable with a mocked `put`/`list`/`del`. [source](dev-journal/2026-06-13.md)
- **flexbox equal-height cards** — `flex h-full flex-col` on the card wrapper + `flex-1` on the inner link fills the grid cell's full height without hardcoding a pixel value; relies on grid's `align-items: stretch` default. [source](dev-journal/2026-06-13.md)

### Watch-outs & Tech Debt

- **Import is replace-by-slug** — re-importing a project overwrites any admin edits made since last import; integer `id` also rotates on each `deleteMany`+`create` cycle. [first flagged: 2026-06-08](dev-journal/2026-06-08.md)
- **Direct Prisma import skips Next cache revalidation** — project pages may serve stale RSC cache after import until the next deploy or manual revalidation. [first flagged: 2026-06-08](dev-journal/2026-06-08.md)
- **Blob orphans grow monotonically** — content-addressed keys + orphan pruning mitigates, but prune only runs per-project-prefix post-import; edits between imports accumulate stale keys on the 1 GB free tier. [first flagged: 2026-06-13](dev-journal/2026-06-13.md)
- **Prune races concurrent importer** — two importer runs on the same project prefix: run-1 prune deletes blobs run-2 just uploaded but hasn't committed. No lockfile. Realistic only under deliberate concurrent runs. [first flagged: 2026-06-13](dev-journal/2026-06-13.md)
- **Uploader pool has no AbortSignal** — a partial Vercel stall can hang `syncImages` indefinitely; no cancellation or timeout on the bounded `Promise.all`. [first flagged: 2026-06-13](dev-journal/2026-06-13.md)
