## Learnings

- **App icon and accent discovery** — icon at `Assets.xcassets/AppIcon.appiconset/icon_1024.png`; accent at `AccentColor.colorset/Contents.json` (sRGB components × 255 → hex). Encoded in `app-copy-to-project` skill. [source](dev-journal/2026-06-08.md)
- **Marketing screenshots are landscape showcase graphics** — actual asset dimensions (1472×960, 2560×1920); portrait-crop assumption was wrong. Verify dimensions before assuming aspect ratio. [source](dev-journal/2026-06-08.md)
- **Blob is one store across DB targets** — local and prod runs share the same `BLOB_READ_WRITE_TOKEN`; only `DATABASE_URL` differs. Content-addressed keys + reuse mean a local test run avoids re-uploading to prod. [source](dev-journal/2026-06-08.md)
- **Testing Redis-present route path** — requires `vi.resetModules()` + `vi.stubEnv(...)` + dynamic `import()` per test; Upstash mocks must be classes (not arrow-function factories); static `Ratelimit.slidingWindow` attached via `Object.assign`. [source](dev-journal/2026-06-10.md)
- **Legal lastUpdated reflects substantive-text changes only** — layout, list markup, and cross-link changes are presentation-only and do not warrant bumping a legal document's revision date. [source](dev-journal/2026-06-13.md)
- **Scope review-flagged refactor to review's explicit recommendation** — generalizing the layout (rename + parameterize) was wanted; maximal version (folder move + every sibling renamed) was not. Do the bounded version unless asked. [source](dev-journal/2026-06-13.md)
- **flexbox equal-height in a CSS grid** — `flex h-full flex-col` propagates the grid item's stretched height down to card content; the chain must pass through every wrapper (`grid item → motion.div → card`); a wrapper with `h-auto` breaks it. [source](dev-journal/2026-06-13.md)
- **DI BlobStore interface for testability** — extracting I/O-free logic into `projectImport.ts` and the I/O shell into `blobSync.ts` with a `BlobStore` interface makes the shell unit-testable with in-memory fakes. [source](dev-journal/2026-06-13.md)

### Watch-outs & Tech Debt

- **Import is replace-by-slug** — re-importing overwrites any admin edits since last import; integer `id` rotates on each `deleteMany`+`create` cycle. [first flagged: 2026-06-08](dev-journal/2026-06-08.md)
- **Direct Prisma import skips Next cache revalidation** — pages may serve stale RSC cache after import until next deploy or manual revalidation. [first flagged: 2026-06-08](dev-journal/2026-06-08.md)
- **Global-bucket lockout DoS when IP_HASH_SECRET unset** — a botnet doing 5 failed attempts/15min locks the admin for 15min; accepted tradeoff, but trigger to investigate: unexpected 429s on `/api/auth/login`. [first flagged: 2026-06-10](dev-journal/2026-06-10.md)
- **Uploader pool has no AbortSignal** — a partial Vercel stall can hang `syncImages` indefinitely. [first flagged: 2026-06-13](dev-journal/2026-06-13.md)
- **Prune races concurrent importer** — two importer runs on the same project prefix: run-1 prune can delete blobs run-2 just uploaded. No lockfile; realistic only under deliberate concurrent runs. [first flagged: 2026-06-13](dev-journal/2026-06-13.md)
- **Upload-before-write orphans** — failed `writeProject` leaves uploaded blobs as orphans until next-run prune. [first flagged: 2026-06-13](dev-journal/2026-06-13.md)
- **Single `accentColor` across themes** — mid-tone accent is always a contrast compromise on both `#f9fafb` and `#030712`; revisit if accent contrast becomes an issue. [first flagged: 2026-06-08](dev-journal/2026-06-08.md)
- **bucket↔tag coherence blocks universal apps** — `refineBucketTagCoherence` prevents a universal iOS+iPad+Mac app from carrying `macOS` as a tag under the `iOS` bucket; Mac coverage lives in copy only. [first flagged: 2026-06-08](dev-journal/2026-06-08.md)
