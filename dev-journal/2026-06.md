## Learnings

- **The import path has two implementations** — `src/lib/import/projectImport.ts` (pure, tested) and `scripts/import-projects.ts` (its own `writeProject`+`referencedImageUrls`). A schema field change must touch both; editing the lib alone passes tests but ships a broken import. [source](dev-journal/2026-06-28.md)
- **Always-mounted + `inert` is the crawlable-and-accessible accordion pattern** — "in the HTML source" (crawlers) and "in the a11y tree/tab order" (AT) are independent axes; CSS/`inert` hide from the latter without removing from the former. [source](dev-journal/2026-06-28.md)
- **`transparent` is transparent black** — fading to `transparent` produces a grey/black midpoint most visible in iOS Safari. Always fade to the same colour at zero alpha. [source](dev-journal/2026-06-29.md)
- **The History API has no push/replace event** — `popstate` is back/forward only; the Navigation API `currententrychange` is the patch-free SPA alternative (Chromium + Safari ≥18). `navigate` doesn't fire for `history.pushState`. [source](dev-journal/2026-06-29.md)
- **A 301 redirect target is a real crawl path** — `/feed` 301s into `/api/feed/`, so a blanket `Disallow: /api/` would silently delist the public feed. Trace where redirects land before disallowing a prefix. [source](dev-journal/2026-06-29.md)
- **Next only special-cases `robots`/`sitemap` filenames** — any other root file (`llms.txt`) must be a `route.ts` under a folder named for the literal URL segment; a `llms.txt.ts` file does nothing. [source](dev-journal/2026-06-29.md)
- **`unstable_cache` serializes `Date` → string on cache hits** — anything reading a cached `Date` (e.g. `dateModified` from `updatedAt`) must normalize through `new Date()` to handle both first-call `Date` and cache-hit ISO string. [source](dev-journal/2026-06-29.md)
- **`object-contain` + `border-radius` don't compose** — CSS can't round only the letterboxed portion; size the element to the image's aspect via `width={0} height={0}` + `max-*` instead. [source](dev-journal/2026-06-26.md)
- **Shared-rendering-path heuristic** — when the same artifact appears in two surfaces that render the subject identically, the cause is in the shared path, not the differing wrappers. [source](dev-journal/2026-06-26.md)
- **Framer drag + AnimatePresence** — keep the `drag` element separate from the keyed, x-animating slide; use a stable drag layer wrapping `AnimatePresence` so gesture state and enter/exit animation don't fight. [source](dev-journal/2026-06-29.md)
- **Legal `lastUpdated` reflects substantive-text changes only** — layout, list markup, and cross-link changes are presentation-only and do not warrant bumping a legal document's revision date. [source](dev-journal/2026-06-13.md)
- **flexbox equal-height in a CSS grid** — `flex h-full flex-col` propagates the grid item's stretched height down through every wrapper; one `h-auto` wrapper in the chain breaks it silently. [source](dev-journal/2026-06-13.md)
- **Blob is one store across DB targets** — `BLOB_READ_WRITE_TOKEN` is shared; only `DATABASE_URL` differs. Content-addressed keys make a local test run reusable in the prod import. [source](dev-journal/2026-06-08.md)
- **Marketing screenshots are landscape showcase graphics** — verify actual dimensions before assuming aspect ratio; `decision.png` is 1472×960, not portrait. [source](dev-journal/2026-06-08.md)
