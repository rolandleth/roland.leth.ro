### What did I, Claude Code, or my agents learned from this

- **Parallel subagents in one checkout race on uncommitted state.** If I ever spawn >1 agent writing to the same tree, either isolate via worktree or accept that one agent will see the other's work-in-progress and possibly react to it (stash, revert). Default to serial + commit-between unless the filesets are disjoint AND don't share generated artifacts.
- **Prompt must forbid Bash-for-inspection explicitly, not just Bash-for-ops.** Agents reach for `awk`/`sed`/`od` to debug mismatched Edit `old_string`. The right escape hatch is another Read with offset/limit, not shell. Bake this into every agent prompt.
- **`vi.spyOn` vs `vi.fn()` differ under `vi.resetAllMocks()`.** Spies fall through to original on reset; plain mocks stay silent. Before "improving" a test setup, verify the semantic the existing code relies on.
- **When agents duplicate-mock `next/cache` across 8 files, the right fix is a shared factory in `src/test/mocks/`, not an eslint rule.** The duplication was a structure gap, not discipline. Same logic applies to fixtures — `makePost` deserved to exist months ago.
- **React `cache()` is the right primitive for `generateMetadata` + page-body dedupe.** I kept reaching for `unstable_cache` (persistent, tag-invalidated) when the actual need was per-request memoization. `cache()` is free and exactly-matching.
- **Always check if a "pre-existing error" is actually pre-existing before blaming the current agent.** Round 1a was suspected of breaking posts.test.ts; `git stash` + tsc on HEAD proved it was there from the start.
- **User preference: `@apply` utilities over wrapper components for repeated Tailwind strings.** Saved as feedback memory; apply proactively on future refactors.

### Decisions

- **`KNOWN_ROUTES` gets the two missing entries, not a generated manifest** — user picked option A. Smaller diff, one place to keep in sync, comment explicitly warns about drift. The deeper fix (runtime-detect against `src/app/` folders) is overkill for a ~7-entry set.
- **`legacy-redirect` miss returns JSON 404, not `NextResponse.redirect('/404')`** — the old redirect reentered middleware (`/404` isn't a known route → rewrite back to `/api/legacy-redirect/404` → loop). 404 JSON settles the request at the API layer where the rewrite originated.
- **Prisma `Section` as a DB enum, not a shared TS union + string column** — user picked option B after I laid out trade-offs. Requires `db push`, but every query now type-narrows `section` at the Prisma boundary; removed all `as Section` casts and tightened 4 interface definitions. Test fixtures picked up `as const` to retain literal types.
- **`ReorderControls` handlers made required, not discriminated** — tried a `canMoveUp: true → onMoveUp: () => void` discriminated union first; callers pass `canMoveUp: index > 0` which TS widens to `boolean`, so the union rejected them. Downshifted to "both handlers always required; `canMove*` drives `disabled` only" with a comment explaining why.
- **`listPostsForAdmin`/`listProjectsForAdmin` paginate search at the same `PAGE_SIZE`** — dropped the silent `ADMIN_LIST_LIMIT = 100` cap that also made `totalPages` lie when searching. Projects return unchanged for non-search (cached grouped view) but now expose `totalCount/totalPages` uniformly so the admin UI can branch on `totalPages > 1`.
- **`PresetOrFreeformInput` fully derived from `value`, no mirror state** — removed both `useState` calls; `isPreset`/`isFreeform` computed on every render from the prop. Always-rendered `Freeform…` option gives users an explicit escape from preset mode. Added 13 tests covering initial render, prop sync in both directions, interactions, and `required` flag behavior.
- **`MarkdownEditor` drops the `setTimeout` debounce** — `useDeferredValue` already drops stale renders; the extra 150ms only delayed every preview without real coalescing gain. Added a `.catch()` that logs + renders an inline error state; silent unhandled rejections are now visible.

### Tradeoffs

- **Admin search now paginates instead of showing `N of 100+`** — gained correct `totalPages`, gained access to matches past 100; accepted that the user now clicks through pages instead of scrolling. Reversibility: easy (restore `ADMIN_LIST_LIMIT` branch).
- **Prisma `Section` enum migration requires `db push`** — runtime safety at the cost of a coordinated deploy (schema + code). Migration is additive (values match prior strings), so rollback is safe if done before new writes land. Reversibility: easy within the deploy window; harder after new rows exist.
- **`PresetOrFreeformInput` always shows `Freeform…`, even on initial render** — old code only showed it once a preset was picked. Gained: deterministic mode switch, no stranded state. Accepted: one extra option visible from the start. Reversibility: easy.
- **`legacy-redirect` hard 404 on miss** — old code sent users through a `/404` redirect that re-entered middleware. Simpler now, but a hypothetical future edge case where we want a soft-redirect to a search page (e.g. "did you mean…") would need to re-plumb. Reversibility: easy.
- **`MarkdownEditor` preview error state renders as a red `<span>`** — minimal affordance; considered and rejected a full error toast (over-engineered for a single-user admin tool).

Not a regression (the doc is meant to live in-repo), just a tidier-commits miss. Noted for future sessions: stage review docs first in an isolated commit.

### What did I, Claude Code, or my agents learned from this

- **Discriminated unions fail silently when callers pass computed booleans.** If `canMoveUp: index > 0` becomes `boolean`, the discriminant is gone. For required-together props, simpler to just make them required and use a comment; reserve unions for literal-typed callers.
- **Prop-mirror state (`useState(propValue)`) is almost always a bug waiting to happen.** The mirror doesn't re-sync on prop change without a `useEffect`, and `useEffect` for sync is the React anti-pattern. Derive instead. `PresetOrFreeformInput` had both bugs (drift on prop change, conditional `Freeform…` toggle) masked by "it works for the first render".
- **When tightening a `string` to a union/enum, test fixtures are the long tail.** 20+ fixtures needed `as const` after the Prisma enum change. Next time, grep `section:` first, fix fixtures proactively, then tighten the type.
- **Loop-closing checklist: when a middleware rewrites an unknown path to an internal route, that internal route must terminate (respond), never redirect to another path that re-enters middleware.** `/404` in the miss branch was a self-rewrite loop. Rule: API legacy-redirect must respond with status, never issue a new path that goes through the matcher again.
- **`useDeferredValue` already debounces.** Don't stack a `setTimeout` on top — it just adds fixed latency without changing coalescing behavior. If you need more throttling, increase the deferral threshold in React devtools, not in userland.
