### Decisions

- **Delegation split by area, not by review dimension** — each agent did reuse + quality + efficiency on its own slice (lib, components, app pages, admin, API+proxy, tests). Alternative rejected: three dimension-scoped agents over the whole repo — would have produced duplicate findings and thin per-file context.
- **Sequential rounds with commit-between gate** — after the initial parallel Round 1 collided on shared working tree (see Incidents), all subsequent rounds ran one agent at a time with a commit between. Alternative rejected: `isolation: "worktree"` for parallel agents — merge painful given Round N depends on Round N−1's helpers.
- **Tailwind reuse via `@apply` utility, not wrapper component** — extracted `.admin-input` in `globals.css` instead of `<AdminInput>` primitive. User preference; saved as feedback memory.
- **`console.error = vi.fn()` over `vi.spyOn`** — reverted my own "improvement". Spies with `vi.resetAllMocks()` fall through to the original (silencing breaks mid-test); plain `vi.fn()` stays a no-op. My assertion-motivated spy change was solving a non-problem since plain `vi.fn()` is already assertable.
- **React `cache()` for per-request dedupe** — `loadPost`/`loadProject`/`loadPostForAdmin`/`loadProjectForAdmin` wrap the existing primitives; `generateMetadata` + page body now share one DB hit.
- **Sitemap uses `updatedAt`, not `datetime`, for `lastModified`** — accuracy improvement; the old code parsed publish date. Accepted: future-dated posts can surface in sitemap if `published: true` (noted as open thread).
- **`Section` as closed union throughout** — tightened `section: string` → `section: "tech" | "life"` in `src/lib/posts.ts`. Propagation required `isValidSection` guard in `generateMetadata` (forgotten before this session).
- **`postDatetimeToISO` throws on malformed input** — replaced the silent `new Date().toISOString()` fallback in feed/sitemap paths so data bugs surface instead of shipping garbage dates.
- **Inline pathname-hide into `Header.tsx`, delete `SiteChrome.tsx`** — the wrapper existed only to gate header rendering; collapsed to `Header` returning null on admin/home. One fewer client island.

### Incidents / Bugs

- **Parallel Round 1 agents collided in shared working tree** — Agent 1a (lib) saw Agent 1b's (components) uncommitted edits as noise and tried `git stash` to test tsc on a clean baseline. User stopped it correctly. Root cause: parallel subagents share the checkout; my plan didn't account for mutual visibility. Fix: switched to serial rounds for all subsequent work.
- **Round 3b agent ran `awk` to inspect indentation** — after an Edit failed to match, it reached for shell introspection instead of another targeted Read. User stopped it. Root cause: prompt didn't explicitly forbid Bash-for-inspection (only Bash-for-ops). Fix: added explicit anti-bash clause to Round 4+ prompts: "If Edit's old_string doesn't match, Read the file again — do NOT reach for awk/sed/od".
- **Pre-existing `src/lib/posts.test.ts(278)` TS error** — `mockImplementation` return type mismatch (`Promise` vs `PrismaPromise`). Persisted across rounds; fixed in Round 5a with a `as unknown as ReturnType<typeof prisma.post.findMany>` cast.

### What did I, Claude Code, or my agents learned from this

- **Parallel subagents in one checkout race on uncommitted state.** If I ever spawn >1 agent writing to the same tree, either isolate via worktree or accept that one agent will see the other's work-in-progress and possibly react to it (stash, revert). Default to serial + commit-between unless the filesets are disjoint AND don't share generated artifacts.
- **Prompt must forbid Bash-for-inspection explicitly, not just Bash-for-ops.** Agents reach for `awk`/`sed`/`od` to debug mismatched Edit `old_string`. The right escape hatch is another Read with offset/limit, not shell. Bake this into every agent prompt.
- **`vi.spyOn` vs `vi.fn()` differ under `vi.resetAllMocks()`.** Spies fall through to original on reset; plain mocks stay silent. Before "improving" a test setup, verify the semantic the existing code relies on.
- **When agents duplicate-mock `next/cache` across 8 files, the right fix is a shared factory in `src/test/mocks/`, not an eslint rule.** The duplication was a structure gap, not discipline. Same logic applies to fixtures — `makePost` deserved to exist months ago.
- **React `cache()` is the right primitive for `generateMetadata` + page-body dedupe.** I kept reaching for `unstable_cache` (persistent, tag-invalidated) when the actual need was per-request memoization. `cache()` is free and exactly-matching.
- **Always check if a "pre-existing error" is actually pre-existing before blaming the current agent.** Round 1a was suspected of breaking posts.test.ts; `git stash` + tsc on HEAD proved it was there from the start.
- **User preference: `@apply` utilities over wrapper components for repeated Tailwind strings.** Saved as feedback memory; apply proactively on future refactors.
