# Lookup Map — overview (through commit c80fc36 on 2026-05-11)

- `src/` — Next.js middleware (`proxy.ts`): admin-API/page auth gate, legacy URL redirects (section-blog, archive, search, feed, privacy-policy).
- `src/app/` — root layout, landing page, sitemap, `not-found`, error boundaries (`error`, `global-error` — `global-error` uses inline styles since the root layout's CSS is unavailable when it fires), `ClientAnalytics` client island. Root layout wraps `{children}` in a `<div id="main-content" tabIndex={-1}>` so a skip-link `<a href="#main-content">` (rendered before `Header`) can move focus past the global nav. Sitemap emits 4 extra static routes (`/projects`, `/tools/loan-calculator`, `/privacy`, `/privacy/body-tracking`) + dynamic project routes via `getAllProjectSlugs`; post + project listings filter `datetime <= now` via `getAllPublishedPostSlugs`/`getAllProjectSlugs`.
- `src/app/[slug]/` — root-level catch-all for legacy URLs; runs only when no static top-level route matches. `permanentRedirect`/`notFound` based on `lookupLegacySlug`.
- `src/app/about/` — about page server component + content.
- `src/app/admin/(protected)/` — protected admin shell; `layout.tsx` adds defense-in-depth `verifySession`. `page.tsx` is the tab-router.
- `src/app/admin/(protected)/posts/[id]/edit/`, `…/posts/new/`, `…/projects/[id]/edit/`, `…/projects/new/` — admin CRUD pages. Edit pages share a single DB hit between `generateMetadata` and the body via React `cache()` inside `loadPostForAdmin`/`loadProjectForAdmin`.
- `src/app/admin/login/` — login page; redirects authenticated visitors to `/admin`.
- `src/app/api/admin/posts/`, `…/posts/[id]/`, `…/projects/`, `…/projects/[id]/` — admin write API. All goes through `parseJsonBody` for body parsing; PUT/POST/DELETE emit a structured `[api:admin:…] success` audit log via `auditLog(tag, AdminAuditPayload)` (every key required; call sites pass explicit `null` for inapplicable fields). Posts PUT audits `previousSlug` when a title rename changes the slug; projects PUT audits `sortOrder` on every PUT so reorders are distinguishable from in-place edits. Project mutations under `Prisma.TransactionIsolationLevel.Serializable`; both posts and projects PUT read the prior section/slug inside the same `$transaction` as the update so cross-section/rename moves bust both old and new cache tags atomically. 409 unique-slug paths log at warn with the colliding slug.
- `src/app/api/auth/login/`, `…/auth/logout/` — public auth entry. Login uses per-IP Upstash rate-limit (`clientBucketKey`) with try/catch fail-open; rate-limit-exceeded logs at warn (routine adversarial), invalid-credentials at error with the bucket key for correlation, success at info.
- `src/app/api/cron/ping/` — Vercel cron keepalive; constant-time Bearer check; sets `KEEPALIVE_KEY` in Redis. Missing `CRON_SECRET` returns 401 (not 500 naming the env var) while the server-side `console.error` preserves operator visibility; unauthorized hits log at warn.
- `src/app/api/feed/[section]/` — Atom feed; `unstable_cache`-tagged per section; 20 posts pre-rendered to HTML inside the cached fn (memory-bound watch-out).
- `src/app/api/upload/` — Vercel Blob upload, gated on `ALLOW_UPLOADS=true` (lazy-read so `vi.stubEnv` works); Content-Length precheck before `formData()` parse, then magic-byte sniff via `detectImageMime` (PNG/JPEG/GIF/WebP/AVIF) rejects payloads mislabelled as allowed image MIMEs. 413/415 paths log at warn.
- `src/app/blog/[section]/`, `…/[slug]/`, `…/archive/`, `…/search/` — public blog pages (list, single post, archive, search). Each gated on `isValidSection(section)` → `notFound()`.
- `src/app/privacy/`, `src/app/privacy/body-tracking/` — privacy pages; share `PrivacyPageLayout`. Per-page metadata + content sections.
- `src/app/projects/`, `src/app/projects/[slug]/` — gallery (cached via `unstable_cache`) + single-project detail (renders all section markdown via `Promise.all`).
- `src/app/tools/loan-calculator/` — public loan calculator page; renders the `LoanCalculatorClient` island.
- `src/components/` — top-level shared chrome: `Header`, `Footer`/`FooterYear`, `ThemeProvider`/`ThemeToggle` + `useTheme` hook, `Typewriter`, `PageGlow`, `AnimatedCard`. `Header` hides itself on `/admin/*` (except login) and `/`.
- `src/components/about/` — `FadeIn` framer wrapper used inside `AboutContent`.
- `src/components/admin/` — admin form + control widgets: `AdminNav` + `LoginForm` (both with AbortController + tagged warn on the catch path; both route response bodies through `readErrorMessage` so server `{ error }` + `(HTTP NNN)` surface uniformly), `AdminSearch`, `AdminPagination` (carries `aria-label="Pagination"`), `PostForm`, `ProjectForm` (each backed by `useAdminResource` + single-state-object `setField`), `LinkManager`/`SectionManager` (via shared `useOrderedList` hook; inputs carry `aria-label` since their captions are placeholders or sibling spans, not bound `<label htmlFor>`s), `ImageUpload` (`useId()` + `<label htmlFor>` binds the URL input) + `IsFeaturedToggle` (both route error surfaces through `readErrorMessage` from `useAdminResource`), `MarkdownEditor` (synchronous `setPreview(null)` clear on cache-miss so the "Rendering…" placeholder shows during stale-edit re-parse), `ProjectSortOrderInput` (1-indexed UI, AbortController on every PUT, strict `/^\d+$/` parse on blur), `PlatformPicker`, `ErrorMessage` (shared error surface), `PostsTab`/`ProjectsTab` (extracted from the dashboard split).
- `src/components/blog/` — public blog widgets: `PostCard`, `PostContent` (both render `<time dateTime={postDatetimeToISO(...)}>` so the spec-required ISO 8601 string is emitted, not the project's internal `yyyy-MM-dd-HHmm`), `PostMarkdownContent`, `BlogSectionHeader` (heading↔inline-search), `SearchForm` (imperative focus via `useEffect` keyed on the `autoFocus` prop — avoids the declarative-attr race with AnimatePresence), `Pagination`. `BlogSectionHeader` reimplements outside-click instead of using `useClickOutside` (open follow-up).
- `src/components/home/` — landing-page islands: `HomeHero` (uses `Typewriter`), `LandingBackground` (animated blobs gated by CSS `prefers-reduced-motion` via `[data-blob-bg]` attribute).
- `src/components/loan-calculator/` — calculator UI: `LoanCalculatorClient` (main UI, computes on every keystroke), `LoanCalculatorInput` (input nested in `<label>` for implicit a11y), `LoanCalculatorSummary` (uses CSS color names; design-token TODO).
- `src/components/privacy/` — `PrivacyPageLayout` and `PrivacySection` for the privacy stack.
- `src/components/projects/` — project gallery + detail widgets: `CompactProjectCard` (discontinued fade scoped to icon container; name stays at full opacity for AA contrast), `FeaturedProjectCard`, `ProjectContent` (single-project chrome; injects `:root { --color-header-accent }` globally because the global header consumes it — do NOT scope to a wrapper; tablist roving-tabindex + ArrowLeft/Right/Home/End wrap-around), `ProjectSectionCarousel` (paginate + dot-direction; APG carousel semantics — `role="group" aria-roledescription="carousel"` on the wrapper + `aria-live="polite"` on the slide region; dot hit region via padded `<button p-2.5>` wrapping the visual `<span>`, not a `before:` pseudo, so adjacent regions don't overlap).
- `src/components/ui/` — generic primitives reused across features: `EmptyState`, `ExpandableSearch` (icon↔input swap), `PresetOrFreeformInput` (`FREEFORM_VALUE` sentinel; accepts an `ariaLabel` prop passed to both select + freeform input so callers can label the dual control), `ReorderControls`, `useClickOutside` hook (mousedown-on-document, gated by `enabled`).
- `src/lib/` — utilities, schemas, persistence, and request-time helpers. Hot spots: `posts.ts`/`projects.ts` (cached fetchers + `revalidate*` helpers; `getPostBySlug` uses `findFirst` with `published: true` + `datetime <= now` so drafts and future-dated posts don't leak via canonical URL; `getAllPublishedPostSlugs` applies the same `datetime` filter for sitemap + `generateStaticParams`; `getAllProjectSlugs` exports `{ slug, updatedAt }` tagged `projects` for sitemap project routes), `auth.ts` (JWT + bcrypt with module-load dummy hash for timing defense), `auditLog.ts` (`auditLog(tag, payload)` + `AdminAuditPayload` — unified 6-key shape with required `T | null` keys, so a future call site that drops a relevant field surfaces at tsc instead of silently emitting `null`), `env.ts` (typed env accessors via `EnvConfigError`), `apiErrors.ts` (shared `parseJsonBody`/`handlePrismaError`/`respondInternalError`/`parseIdParam`; `parseJsonBody` logs schema-mismatch paths-only at warn — never values; malformed-JSON also at warn; `describeZodIssues` falls back to `issue.code` joins when every path is empty), `format.ts` (id/page/slug/date/text formatters; `createSlug` dash class includes U+2212 minus + U+00AD soft hyphen), `isAbortError.ts` (`isAbortError(err)` — handles both `DOMException` and plain-`Error` shapes; consumed by every admin mutation site), `loanCalculator.ts` (PMT + amortization, throws on bad inputs), `boundedCache.ts` (FIFO+LRU cache for per-slug `unstable_cache` wrappers), `legacySlug.ts` (`lookupLegacySlug` for the catch-all page; cached `findFirst` filters `published: true` + `datetime <= now` to match `getPostBySlug`), `markdown.ts` (`unified` AST pipelines, `markdownToHtml` strips raw HTML by default), `motion.ts` (`fadeUp` shared variants), `navigation.ts` (`navLinks` source of truth), `platforms.ts` (project bucket logic — word-boundary keyword match), `reorder.ts` (`moveAndReorder`), `request.ts` (`siteBase`/`defaultProto`), `schemas.ts` (Zod for posts/projects/login; `producesNonEmptySlug` refine on `postCreateSchema.title` + `projectCreateSchema.name` rejects all-punctuation titles; `loginSchema.email` is lowercase-trimmed), `sections.ts` (`SECTIONS` + guards), `theme.ts` (cookie→class server-side resolution), `analytics.ts` (`filterAdminEvents` URL anchor), `metadata.ts` (`buildPageMetadata`), `pagination.ts` (`PAGE_SIZE`), `db.ts` (Prisma client + Prisma-error type guards), `adminPageUrl.ts` (admin tab URL builder shared by dashboard split).
