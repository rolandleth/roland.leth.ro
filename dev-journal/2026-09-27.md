### Tradeoffs

- **Guard stays on during save** — a needless prompt is possible if a link is clicked after a successful save but before the list renders; accepted over losing an in-flight save. Reversibility: easy.
- **`requireAdmin` signature change touched all 21 handlers** — gained a contract-enforced CSRF check; cost a wide mechanical diff. Reversibility: moderate.

### Incidents / Bugs

- **Invalid loan-calculator fields had no red border** — `aria-[invalid=true]:border-red-500[&::-webkit-inner-spin-button]:appearance-none` fused two utilities, so Tailwind generated neither. Fixed; a class-token test fails on the fused form (checked by reverting).
- **Uploads stored under the client's extension** — `put` got no `contentType`, and the Blob SDK takes it from the pathname, which keeps the client filename; confirmed from the SDK docs. Fixed with the sniffed type.
- **Lint hook turned `let` into `const` mid-edit** — adding `let isNavigating = false` before its assignment let the post-edit `eslint --fix` apply `prefer-const`, which tsc then flagged. Restored after the assignments existed.

### What did I, Claude Code, or my agents learn from this

- **Add a variable's reassignment in the same edit as its `let`** — this repo's post-edit hook runs `eslint --fix`, which rewrites a not-yet-reassigned `let` to `const` between edits.
- **happy-dom's `sessionStorage` bypasses `Storage.prototype`** — to simulate blocked storage, spy on the `window.sessionStorage` getter, which also matches how real browsers fail.
- **`.test.ts` files run in the node environment here** — anything touching `window` needs `.test.tsx` (happy-dom project in `vitest.config.ts`).
