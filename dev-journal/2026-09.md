## Learnings

- **A review finding can be already-mitigated one layer up** — read the adjacent mechanism (the cron's quiet-path heartbeat) before writing up a gap. [source](dev-journal/2026-09-01.md)
- **Check the helpers before proposing a fix** — `isFutureDatetime` already existed with a docblock arguing for the single captured `now` the race fix needed. [source](dev-journal/2026-09-01.md)
- **Read the prior day's journal before writing findings, not after** — three candidate findings on 2026-09-02 were already recorded decisions or watch-outs; re-raising them reads as the reviewer not having done the reading. A subagent's confident causal claim ("collateral, not intended") had true facts and a wrong conclusion. [source](dev-journal/2026-09-02.md)
- **A wrong test name costs more than a missing test** — a gap gets found; a false positive gets trusted. [source](dev-journal/2026-09-02.md)
- **A test can be green for a reason that isn't the guard** — give mocks a hostile default and mutation-test each guard separately; a one-to-one mapping from mutation to single failing test is what says each guard watches its own invariant. [source](dev-journal/2026-09-03.md)
- **Answer the question that was asked before the one that seems bigger** — the access question was posed as load-bearing and got filled with a safe default instead of re-asked; the work was thrown away one message later. [source](dev-journal/2026-09-03.md)
- **"Zero server compute" is not "no cost"** — the prerendered 404 still mounts the root layout and `<SpeedInsights />`, so every browser hit files Web Vitals under the junk path; a redirect returns no HTML. A "why isn't this in the obvious place" question often has an expired constraint behind it (the alias map predated the deletion of the root catch-all route). [source](dev-journal/2026-09-08.md)
- **Audit live content through the site when no DB command is sanctioned** — sweeping the 20 project pages in the browser settled both badge design questions and surfaced the `itunes.apple.com` quirk no code read would show. Apple listing URLs don't encode the platform, and admin presets don't make a field an enum. [source](dev-journal/2026-09-13.md)
