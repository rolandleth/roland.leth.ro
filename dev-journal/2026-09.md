## Learnings

- **A review finding can be already-mitigated one layer up** — the cron's own heartbeat log already covered a "detection" gap the reviewer thought was missing; read the adjacent mechanism before writing up a gap. [source](dev-journal/2026-09-01.md)
- **"I don't really get it" means the explanation was wrong, not the reader** — a timeline with a concrete date landed where a description in terms of function signatures didn't. [source](dev-journal/2026-09-01.md)
- **A wrong test name costs more than a missing test** — a test whose name claims coverage it no longer has is a false positive that gets trusted; a gap at least gets found. [source](dev-journal/2026-09-02.md)
- **A comment's justification can go stale faster than its code** — recurred all month: session-gate comments outlived the gate's removal (09-03), CLAUDE.md's scheduled-content section contradicted itself for weeks (resolved 09-17), a `postImport.ts` comment was still stale as of 09-24. When a decision reverses, grep for the prose that argued the old one. [source](dev-journal/2026-09-03.md)
- **"Zero server compute" is not "no cost"** — a prerendered 404 is still a full page that mounts analytics; every real hit files Web Vitals under the junk path. [source](dev-journal/2026-09-08.md)
- **Tailwind v4 generates CSS for any class-shaped word in scanned files** — comments, test names and journal Markdown included; `@apply`-ing a plugin class duplicates it, and `@source not inline()` blocks `@apply` too. [source](dev-journal/2026-09-14.md)
- **Cascade layers beat specificity** — an override in `@layer components` can't beat typography's utilities-layer rules; `rg -b -o` over the compiled CSS shows which layer a rule landed in. [source](dev-journal/2026-09-14.md)
- **This sandbox can't run `next build` or start a dev server** — unattended scheduled sessions can't either; CSS and browser-only behavior needs Roland's own verification. Recurred from 2026-09-14 onward. [source](dev-journal/2026-09-14.md)
- **Worktrees in this repo have no `node_modules`** — third occurrence this month, now in memory; work lands on a branch in the main checkout instead. [source](dev-journal/2026-09-15.md)
- **`restoreMocks: true` doesn't clear a `vi.fn()`'s call history** in this repo's Vitest 4 config — a "not called" assertion needs an explicit `vi.clearAllMocks()` in `beforeEach`. [source](dev-journal/2026-09-16.md)
- **Mutations can mask each other** — when two mutations combined still pass a test, rerun each one alone; a restored `maxLength` and an added raw-length check together hid what neither guarded separately. [source](dev-journal/2026-09-23.md)
- **`happy-dom`'s `sessionStorage` bypasses `Storage.prototype`** — simulate blocked storage by spying on the `window.sessionStorage` getter, which also matches how real browsers fail. [source](dev-journal/2026-09-27.md)
