## Incidents / Bugs

No lint/`tsc` guard catches this class of typo. Fixed by hand to `max-w-lg`. [source](dev-journal/2026-09-01.md)

Fixed by the single-read `resolvePost`; boundary now pinned by fake-timer tests, no regression risk. [source](dev-journal/2026-09-01.md)
- **2026-09-03 (session 2) — Three comments still argued for a removed session gate** — `loadingBoundaries.test.ts`, `posts.test.ts`, and the `force-dynamic` comment on `override-preview` all still justified themselves against a session check deleted earlier the same day. Root cause: session 1's cleanup pass fixed the source docblocks and missed the test comments. Regression risk: none, comments only. [source](dev-journal/2026-09-03.md)

## Learnings

- **A review finding can already be mitigated one layer up** — the "stale scheduled notice" observability gap was withdrawn once the cron's existing heartbeat log (with a comment stating that exact purpose) was found; a pinned prerendered page executes no code and can't report on itself, so the cron is the only layer detection can live in. [source](dev-journal/2026-09-01.md)
- **Read the prior day's journal before writing findings, not after** — three candidate findings on 2026-09-02 were already-recorded decisions or watch-outs; skipping the cross-reference would have re-litigated a tradeoff the author had already weighed and logged. [source](dev-journal/2026-09-02.md)
- **A wrong test name costs more than a missing test** — the strongest 2026-09-02 finding wasn't an uncovered branch, it was a test whose name claimed coverage for exactly the thing that changed, with the pinning assertion deleted and nothing replacing it. A gap gets found; a false positive gets trusted. [source](dev-journal/2026-09-02.md)
- **Mutation-test the guard, not just the suite** — each load-bearing 2026-09-03 test (`force-dynamic`, no-session-call) was run against a deliberately broken implementation to confirm it goes red; a "no session" test that passed only because an unmocked helper throws in the test environment isn't a real guard until proven with a hostile default. [source](dev-journal/2026-09-03.md)
- **Answer the question that was asked before the one that seems bigger** — the public-vs-gated access question for `override-preview` was posed as load-bearing and dodged in favour of route shape; filling it with a safe default meant the work was thrown away once the real answer arrived one message later. [source](dev-journal/2026-09-03.md)
- **"Zero server compute" is not "no cost"** — a prerendered 404 is still a full page wrapped by the root layout, which mounts `SpeedInsights`; every real hit files Web Vitals under the junk path. A redirect returns no HTML and reports nothing. [source](dev-journal/2026-09-08.md)
- **Apple listing URLs don't encode the platform** — per-store badge artwork needs a data field or a bucket mapping; URL parsing can't distinguish an iOS listing from a Mac one. [source](dev-journal/2026-09-13.md)
