## Learnings

- **A review finding can already be mitigated one layer up** (the cron heartbeat); read adjacent mechanisms and the prior day's journal before filing a finding; a subagent's confident causal claim is the first thing to check. [2026-09-01](dev-journal/2026-09-01.md), [2026-09-02](dev-journal/2026-09-02.md)
- **A test can be green for a reason that is not the guard** — mutation-test each guard separately; a wrong test name costs more than a missing test; a comment's justification can go stale faster than its code, so grep for prose that argued the old decision. [2026-09-02](dev-journal/2026-09-02.md), [2026-09-03](dev-journal/2026-09-03.md)
- **"Zero server compute" is not "no cost"** — check what a 404 page carries; `robots.ts` re-allows `/api/feed/`; a "why isn't this in the obvious place" question often has an expired constraint behind it. [source](dev-journal/2026-09-08.md)
- **Audit live content through the site when no DB command is sanctioned; Apple listing URLs do not encode the platform; admin presets do not make a field an enum.** [source](dev-journal/2026-09-13.md)
- **Tailwind v4 generates CSS for any class-shaped word in scanned files; cascade layers beat specificity; `yarn build` cannot run in this sandbox (fonts fetch blocked) and worktrees have no `node_modules`.** [2026-09-14](dev-journal/2026-09-14.md), [2026-09-16](dev-journal/2026-09-16.md)
- **Subagent prompts for this user must forbid scripts outright** and list allowed commands; hooks block some command shapes (`git diff --stat HEAD@{…}`, `rg -g`, `rg --files`, pipes through `tail`). [source](dev-journal/2026-09-15.md)
- **Check a scope claim against the shared code path** (orphaned-blob task said "post images"; the upload route serves every admin image field); `restoreMocks: true` does not clear `vi.fn()` call history in the Vitest 4 config. [source](dev-journal/2026-09-16.md)
