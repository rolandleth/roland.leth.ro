# Rolling History — last 30 days (through 2026-10-09)

## Themes

- **Project CTAs evolved into a full product-page and placement model** — 2026-09-13 added an explicit `isOwnApp` boolean on `Project` (rejected deriving it from the free-text `role` field or from hostname alone) plus badge-vs-pill CTA logic keyed on `bucket`. The next day's review found the importer silently reset `isOwnApp` to `false` on re-import (fixed via `assertRequiredFlags`), and that an own app with more than one storefront link rendered the wrong badge (changed to "Download on {label}" pills). By 2026-10-02 this had become a full product-page redesign: required section `kind`/`layout`, per-step galleries, a "Best value" offer flag, and a gallery grouped by featured/own-app flags. 2026-10-03 replaced `isFeatured` and the ownership-driven placement rules entirely with independent `prominence` (high/medium/low) and `pageLayout` (product/portfolio) enums, carried across by one-off SQL before the schema push dropped the old column; `isOwnApp` now only words the store buttons. 2026-10-09 made the closed More projects preview real links and replaced its two `CollapsiblePanel`s with a shared-element slide: the preview row and the full list stay rendered as overlaid layers, `MoreProjectsDisclosure` measures each preview `li` against its twin by `data-project-id`, and one `progress` MotionValue drives `SlideFromPreview`, `FadeInWithList` and the box height (rejected: Framer `layout` over one list, which needs `display: contents` and can't fade the rest on close; `layoutId`, which needs one of each pair unmounted). The same day fixed the preview pick, which took the first 10 after `groupByBucket` and so filled the row with discontinued iOS apps; it now leaves out open source, puts live projects first (`liveFirst`), groups by platform and ends the row with any discontinued ones.
