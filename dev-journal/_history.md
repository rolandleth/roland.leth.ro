# Rolling History — last 30 days (through 2026-08-24)

## Themes

- **Admin auth: single gate to defense-in-depth** — Originated 2026-07-26 as an incident: `src/proxy.ts`'s unanchored extension-exclusion regex let any path merely containing an excluded substring (`.json` contains `.js`) skip the auth gate entirely; fixed with an anchored matcher plus a `requireAdmin()` second lock on all 21 API handlers, and a `SESSION_SECRET` 32-char floor. The gap resurfaced in the page namespace: 2026-08-12 found unauthenticated `generateMetadata` DB reads on the four edit pages, closed with a shared `adminEditMetadata` helper; 2026-08-13 added bypass logging so a future hole is detectable; 2026-08-21 found (via an external review) that the helper only logged-and-fell-through rather than blocking the render, so all six admin data-reading pages — including the `/admin` dashboard root — needed a real `requireAdminPageSession` plus a contract test tying every page body to an actual guard call. 2026-08-15 additionally narrowed the middleware matcher to `/admin*` + `/api/admin*` with no catch-all backstop, deleting the legacy `/:slug` route and its bot-probe filter that had depended on the old broad pattern. [dev-journal/2026-07-26.md](dev-journal/2026-07-26.md), [dev-journal/2026-08-12.md](dev-journal/2026-08-12.md), [dev-journal/2026-08-21.md](dev-journal/2026-08-21.md)
- **Scheduled-content revalidation redesign, and the incident it surfaced** — 2026-08-15 replaced a blanket hourly `revalidate=3600` (a guaranteed ~72 regenerations/day given constant crawler traffic) with a due-check cron that busts tags only when a post/guide comes due, and moved blog pagination from `?page=N` to path-based `/blog/:section/p/:page` so both prerender. Static prerendering then made visible a pre-existing bug: 2026-08-17 found `loading.tsx` Suspense boundaries let `notFound()` commit under HTTP 200 on three production routes, fixed via `(list)`/`(gallery)` route groups plus per-item cron tag busts. The mechanism kept generating friction afterward: 2026-08-21 removed `BlogPostList`'s empty-page guard reasoning the two blog caches "agree by construction," then had to restore it after re-deriving the real failure mode (unpublish/delete racing an `unstable_cache` stale-serve, not a post becoming due); 2026-08-22 documented that `makeBlogPageCache` reads `getSectionPageCount` from inside its own cache callback, so a warm page's `totalPages` can drift from the live count between busts. [dev-journal/2026-08-15.md](dev-journal/2026-08-15.md), [dev-journal/2026-08-17.md](dev-journal/2026-08-17.md), [dev-journal/2026-08-22.md](dev-journal/2026-08-22.md)
- **Social card generation moved off a production route to a build script** — 2026-08-13 built `og-card.png` as a committed fallback image with a dev-only Satori-based generator; the first render had a hard seam traced to Satori not parsing 8-digit hex colors. 2026-08-15 deleted the `/og` route entirely in favor of `scripts/generate-og-card.tsx` (verified byte-identical output), and fixed JSON-LD issues found alongside it: the non-numeric-price fallback deleted as unreachable given the write-side Zod contract, discontinued projects marked `schema:Discontinued` on offer nodes rather than dropping `offers`, and a projectless guide now falls back to the site card instead of no image. Palette drift between `globals.css` and the script's hand-copied color literals remains an open watch-out. [dev-journal/2026-08-13.md](dev-journal/2026-08-13.md), [dev-journal/2026-08-15.md](dev-journal/2026-08-15.md)
- **Recurring learning: a guard never seen to fail is untested** — First stated 2026-08-13 ("verify a lint rule fires"), repeated 2026-08-15 (two bad tests — a bot-probe path and a path-traversal check — both asserted nothing because they never matched), practiced systematically 2026-08-21 (every new/restored test that session was deliberately broken first, catching a vacuous JSX-mock assertion and a nested-brace regex bug), and named explicitly 2026-08-22 after a source-text contract test (`adminPageContract.test.ts`) turned out unable to catch the missing `await` it was written to catch. 2026-08-24 added the mirror case — two tests failed red because their *fixtures* were invalid (a definition whose unescaped `"` closed its own title, and fence fixtures whose closing delimiter fell before the truncation cut), and both read as code bugs until the fixture was checked. [dev-journal/2026-08-13.md](dev-journal/2026-08-13.md), [dev-journal/2026-08-21.md](dev-journal/2026-08-21.md), [dev-journal/2026-08-22.md](dev-journal/2026-08-22.md), [dev-journal/2026-08-24.md](dev-journal/2026-08-24.md)
- **Markdown pipeline gained excerpt-awareness** — 2026-08-24 fixed reference-style links rendering as literal brackets in every blog list excerpt: `truncateBody` slices the raw body at ~700 chars, but link reference definitions are authored at the bottom of a post, so remark parsed `[the opener][series]` as an unresolvable `linkReference`. `extractDefinitions` now slices those definition lines out of the source by mdast node offset (chosen over rebuilding from `label`/`url`/`title`, which needed escaping for quoted titles and spaced URLs) and `PostCard` appends them to a truncated preview. The same pass made the cut code-block-aware via `enclosingCodeBlockStart`, and moved `truncateBody` from `src/lib/utils/format.ts` into `src/lib/content/markdown.ts` — `format.ts` is imported by a `"use client"` component, so importing the parser there would have shipped `unified` and Shiki to the browser.
