## Session 1

### Decisions

- **Legal dates: typed `yyyy-MM-dd` in one list, formatted by the layout** — owner's pick over a test-only shape check (smaller, but the format stays a convention) and fixing only the fixtures. `IsoDay` (template literal) rejects the display form at compile time; `formatIsoDay` refuses unpadded parts, time parts and rolled-over days (`2026-02-30`), and the layout throws, so a bad date fails the build.
- **`LegalPageLayout` takes `path`, not a date** — chosen over each page reading its own date from the list: a page can't render without a list entry, so the sitemap can't miss it. `legalPagesVoice.test.tsx` keys its page map by `LegalPagePath`, so a page in one list and not the other fails `tsc`.
- **Sitemap lists all 11 legal pages, with `lastModified`** (owner: both yes) — the IndexNow panel reads `sitemap()`, and the Weekly Gym pages have no inbound link yet. The date string goes in as is; Next writes it verbatim, so there's no time zone shift.
- **`splitStoreLinks(linkCtas)` over a `storeLinksFor(project)` helper** — `ProductPage` also needs the other links and `ProjectContent` needs the full list, so the helper splits an already-computed list instead of calling `linkCtasFor` again.
- **Tabbed layout's bottom CTA stays first-store-only** — owner confirmed; deliberate, the author picks the primary listing by link order.
- **Header's 1px border: comment fix only** — owner's pick over making the `<header>` itself the token's height (moves the nav content half a pixel, needs a browser check).

### What did I, Claude Code, or my agents learn from this

- **A fixed string formatted at render keeps a route static** — Next.js goes dynamic only on request APIs (`cookies()`, `headers()`, `searchParams`, `connection()`, uncached fetch). The owner asked; answered from the code, not a build, so the build check stays an open thread.
- **`vi.doMock` plus `vi.resetModules` and a dynamic import tests a module-level constant's failure path** — used for the layout's throw on a bad listed date, since the real list can't hold one.
- **Check a review finding against the types before "fixing" it** — the unreachable `?? []` was unreachable only at runtime.
- **The Bash hooks here block `rg --glob`, `rg --files -g` and `git show … > file`** — use `ls`, plain `rg <pattern> <path>`, and Read; run a read-only check against the main checkout's file when the worktree copy can't be compared.
