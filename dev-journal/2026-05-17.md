## Session 1

### Decisions

- **Move `/api/upload` under `/api/admin/upload`** — folds the route into the existing admin namespace so it's protected by the generic `startsWith("/api/admin/")` gate in `src/proxy.ts`, dropping the exact-match special case. Alternative (keep at `/api/upload` and add a second guard list) was rejected: one namespace = one gate is simpler and removes a class of bypass risk.
- **Rename log tag `[api:upload:POST]` → `[api:admin:upload:POST]`** — log-tag prefix follows the route path everywhere else in `src/app/api/` (e.g. `[api:admin:projects:PUT]`, `[api:admin:keepalive]`); divergent naming would have made grepping admin-namespace logs incomplete.
- **Delete the `/api/upload boundary` describe block in `proxy.test.ts`** — both tests pinned the old exact-match contract (gated bare path, sub-paths fell through). After the move, sub-paths are gated by the same `startsWith` that covers the rest of the admin namespace, so the contract no longer exists. The `it.each` further up still backstops admin-gate coverage for the renamed path.

### Tradeoffs

- **`/api/admin/upload/<sub-path>` is now auth-gated by default** — gained: no future sub-route can silently bypass auth (safer posture). Accepted: if a future sub-route ever wants to be public, it has to be carved out explicitly. Reversibility: easy (re-introduce a per-path exception in `src/proxy.ts`).

### Environment / Config Changes

- `src/app/api/upload/` moved to `src/app/api/admin/upload/` via `git mv` (history preserved). Client at `src/components/admin/ImageUpload.tsx:51` now POSTs to `/api/admin/upload`.

### What did I, Claude Code, or my agents learn from this

- **Next.js caches per-route type stubs in `.next/dev/types/`** — after a `git mv` of a route handler, `tsc --noEmit` failed against the stale generated `validator.ts` until the file was removed. The cache regenerates on next dev/build; deleting the single stale file is the minimum-blast-radius fix vs. nuking the whole `.next/` tree. Worth checking `.next/dev/types/` first whenever a tsc error references a path that no longer exists on disk.

Only the upload-specific clause was removed.
