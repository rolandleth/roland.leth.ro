### What did I, Claude Code, or my agents learn from this

- **`yarn build` can't run in this sandbox** — `next/font/google` fetches from `fonts.googleapis.com`, which is blocked, and Roland declined allowing it. Build verification is Roland's to run.
- **No pipe chains in Bash** — a `| sort | uniq -c | sort | head` command was rejected; use separate, targeted commands.
- **Check a scope claim against the shared code path** — the orphaned-blob task said "post images", but the upload route serves every admin image field. The design changed because of it.
- **Verify agent findings before filing them** — one claim ("unbounded log keys") was wrong because Zod messages are fixed text; two independent agents converging on the title-fallback bug was the strongest signal of the session.
- **`restoreMocks: true` doesn't clear a `vi.fn()`'s call history** in this repo's Vitest 4 config — a "not called" assertion needs `vi.clearAllMocks()` in `beforeEach`. Constructor-only mock classes fail `@typescript-eslint/no-extraneous-class`; `vi.fn(function Name() {})` is constructible and passes.
- **`@vercel/blob` facts** (installed version) — `list()` builds a real `Date` for `uploadedAt`, and `put`'s `addRandomSuffix` defaults to `false`.
- **Watching a subagent's output file tells you nothing** — it's the live transcript, non-empty from the start; wait for the completion notification.
- **When a change reverses a test from an earlier day, say so** — `5521775` pinned page 2's description; the change is flagged for confirmation rather than buried.
