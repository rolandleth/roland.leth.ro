### Decisions

- **`postDatetimeToISO` throw → `string | undefined`** — original throw was over-cautious; the schema regex catches malformed datetimes at write time, so legacy DB rows are the only path to bad input. Returning `undefined` (rather than `null`) drops `?? undefined` at 3 of 4 callers, since React props and Next `Metadata` fields are typed for `undefined`. The CLAUDE.md "prefer `null`" guideline applies to object shapes, not function return types feeding React props. Alternative considered: keep throw + try/catch wrapper at every caller — rejected as worse ergonomics and silent-error risk.
- **Hoist `<main>` to root layout** — pages now render plain wrappers; layout owns the single `<main>` with the skip-link target. Alternative considered: leave per-page `<main>` and move `id="main-content"` onto each — same edit count, but layout-owned matches App Router convention. Honest read: marginal a11y improvement for 15-file change; long-term hygiene over near-term ROI.
- **Skip the carousel caption-in-live-region change** — agent flagged that caption sat outside the `aria-live` region, so SR users wouldn't hear it on slide change. On re-read, the image's `alt` already mirrors the caption text and lives inside the live region, so it IS announced. Withdrew the fix.
- **`readErrorMessage` extracted at the 5th caller** — yesterday's "flag at the 4th caller" trigger was crossed; module moved to `src/lib/readErrorMessage.ts` (+ test). 5 admin sites no longer pull `useAdminResource` (a `"use client"` hook module) just for a pure helper.
- **`useOptimisticMutation` extracted at the 2nd consumer** — earlier pass deferred this to the third consumer. Tackled today as part of the explicit deferred-items follow-up. Hook owns abort plumbing + `isAbortError` + supersession guards; callers own the optimistic value commit and the `onRevert` callback. Added full test coverage including the supersession-guard case (stale non-ok response after a newer mutate).
- **Posts PUT escalated to Serializable** — closes the cross-section cache-invalidation race that the Phase 3 comment-fix had left honestly documented but unfixed. Single-admin volume makes `serialization_failure` essentially impossible. Alternative considered: `withRetry` wrapper — deferred until a real conflict surfaces; the `auditLog` double-fire concern would need to be solved first.
- **`AdminAuditTag` typed as a closed union** — string `tag` parameter was a typo vector. Closed union forces tsc to catch new admin-write tags at the call site, matches the same load-bearing-discipline argument as the `T | null` payload tightening from yesterday.

Aligned both to "the slug renamed, here's what it was" — `previousSlug` is now strictly a rename signal in audit lines.

Adding `@@index([slug])` is essentially free and prevents the seq-scan from getting worse linearly with post count.

### Tradeoffs

- **`<main>` hoist** — gained: skip link targets the actual landmark; structurally one `<main>` per document owned by the closest enclosing layout. Cost: 15-file mechanical change; tests passed but real assertion is "does Tab + Enter on the skip link land on `<main>`" — verified by inspection, not test. Reversibility: easy.
- **Posts PUT Serializable** — gained: cross-section cache-invalidation race closed. Cost: tail latency under concurrent writes (irrelevant at single-admin volume); no retry loop, so a `serialization_failure` surfaces as a generic 500. Reversibility: easy (revert isolation level).
- **`useOptimisticMutation` extraction at the 2nd consumer** — gained: ~80 LOC removed across two widgets, supersession-guard concentrated in one tested place. Cost: the abstraction may shape wrongly for the 3rd consumer (rule-of-three exists for a reason). Mitigation: hook returns primitives (`mutate`, `isSaving`, `error`) rather than baking opinions about display state — caller still owns the value. Reversibility: moderate (callers would re-inline ~40 LOC each).
- **Audit-sink durability defer** — gained: avoided ~50ms per admin write + a schema migration + retention-cron complexity. Cost: audit history evaporates after ~1h. Reversibility: easy if the answer changes; documented as `DO NOT PROPOSE` so future code reviews stop re-pitching it.

### What did I, Claude Code, or my agents learn from this

- **The "extract at the Nth caller" trigger from a prior session held up** — `readErrorMessage` was deferred at the 4th-caller flag yesterday; today it crossed to the 5th and the extraction was clean. The discipline of waiting until the threshold is real, then doing it cleanly, beats both premature abstraction and accumulating duplication. Same logic applied (slightly looser) to `useOptimisticMutation` at the 2nd consumer — the 3rd-consumer trigger would have been more defensible, but the deferred-items pass was the right time to re-evaluate and the abstraction landed without contortion.
- **`null` vs `undefined` is a context call, not a global rule** — CLAUDE.md prefers `null` checks in TS, but that's about object shapes (intentional absence in a record). For function return values feeding React props or Next `Metadata` fields, `undefined` is the ergonomic choice — those types are written `T | undefined`, so `null` adds `?? undefined` boilerplate without buying anything. Generalizable: when the consumer pattern is "fall back or omit", return `undefined`; when the value will be stored in a record where "explicitly absent" matters, return `null`.
- **Single `<main>` per document is the App Router convention** — multiple `<main>` is invalid HTML5; layout-owned `<main>` with pages rendering plain wrappers is the structural norm, not just an a11y polish. Will apply going forward to any new layout/page split.
- **Edit tool's JSON encoding interprets `\u` escapes** — to insert the literal text `‐` into a file via Edit, you'd need `\\u2010` in the JSON-encoded `new_string`. Worth knowing for the rare case where a literal escape sequence is wanted in source. Today the workaround was a comment block — same readability outcome.
- **Audit-log structured-payload design is a debt artifact, not a feature** — was sized for an aggregator that won't come. Worth flagging in journal so future maintenance respects the actual carrying cost (the typed shape catches typos at compile time, the structure helps grep, but neither earns the design overhead alone). Documented in this session's watch-outs to give future agents the context.
- **Skip-link wasn't actually broken; just suboptimal** — pre-fix had ONE `<main>` per page with the skip target on a `<div>` wrapper. Honest about urgency: the change was correct, the user impact was marginal. Important to be candid about marginal-vs-load-bearing in code-review writeups so the user can prioritize.
