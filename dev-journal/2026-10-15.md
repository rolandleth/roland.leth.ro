### What did I, Claude Code, or my agents learn from this

- **`scripts/imports/` is gitignored and lives only in the main checkout** — a worktree has none, and a hook blocks Write and Edit into the main checkout from a worktree session even there. Bash `cp` slips past that hook, which is how images landed there before it fired; don't use it to go around the hook. Stage the folder in the worktree and move it after merging, or do import work from the main checkout.
- **tsx's CLI can't run in the sandbox** — it opens an IPC pipe and fails with `listen EPERM`. `node --import tsx scripts/import-projects.ts <name> --dry-run` runs the same script with no socket, and the dry run needs no database.
- **This worktree had `node_modules` but no env file** — `next dev` started, then every page 500'd on `NEXT_PUBLIC_SITE_URL` in the root layout's `generateMetadata`. Check with `ls` rather than assuming either way.
