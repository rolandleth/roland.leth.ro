## Watch-outs & Tech Debt

- **Every `Post.description` write goes through `src/lib/content/postDescription.ts`** — `descriptionForCreate` / `descriptionForUpdate`, used by the admin POST, PUT, bulk upload, `planCreate` and the import overwrite. A value equal to the stored one counts as not sent. A derived description (body excerpt, or the title when the body has no prose) follows body and title edits; an authored one never does. A new write path that sets the column directly brings back the drift.
- **Admin form contract: an omitted key means "leave the column"** — `PostForm` sends `description` as typed (`""` = cleared, derive) and `imageUrl` as `null` when empty. Any new clearable field on an admin form needs the same `""`/`null` handling, or clearing it does nothing.
- **Descriptions stored at 161 chars by the old hard slice** — they no longer equal a derivation, so the rule treats them as authored and they don't follow body edits. Needs a 160-char run with no space; clear the field in the admin if one turns up.
- **`.legal-content a` is part of the unlayered text-link rule** — every anchor inside `PrivacySection` content is styled as a text link. Revisit if a legal page needs a button-styled link.
- **Bulk upload now skips any file `postCreateSchema` rejects** (description over 160, title over 200, body over 100k) via `validatePostFile`, with the schema message as the skip reason.
- **Project manifests are read only through `parseManifest`** — it parses the JSON and runs `assertRequiredFlags`, and `writeProject` takes the flags typed as booleans from it. Bypassing it breaks the `writeProject` type, which is the point.

- **Silent whitespace collapse** — gained: a pasted paragraph just works; cost: intentional double spaces in a description disappear. Reversibility: easy.

- **Title as fallback description** — gained: no blank meta description, feed summary or llms.txt line; cost: the meta description repeats `<title>` for no-prose posts. Reversibility: easy.
