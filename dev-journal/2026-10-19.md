### What did I, Claude Code, or my agents learn from this

- **Check `git rev-parse --show-toplevel` after a cwd reset** — a removed worktree whose folder still exists makes git fall through to the main checkout, where a write would land on `release`.
- **A hook blocks `git worktree add`** — make the worktree with EnterWorktree, then fast-forward it to local `release` (it branches from `origin/release`).
- **Tailwind classes can be checked without a build** — `compile()` from `@tailwindcss/node` on the real `globals.css`, then `.build([candidates])`, from a scratch script. Tailwind 4.3.3 turns `-mt-(--x)` into `calc(var(--x) * -1)`.
- **Mutation-check with the exact old code** — an invented mutation (dropping only the offers guard) sent `offers: null` into the offers card and broke 44 tests; restoring the old body broke exactly the 3 target tests.
- **`src/test/setup.ts` mocks `console.error` in every test** — a test can read `vi.mocked(console.error).mock.calls` for React's duplicate-key warning without its own spy.
