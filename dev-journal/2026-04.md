## Learnings

- **`unstable_cache` JSON-serializes its return value** — any `Date`, `Map`, `Set`, `BigInt` comes back as string or mangled on cache hits. Normalize to serializable shapes (ISO strings, plain objects) **inside** the cached function. Bug is invisible on fresh fetches; only surfaces under cache-hit conditions ("works locally, 500s in prod after first revalidation"). Spot-check any `select:` that includes `createdAt`/`updatedAt`/other `DateTime` fields. [source](dev-journal/2026-04-20.md)
- **`unstable_cache(fn, keyParts, options)` returns a wrapper meant to be built once and reused** — rebuilding per call wastes work and trips Next.js "new cache registered" logs with the function body as identifier. Two correct patterns: (a) lift to module scope, pass variable inputs as fn arguments (keyParts as static namespace); (b) Map-memoize wrappers keyed by variable input when per-key options like tags are required. [source](dev-journal/2026-04-20.md)
- **Per-slug tags declared but never revalidated are dead weight** — grep for `revalidateTag(\`<prefix>-` before assuming a tag is load-bearing. Dropping unused ones simplifies the caching shape. [source](dev-journal/2026-04-20.md)
- **`unified().parse()` is synchronous** — only `.run()` is async. Means `stripMarkdown` doesn't need to be async despite living next to `markdownToReact`. [source](dev-journal/2026-04-20.md)
- **Block vs inline distinction matters for text extraction** — without marking block nodes, sibling paragraphs run together (`"First.Second."`). Trailing `\n` on block node output + `\s+` normalisation is the minimal fix. [source](dev-journal/2026-04-20.md)
- **`notFound()` from an API route renders JSON, not the styled 404 page** — if you need site chrome on a miss, the lookup belongs in a page (catch-all or otherwise), not an API route. [source](dev-journal/2026-04-17.md)
- **When 6 independent buckets are available, parallel sub-agents beat sequential sweeps** — 10 commits / 96 files in one session on 2026-04-17. Works when subtask boundaries are genuinely independent. [source](dev-journal/2026-04-17.md)
