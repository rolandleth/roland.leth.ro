## Learnings

- **Parallel subagents in one checkout race on uncommitted state.** Default to serial + commit-between unless filesets are disjoint and don't share generated artifacts. [source](dev-journal/2026-04-17.md)
- **Agent prompts must forbid Bash-for-inspection explicitly, not just Bash-for-ops.** Agents reach for `awk`/`sed`/`od` to debug mismatched Edit `old_string`. The right escape hatch is another Read with offset/limit. [source](dev-journal/2026-04-17.md)
- **`vi.spyOn` vs `vi.fn()` differ under `vi.resetAllMocks()`.** Spies fall through to original on reset; plain mocks stay silent. Verify the semantic the existing code relies on before "improving" a test setup. [source](dev-journal/2026-04-17.md)
- **React `cache()` is the right primitive for `generateMetadata` + page-body dedupe.** Don't reach for `unstable_cache` (persistent, tag-invalidated) when the actual need is per-request memoization. [source](dev-journal/2026-04-17.md)
- **Prop-mirror state (`useState(propValue)`) is almost always a bug waiting to happen.** Derive from the prop instead. [source](dev-journal/2026-04-17.md)
- **Discriminated unions need literal-typed callers.** A computed boolean (`index > 0`) widens to `boolean` and defeats the discriminant. For required-together props, simpler to make them required and comment why. [source](dev-journal/2026-04-17.md)
- **When middleware rewrites an unknown path to an internal route, the internal route must terminate, never redirect to another path that re-enters the matcher.** Rule applied to the legacy-redirect catch-all. [source](dev-journal/2026-04-17.md)
- **Next.js static routes already act as an allowlist against catch-all dynamic routes.** A `KNOWN_ROUTES` Set next to a middleware that rewrites unknown paths reinvents what the router does natively. [source](dev-journal/2026-04-17.md)
- **Cognitive-complexity lint can be a signal to change the shape of the code, not silence the rule.** `proxy.ts` was at 16 because it was doing routing decisions that belong in the router. [source](dev-journal/2026-04-17.md)
- **0-indexed DB + 1-indexed UI is the right default for ordinal inputs.** Translate once at the component boundary; don't leak DB convention into UX. [source](dev-journal/2026-04-17.md)
- **Anticipatory tests with "this will flip" comments pay off precisely at the moment the code catches up.** [source](dev-journal/2026-04-17.md)
- **Second review pass finds a completely different set of issues from the first.** Coverage is shaped by whichever dimensions the reviewer is attuned to; running both gets both shapes of issue. [source](dev-journal/2026-04-17.md)
- **`useDeferredValue` already debounces.** Don't stack a `setTimeout` on top — adds fixed latency without changing coalescing. [source](dev-journal/2026-04-17.md)
- **`keyof typeof motion` is the right primitive when a component wants to forward to Framer Motion's full tag surface.** Beats hand-maintained unions and beats `keyof JSX.IntrinsicElements`. [source](dev-journal/2026-04-17.md)
- **`restoreMocks: true` in vitest config does not clear `vi.fn()` call history.** Applies to spies only; for `vi.fn()` declared inside `vi.mock(...)`, add explicit `mockReset()` in `beforeEach`. [source](dev-journal/2026-04-17.md)
- **`unstable_cache` JSON-serializes its return value.** Any `Date`, `Map`, `Set`, `BigInt` comes back as a string or mangled on cache hits. Normalize inside the cached function. Invisible on fresh fetches; only surfaces on cache hits — classic "works locally, 500s in prod" trap. [source](dev-journal/2026-04-20.md)
- **`unstable_cache(fn, keyParts, options)` returns a wrapper meant to be built once and reused.** Rebuilding per call is wasteful and trips Next's revalidation bookkeeping. Two correct patterns: lift to module scope or Map-memoize per variable input. [source](dev-journal/2026-04-20.md)
- **`unified().parse()` is synchronous.** Only `.run()` is async. Mdast production can be used in sync contexts. [source](dev-journal/2026-04-20.md)
- **`remark-rehype` strips raw HTML by default.** `markdownToHtml` is implicitly safer than it looks; sanitization is the *actual* behavior even though trusted-input is the *stated* contract. [source](dev-journal/2026-04-21.md)
- **mdast `image`/`imageReference` inherit `alt` from `Alternative` mixin, not `Literal`.** A generic walk that only checks `value`/`children` silently drops captions. Pattern-match on type explicitly. [source](dev-journal/2026-04-21.md)
- **`@types/mdast` ships `Nodes` (union of all node types) and `Root`.** Narrowing via `"value" in node` / `"children" in node` over `Nodes` beats a local shim — new node types get picked up without editing the walker. [source](dev-journal/2026-04-21.md)
- **CDATA-termination is a real-but-rare Atom trap.** `<![CDATA[payload]]>` breaks silently if `payload` contains `]]>`. Canonical fix: `replace(/\]\]>/g, "]]]]><![CDATA[>")`. Apply preemptively to user-authored content. [source](dev-journal/2026-04-21.md)
- **Verify a format claim against the consumer site, not against a doc-comment.** When adding a schema validator (hex, URL, length), grep usages and check whether the consumer actually parses that format — `Buffer.from(..., "hex")` vs `TextEncoder().encode()` is the kind of distinction docs routinely get wrong. [source](dev-journal/2026-04-26.md)
- **`vi.fn().mockImplementation(fn)` is not a constructor.** When mocking an ES class that's `new`'d, mock with a class literal (`class { method = vi.fn() }`). [source](dev-journal/2026-04-26.md)
- **Resolution-marker convention here is strikethrough, not checkbox.** Match the project's actual prior commits (`~~**…**~~ — resolved.`), not the `wrap-up` skill default. [source](dev-journal/2026-04-26.md)
