## Learnings

- **Parallel subagents in one checkout race on uncommitted state** — if spawning >1 writing agent, isolate via worktree or run serial with commit-between unless filesets are strictly disjoint. [source](dev-journal/2026-04-17.md)
- **`unstable_cache` JSON-serializes its return value** — any `Date`/`Map`/`BigInt` comes back mangled on cache hits; normalize inside the cached function so the handler has a single contract. [source](dev-journal/2026-04-20.md)
- **`unstable_cache(fn, keyParts, options)` is meant to be built once and reused** — per-call rebuilding logs the function body as a new revalidation event. Two patterns: lift to module scope, or Map-memoize keyed by the variable input. [source](dev-journal/2026-04-20.md)
- **`unified().parse()` is synchronous** — only `.run()` is async; `stripMarkdown` doesn't need to be async. [source](dev-journal/2026-04-20.md)
- **mdast `image`/`imageReference` inherit `alt` from `Alternative` mixin, not `Literal`** — a generic walk checking only `value` and `children` silently drops image captions. [source](dev-journal/2026-04-21.md)
- **CDATA-termination risk is a real-but-rare Atom trap** — `]]>` in any user-authored payload breaks the feed silently and totally; one-line mitigation applies preemptively. [source](dev-journal/2026-04-21.md)
- **`remark-rehype` strips raw HTML by default** — `markdownToHtml` is implicitly safer than it looks; don't reflexively add `rehype-sanitize` without checking what the pipeline already does. [source](dev-journal/2026-04-21.md)
- **Verify a format claim against the consumer site, not a doc-comment** — `SESSION_SECRET` doc said "hex-encoded" but consumer used `TextEncoder`; misapplied regex. [source](dev-journal/2026-04-26.md)
- **`vi.fn().mockImplementation(fn)` is not a constructor** — when mocking a class instantiated with `new`, use a class literal mock. [source](dev-journal/2026-04-26.md)
- **Next.js static routes already act as an allowlist against catch-all dynamic routes** — any `KNOWN_ROUTES` set adjacent to a middleware rewriting unknown paths is reinventing the router. Add the catch-all page and delete the list. [source](dev-journal/2026-04-17.md)
- **`React.cache()` is the per-request dedupe primitive; `unstable_cache` is for persistent cross-request caching** — don't use `unstable_cache` for `generateMetadata` + page body dedupe. [source](dev-journal/2026-04-17.md)
- **Discriminated unions fail silently when callers pass computed booleans** — `canMoveUp: index > 0` widens to `boolean`, defeating the discriminant. Use required props + `disabled` flag. [source](dev-journal/2026-04-17.md)
- **`@apply` utilities over wrapper components for repeated Tailwind patterns** — user preference; applies proactively on future refactors. [source](dev-journal/2026-04-17.md)
- **`restoreMocks: true` in vitest does not clear `vi.fn()` call history** — applies to spies only; add explicit `mockReset()` in `beforeEach` for `vi.fn()`s inside `vi.mock()` factories. [source](dev-journal/2026-04-17.md)
