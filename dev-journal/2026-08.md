## Learnings

- **`rg -r` is `--replace`, not "recursive"** — `rg -rn`/`rg -rln` silently rewrote every match in the output, making a normal Zod schema look like it was assigned to a one-letter variable and nearly producing a bogus code-quality finding. When `rg` output contradicts the codebase's established conventions, suspect the command first. [source](dev-journal/2026-08-12.md)
- **Probe the live DOM to verify a layout claim when the local server can't run** — forcing candidate styles onto the real page, re-measuring `scrollWidth`, then reverting proved the fix against real content and fonts in a way no unit test can. [source](dev-journal/2026-08-12.md)
- **State the measurement conditions with the measurement** — the overflow was reported as affecting "every project page" without the 375pt qualifier, so on a 393pt phone the claim read as false. Both observations were correct; only the framing was wrong. [source](dev-journal/2026-08-12.md)
