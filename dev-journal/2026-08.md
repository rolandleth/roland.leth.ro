## Learnings

- **Structural reasoning was wrong every time; artifacts were right every time** — four confident framework-behavior claims failed during the soft-404 debugging; every correct conclusion came from reading a `.meta` file or probing a real build. [source](dev-journal/2026-08-17.md)
- **`.next/server/app/**/*.meta` is the cheapest diagnostic available** for whether a route's status was actually set. [source](dev-journal/2026-08-17.md)
- **A static route cannot run a read-time filter** — the single fact that explained why the feed/archive/sitemap needed `revalidate` while the blog list needed a cron instead. [source](dev-journal/2026-08-15.md)
- **Check the traffic assumption before pricing a caching tradeoff** — "costs nothing in idle hours" was imaginary for a site with crawlers and feed readers polling continuously. [source](dev-journal/2026-08-15.md)
- **A regex over source text is a standing liability, not a one-time bug** — `hasGenerateMetadataExport` failed twice in one session with the same shape; the durable fix was leaving source-text matching entirely. [source](dev-journal/2026-08-21.md)
- **A guard that has never been seen to fail is a guard nobody has tested** — mutation-test every new guard by breaking the thing it protects; caught a vacuous JSX assertion and a nested-brace regex bug this way. [source](dev-journal/2026-08-21.md)
- **The review-then-fix pattern generalized to a third instance this month** — a fix (the `errorDetails` widening) created a new hole (JSON-safety), and a fix (the contract test) shipped with a hole in its own assertion. Reviewing remediation commits, not just original code, keeps paying. [source](dev-journal/2026-08-22.md)
- **Verify an automated review's claims before relaying them, even the alarming ones** — confirmed the edit-pages-unguarded finding by reading the page body directly before reporting it; a lower-confidence finding needed full re-derivation before acting. [source](dev-journal/2026-08-21.md)
- **Remove the falsehood before deciding what to add** — narrowing an overreaching privacy-policy claim made most of a proposed disclosure paragraph unnecessary. [source](dev-journal/2026-08-21.md)
- **Framer Motion ignores `prefers-reduced-motion` by default** — `MotionConfigContext` ships `reducedMotion: "never"`; worth checking on any project using the library. [source](dev-journal/2026-08-21.md)
- **`rg -r` is `--replace`, not "recursive"** — silently rewrote matches in output and nearly produced a false code-quality finding. [source](dev-journal/2026-08-12.md)
- **Probe the live DOM to verify a layout claim** when the local server can't reach the database — cheap and decisive against real content and fonts. [source](dev-journal/2026-08-12.md)
- **A failing test can be the most precise handoff** — a deliberately red existence check let the user drop in a file mid-turn with no discussion needed. [source](dev-journal/2026-08-13.md)
- **Journal notes age out of truth** — a July entry about DB-hitting 404 probes was cited as current evidence and had stopped describing the build. [source](dev-journal/2026-08-17.md)
- **A journal bullet that contradicts itself is worth more attention than one that is merely wrong** — self-contradiction inside a single entry is a cheap signal to re-derive. [source](dev-journal/2026-08-21.md)
- **Check the client/server boundary before deciding where a helper lives** — one of `format.ts`'s ~40 importers is a client component, ruling out the smaller-diff option for a markdown-aware rewrite. [source](dev-journal/2026-08-24.md)
- **A test can fail because the test is wrong — check that first** — two apparent code bugs this session were actually invalid CommonMark fixtures. [source](dev-journal/2026-08-24.md)
