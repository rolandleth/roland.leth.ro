## Learnings

- **`rg -r` is `--replace`, not "recursive"** — silently rewrote matches, making normal code look wrong; suspect the command before the code when `rg` output contradicts project convention. [source](dev-journal/2026-08-12.md)
- **Probe the live DOM when the local server can't run** — forcing candidate styles onto the real page and remeasuring `scrollWidth` proved a layout fix against real content and fonts, which no unit test can do. [source](dev-journal/2026-08-12.md)
- **State the measurement conditions with the measurement** — reporting overflow as affecting "every project page" dropped a 375pt qualifier and read as false on a 393pt+ phone. [source](dev-journal/2026-08-12.md)
- **Ran an unsanctioned command and got stopped** — `yarn tsx`, when CLAUDE.md lists exactly four sanctioned command shapes; also wrote a throwaway script into `scripts/` instead of the scratchpad. [source](dev-journal/2026-08-13.md)
- **"Fix them" doesn't extend to a question asked after it** — built the generated OG card while an explicit either/or (generated vs. static) was still unanswered. [source](dev-journal/2026-08-13.md)
- **Recommend against your own finding when the fix is worse than the gap** — flagged `verifySession` as needing `cache()`, then walked it back once the actual gain/cost was weighed; the user accepted the reversal. [source](dev-journal/2026-08-13.md)
- **A failing test can be the most precise handoff** — wrote `defaultOgImage`'s existence check red on purpose; the user dropped in the PNG and it went green with no discussion. [source](dev-journal/2026-08-13.md)
- **Verify a lint rule actually fires** — wrote and deleted a probe page to confirm two new `no-restricted-syntax` errors trigger; `yarn lint` passing alone proves nothing. [source](dev-journal/2026-08-13.md)
- **Check the traffic assumption before pricing a caching tradeoff** — dismissed `revalidate=3600`'s cost as free "in idle hours"; a site with crawlers/feed readers has no idle hours, so the real cost was ~72 guaranteed regenerations/day. [source](dev-journal/2026-08-15.md)
- **A static route cannot run a read-time filter** — this single fact explained why the feed/archive/sitemap needed `revalidate`, why the blog list needed the cron, and why the padded-superset trick had to go. [source](dev-journal/2026-08-15.md)
- **Anchoring on preserving an existing mechanism can invent complexity that doesn't exist** — worried a rewrite was delicate over offset arithmetic that only mattered if the old read-time filter was kept; filtering in SQL made the problem disappear. [source](dev-journal/2026-08-15.md)
- **Route segment config is compile-time** — `export const revalidate` is statically analyzed, so no runtime-computed revalidation window is expressible. [source](dev-journal/2026-08-15.md)
- **Worktrees in this project have no `node_modules`** — symlinking is denied; use a plain branch in the main checkout unless deps are installed per worktree. [source](dev-journal/2026-08-15.md)
- **Flat-config severity-only means "keep the old options," not "clear them"** — `yarn lint --print-config <file>` is the fastest way to see what a block actually did. [source](dev-journal/2026-08-15.md)
- **Verify a contract test fails before trusting it** — `adminPageContract.test.ts` passing on first run proved nothing; deliberately breaking two invariants confirmed both actually bite. [source](dev-journal/2026-08-15.md)
- **State an inconsistency instead of quietly resolving it** — told to stop defending against unreachable input in one place, was about to defend against equally unreachable input elsewhere; surfaced the cost argument instead of silently acting. [source](dev-journal/2026-08-15.md)
- **A rename can be a type-level bug detector** — renaming `getSessionSecret` to `getSessionSecretKey` immediately surfaced two call sites resolving to the wrong version. [source](dev-journal/2026-08-15.md)
- **Ask before reaching for an unsanctioned command, even a plausible one** — ran `yarn tsx` then `node --import tsx` to probe rendering; the user stopped the second one. [source](dev-journal/2026-08-15.md)
- **Distinguish "the tests pass" from "the mechanism works"** — `bypassId` tests prove `cache()` doesn't throw outside a render, not that two guards in one request actually share an id. [source](dev-journal/2026-08-15.md)
- **Structural reasoning was wrong every time; artefacts were right every time** — four confident claims about framework rendering/caching behavior failed; every correct conclusion came from reading a build artefact or probing directly. [source](dev-journal/2026-08-17.md)
- **`.next/server/app/**/*.meta` is the cheapest diagnostic available** — records `"status": 404` only when the status was actually set, localizing this bug class in seconds without a deploy. [source](dev-journal/2026-08-17.md)
- **The route that worked was the clue** — guides was the only detail route returning a real 404; dismissing that outlier as unexplained nearly cost the root cause. [source](dev-journal/2026-08-17.md)
- **Journal notes age out of truth** — a July entry describing framework behavior was treated as current evidence and had stopped describing the build; date-stamped framework observations need re-verification, not citation. [source](dev-journal/2026-08-17.md)
- **`curl -I` sends HEAD, handled on a different path than GET** — misled an early probe; use `curl -o /dev/null -w "%{http_code}"` instead. [source](dev-journal/2026-08-17.md)
- **A build that predates a revert will happily test the reverted code** — cost one confusing 500 misattributed to a live bug rather than a stale binary. [source](dev-journal/2026-08-17.md)
