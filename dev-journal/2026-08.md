## Learnings

- **Structural reasoning about framework behavior was wrong every time this session; build artefacts were right every time** — four confident mechanism claims about Next.js failed in the same session; `.next/server/app/**/*.meta` proved the cheapest reliable diagnostic. When a claim is about framework internals, probe before asserting. [source](dev-journal/2026-08-17.md)
- **Check the traffic assumption before pricing a caching tradeoff** — dismissed `revalidate = 3600`'s cost as negligible "in idle hours," but with crawlers and feed readers polling continuously the site is never idle; the discount was imaginary. [source](dev-journal/2026-08-15.md)
- **A static route cannot run a read-time filter** — this single fact explained why the feed/archive/sitemap needed `revalidate` while the blog list didn't, and why the padded-superset trick had to go once the list was prerendered. [source](dev-journal/2026-08-15.md)
- **A regex over source text is a standing liability, not a one-time bug** — `hasGenerateMetadataExport` was already a rewrite of a prior regex failure; the replacement regex for a different check failed the same way (nested braces) within the same session. The durable fix both times was leaving source-text matching entirely. [source](dev-journal/2026-08-21.md)
- **Verify an automated review's claims before relaying them, even the alarming ones** — a review's top finding (edit pages unguarded) was confirmed by reading the actual page body before reporting it as real; a lower-confidence finding in the same review needed full re-derivation before being trusted. [source](dev-journal/2026-08-21.md)
- **Ask before reaching for an unsanctioned command, even a plausible one** — `yarn tsx` (08-13) and later `node --import tsx` (08-15) were both run outside the project's four sanctioned command shapes; the user stopped the second one. [source](dev-journal/2026-08-13.md)
- **Pseudonymized is not anonymous when you hold the key** — verified against the Redis library source rather than design intent: the rate-limit bucket key outlives its own TTL on whatever schedule the host retains logs. [source](dev-journal/2026-08-21.md)
- **Framer Motion ignores `prefers-reduced-motion` by default** — `MotionConfigContext` ships `reducedMotion: "never"`; every `motion` component opts out until something explicitly opts in. [source](dev-journal/2026-08-21.md)
- **Check the client/server boundary before deciding where a helper lives** — `src/lib/utils/format.ts` looks like a neutral util module, but one of its ~40 importers is a `"use client"` component; that single fact ruled out the smaller-diff placement for markdown-aware truncation. [source](dev-journal/2026-08-24.md)
- **Explaining a workaround is a good moment to check whether it's needed** — two escaping conditionals existed only because of an upstream choice to rebuild definition lines from parsed fields; being asked to explain them surfaced that mdast already carries source offsets, deleting both the conditionals and the reasoning behind them. [source](dev-journal/2026-08-24.md)

### Watch-outs & Tech Debt

- **`stripComments` (`src/test/sourceText.ts`) is a naive scanner, not a tokenizer** — doesn't know about string/template/regex literals. Its own docblock claims every failure mode is a safe false-positive; **code-reviews/2026-08-23.md found that's wrong for two of its three callers** (the `searchParams` presence check and the admin await guard both have a false-negative path via block comments). Fix pending. [first flagged: 2026-08-22]

- **`makeBlogPageCache` reads `getSectionPageCount` from inside its own `unstable_cache` callback** — one cache entry reading another. A warm page entry can serve a `totalPages` frozen at its own last generation while `isRealPage` reads the count entry's current value; `BlogPostList`'s restored empty-page guard is the backstop. Revisit if a third reader of the page count appears. [first flagged: 2026-08-22]
- **`src/lib/utils/format.ts` is imported by a client component** — `src/components/admin/PostForm.tsx` carries `"use client"`, so anything added to `format.ts` ships to the browser. Trigger: any time a formatter needs to become markdown-aware, put it in `src/lib/content/markdown.ts` instead. [first flagged: 2026-08-24]
- **`PostCard` parses each post body three times** — `truncateBody`, `extractDefinitions`, then the render. Build-time only while the list routes stay static. Revisit if a list route ever goes dynamic. [first flagged: 2026-08-24]
