## Session 1

### Decisions

- **Project status** — a `ProjectStatus` enum (`comingSoon`, `live`, `discontinued`) replaces `isDiscontinued` (rejected an `isComingSoon` boolean: allows a both-true row, and every renderer reads two flags). Data carried over by hand-written SQL before `db:push`, the 2026-10-03 pattern.
- **Placement** — only `discontinued` moves a project (to More projects); a coming-soon one keeps its prominence and its `sortOrder` place. `discontinuedLast` sorts in code, because ordering by `status` in Prisma would also move coming-soon projects.
- **Coming-soon commerce** — links render as bare pills (no badge, no "Download on", no store note); prices show on the page when configured; JSON-LD drops `offers`, since `ItemAvailability` has no "not released" value and `PreOrder`/`PreSale` claim it can be ordered; `llms.txt` lists live projects only.
- **Automatic pricing note** — "The App Store shows yours." shows only beside a store button; "US prices." shows whenever there are USD prices (rejected tying either sentence to pricing alone: the App Store half needs a listing).
- **Disclaimer placement** — the product page shows `disclaimer` in the hero under the summary, and no longer at the foot (rejected a note after the hero and moving the "What Digest doesn't do" section up).
- **Continuum terms** — "What Continuum is" replaces "as is, without warranties" (not binding on EU/UK consumers for paid features, per the medical-claims review); the contact line says "contact me" to match the first-person body.
- **Digest stand-in images** — one iPad App Store frame per image, centred on its ground at 2540 × 1520 with `stitch-frames.swift` (rejected iPhone + iPad pairs: two copies of the same headline; iPhone alone: smaller text).
- **Digest pivot** — after the "Digest — Medical-Claims & Liability Review" doc, Roland chose: no guided tests in the shipped app (kept behind a debug flag), no labels (suspect, fine so far, watching), and Insights shows per-symptom counts with and without each food in one fixed format (rejected raw co-occurrence counts: they rank the most-eaten foods first).

### Tradeoffs

- **The pivot** — removes the medical-device question and most liability exposure; gives up the ranked shortlist and the tests that set Digest apart, and weakens the case for its price ($39.99 a year is above Bearable). Reversibility: moderate (the tests stay in code).
- **One terms clause for the strictest regime** — EU/UK-valid wording costs some US protection that a conspicuous "as is" would have kept. Reversibility: easy.

### What did I, Claude Code, or my agents learn from this

- **The dev database isn't reachable from the sandbox** — Postgres.app rejects the sandboxed dev server with "trust" authentication, so pages that query the database 500 in the preview. Static pages render fine; database-backed checks need Roland's own `yarn dev`.
- **Validate a manifest with the import's dry run** — `yarn run db:import-projects <slug> --dry-run` runs the field, placeholder and schema checks and loads every image, with no database or Blob credentials. Use it instead of a hand-rolled `tsx` check.
- **Env-dependent suites in a worktree** — pass `NEXT_PUBLIC_SITE_URL` and a dummy `DATABASE_URL` on the command line (`env … vitest run`); no `.env` file needs reading.
- **claude.ai docs are readable** — the docs connector's `read` takes a claude.ai artifact link's id; read the outline first, then `view` lists and tables and `search` for paragraphs.
