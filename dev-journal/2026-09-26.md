## Watch-outs & Tech Debt

- **Post importer still normalizes an explicit non-canonical `slug:`** — `resolveSlug` in `src/lib/import/postImport.ts` runs `createSlug` on it and writes the result back, while the admin forms and guides reject a non-canonical slug. Revisit if a normalized value ever collides with an existing post.
- **Project and post slugs have no rename path** — both update schemas strip `slug`; a real rename is a manual DB change, plus rewriting `projectSlug` on guides and topics, with no redirect. Guide and topic slugs stay editable (pre-existing policy). Revisit if a rename is ever needed.
- **`ImageUpload` reports `false` twice when an upload ends** — the effect cleanup and the effect body both call `onUploadingChange(false)`. Receivers must stay idempotent (`useUploadTracker`'s keyed set, `PostForm`'s setter). Revisit if a receiver ever counts reports.
- **`NO_SCRIPT_FADE_RULE` depends on Framer's SSR output** — it overrides the inline `opacity:0` Framer prerenders for `fadeUp` elements; `motion.test.ts` renders a `motion.p` to static markup to pin that. Revisit on a framer-motion major upgrade. It does not help when JavaScript fails to load or with LCP (the CSS-keyframe option was not taken).
- **`CANONICAL_SLUG_SOURCE` doubles as an HTML `pattern`** — browsers compile `pattern` with the `v` flag. Revisit if the pattern ever gains characters that need escaping under `v`.

### What did I, Claude Code, or my agents learn from this

- **Search call sites by bare name, not `name(`** — a generic call (`useOrderedList<T>(`) slips past a `name\(` pattern. Search the bare identifier, and let `yarn tsc --noEmit` confirm.
- **Scheduled-run sessions can't start dev servers** — `preview_start` refuses in unattended sessions even after the user starts talking; browser checks have to be handed to Roland.
- **Truncated vitest output** — run with `--reporter=json --outputFile=<scratchpad>` and `rg` the report for `"status":"failed"` instead of chaining shell commands (hooks block pipes and several flag shapes).
- **Hook-blocked command shapes** — `rg --files -g …`, `rg -g`, `--glob`, `git -C`, and a redirect command that matched the `tr` guard. Use plain `ls`/`rg` patterns.
