## Session 1

### Decisions

- **Carousel aspect-ratio reset** — reset to the `h-120` fallback only on invalid `onLoad` dimensions and on `onError`, not on every image change. Rejected reset-on-change (the reviewer's literal suggestion) because it forces an `h-120` reflow on every valid→valid swipe; `onError` covers the true broken-image case that never fires `onLoad`.
- **`JsonLdScript` prop tightened to `Record<string, unknown> | null`** — `undefined` is no longer a "render nothing" input; it now surfaces (throws via `safeJsonLdString`). Aligns with that function's existing throw-on-undefined design and the no-silent-suppression rule. Rejected keeping `unknown` + swallowing undefined.
- **Nav-tracker idempotency stays in the module** — kept `isInstalled` as the single guard; declined a dev-only `console.warn` on repeat install because React StrictMode's double-invoke would make it noise. Component re-installs per mount by design; the module absorbs it.
- **CCBot rule `$`-anchored** for exact-path blocking (see Watch-outs).
- **`import-projects.ts` `prisma!` → explicit guard** — replaced the non-null assertion with a real `if (prisma === null) throw` after the dry-run early-return, so a future reorder can't pass null into the transaction.

### Tradeoffs

- **`llms.txt` filters discontinued projects** — gained: LLMs can't cite dead apps as live. Cost: discontinued apps are absent from the agent overview entirely (they were sorted-last before). Reversibility: easy.
- **Serializable import without retry** — documented the no-retry rationale (single-admin, re-run is the recovery) and the orphaned-blob tradeoff (blobs uploaded before an abort linger until a later `pruneOrphans`). Added a distinct `P2034` log branch so a real conflict isn't triaged as a manifest typo.

### Incidents / Bugs

- **Offer NaN guard missed `Number("") === 0`** — the Phase 1 guard (`!Number.isFinite(Number(price))`) let an empty/whitespace price through as `0`, which would emit an `AggregateOffer` with an empty-string `lowPrice`. Caught while writing the negative test; tightened to reject `trimmed === ""` before the finite check.
- **Existing FAQ-fallback test passed for the wrong reason** — `ProjectContent` is mocked to `null`, so its `container.textContent` assertion only passed because the FAQ answer is embedded in the FAQPage JSON-LD, not because the fallback `<p>` rendered. Strengthened both the FAQ and the new section-fallback tests to assert the structured `console.error` payload shape (`projectSlug`/`faqId`/`sectionId`/`reason`).

### What did I, Claude Code, or my agents learn from this

- **Write the test from the logic, and it catches the impl gap** — the empty-string price bug surfaced only because the test asserted the intended behaviour rather than mirroring the code. Direct validation of the CLAUDE.md rule.
- **`AnimatePresence` keeps a dialog mounted through its exit animation** — asserting `queryByRole("dialog")` is gone after `isOpen=false` fails. Assert the side effects that run on effect cleanup (focus restore, `overflow` restore) instead of DOM removal.
- **A `textContent` assertion can pass via an unrelated mechanism** — when the same string is embedded elsewhere (JSON-LD here), the test proves nothing about the code path it names. Assert the specific mechanism (the structured log), not incidental text.
