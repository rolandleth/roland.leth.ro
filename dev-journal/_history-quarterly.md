- **2026-04-20 — 500 on `/api/feed/tech`** — `TypeError: Date.getTime()` on `unstable_cache` hit; JSON-serialization turns Prisma `DateTime` into strings. Fixed: normalize inside cached fn. Pattern now codified as a project convention. [source](dev-journal/2026-04.md)
- **2026-05-07 — Edit-page tests had never run** — `vitest.config.ts` glob excluded `src/app/**/*.test.tsx`; two existing tests silently skipped. Fixed: widened glob. [source](dev-journal/2026-05.md)
- **2026-05-11 — `legacySlug.cachedLookup` missed future-dated filter** — added `datetime <= now` to `getPostBySlug` etc but legacy-slug lookup only filtered `published: true`; future-dated published post 308-redirects to a canonical page that 404s. [source](dev-journal/2026-05.md)

The watch-out's explicit trigger ("code-review on any new top-level page") fired on the pre-existing file. [source](dev-journal/2026-05.md)
- **2026-05-17 — Optimistic-toggle revert used stale baseline** — `onRevert` captured first-render `initial` prop; after successful toggle + `router.refresh()`, a subsequent failed toggle reverted to the now-stale value. Fix: `const prev = isOn` before `setIsOn(next)`. [source](dev-journal/2026-05.md)
- **2026-05-18 — Session lockout from `cd src/lib`** — changing directory mid-session caused `.claude/hooks/` relative path to resolve incorrectly, blocking tool calls. User restarted session; no data lost. [source](dev-journal/2026-05.md)
- **2026-06-08 — `scripts/` wholly gitignored** — root `.gitignore` `scripts/` line prevented `import-projects.ts` from being committed; `db:import-projects` would fail on a fresh clone. Fixed: narrowed to `scripts/imports/`. [source](dev-journal/2026-06-08.md)
- **2026-06-26 — Corner-halo misdiagnosed twice** — first attributed to backdrop opacity (`/80`→`/95`, no effect), then to `backdrop-filter` fringe (opaque backdrop helped but didn't fix). Actual cause: `object-contain` letterboxing means container `rounded-xl` never touches the visible image. Fixed by aspect-true sizing. Lesson: when a visual artifact appears in two surfaces sharing identical image rendering, suspect the shared render path, not the differing wrapper. [source](dev-journal/2026-06-26.md)
- **2026-06-28 — FAQs in DB but not on the page** — `import-projects.ts` writes via Prisma outside Next runtime, so `revalidateTag` can't be called; `getProjectBySlug`'s `unstable_cache` has no TTL. Fix: clear `.next`. Pattern recurs on every import until a revalidation hook exists. [source](dev-journal/2026-06-28.md)
- **2026-06-29 — SSR `ReferenceError` in inline Navigation API cast** — first draft read `window` before the `typeof window === "undefined"` guard; would throw during server rendering. Caught immediately; reordered so guard runs first. [source](dev-journal/2026-06-29.md)
