## Decisions of note

- **2026-04-26 — `SESSION_SECRET` hex-regex reverted, `ADMIN_HASH_PASSWORD` kept it** — the CLAUDE.md note "JWT signing secret (hex-encoded)" was a stale usage claim; actual consumption is `TextEncoder().encode()`, not `Buffer.from(hex)`. Alternative (validate at consumer site) rejected as redundant. [source](dev-journal/2026-04-26.md)
- **2026-05-11 — Scheduled publishing v1: `now` captured inside cached functions** — cascaded a `datetime <= now` filter across `getPostBySlug`, sitemap, `generateStaticParams`; accepted that scheduled posts wouldn't auto-surface. Reversed 2026-05-14. [source](dev-journal/2026-05.md)
- **2026-05-12 — Posts PUT escalated to Serializable isolation** — closes a cross-section cache-invalidation race; `serialization_failure → 500` accepted as non-client-retriable at single-admin volumes. [source](dev-journal/2026-05.md)
- **2026-05-14 — Scheduled publishing v2: read-time filter over cached `now`** — reversed 05-11; cache stores rows time-independently, the wrapper applies fresh `now` per request, paginated caches pad with `LIMIT + futureCount`. Alternative (keep write-time filtering) rejected — it can't auto-surface a scheduled post without a cron. [source](dev-journal/2026-05.md)
- **2026-05-14 — `IP_HASH_SECRET` HMAC-SHA256 for rate-limit buckets** — plain IP hashing is reversible (IPv4 keyspace ~4B); HMAC with a server-held secret blocks rainbow-table precomputation. Rate-limit gate fails open only if both Redis and the secret are missing. [source](dev-journal/2026-05.md)
- **2026-05-18 — `Post.summary` changed to `String NOT NULL`** — `deriveSummary(body)` derives on write; edit-route resolution (authored→keep, cleared→re-derive, body-changed-untouched→re-derive, unchanged→skip). No backfill was committed alongside the schema change — a deliberate deploy-order risk. [source](dev-journal/2026-05.md)
- **2026-05-18 — `src/lib/` reorganized into 6 semantic buckets** (`db/`, `auth/`, `api/`, `content/`, `client/`, `utils/`) in one commit (`8d8fa8b`, 140 files, 220 import paths) — atomic to avoid intermediate broken-import states. [source](dev-journal/2026-05.md)
- **2026-06-08 — Manifest-driven importer: `project.json` + direct Prisma + direct Blob** — chosen over an admin HTTP API (needs a live server, random blob keys, slug-shift risk) and raw-markdown parsing (no stable schema). [source](dev-journal/2026-06.md)
- **2026-06-28 — FAQ render is an always-in-DOM accordion with `inert`**, not `AnimatePresence` conditional-mount — conditional-mount would exclude collapsed answers from SSR HTML, defeating the SEO/AI-citation goal; `inert` keeps them out of the a11y tree/tab order while staying crawlable. [source](dev-journal/2026-06-28.md)
- **2026-06-29 — JSON-LD origin moved to `siteBase()`, reversing 06-28's hardcoded `SITE_ORIGIN`** — aligns with the existing sitemap/feed/layout convention after the user flagged the pre-existing helper; accepted that preview deploys now emit the preview host (low-risk, previews are `noindex`'d). [source](dev-journal/2026-06.md)
- **2026-07-06 — `.md` blog-post route via a middleware rewrite to a separate route handler** — forced because Next dynamic segments can't carry a file extension (`[slug].md` is invalid) and a `page.tsx`/`route.ts` can't coexist at one path. [source](dev-journal/2026-07-06.md)
- **2026-07-07 — Cut Vercel CPU by making content pages static** — `unstable_cache` spared the DB but not per-request compute; removing `cookies()` (theme→localStorage) and `headers()` (origin→env) let the Full Route Cache take over. [source](dev-journal/2026-07-07.md)
- **2026-07-17 — New `Guide` entity over `Post` reuse; guides live at top-level `/guides/:slug`** — `Post` carries legacy shape (string `datetime`, feed/archive/search, frozen-after-publish lifecycle) guides shouldn't inherit; guides are maintained SEO pages, not a dated stream. [source](dev-journal/2026-07-17.md)
- **2026-07-17 — Catch-all `[slug]` stays in-memory, no DB fallback, even though DB awaits aren't Fluid-billed** — a DB fallback would re-expose Postgres to unbounded bot traffic (connection exhaustion / DoS amplification); reframed "I/O isn't billed" away from "move work to the DB". [source](dev-journal/2026-07-17.md)
- **2026-07-19 — IndexNow submission runs from a session-gated admin endpoint, not a local script** — guarantees `getSiteUrl()` resolves the real prod origin and the DB is prod; a local `tsx` script would need `vercel env pull` and risk announcing localhost. [source](dev-journal/2026-07-19.md)
- **2026-07-20 — `INDEXNOW_KEY` format validation moved out of the env schema** — reverses the 07-19 choice: `readEnv()` aggregates every schema issue into one throw, so a regex on an optional single-feature var took down login, cron auth and site-URL resolution over a typo. Now `isValidIndexNowKey` + `describeKeyProblem` at the single route that needs it; rejected letting IndexNow 403 instead, which surfaces the error far from its cause. [source](dev-journal/2026-07-20.md)
- **2026-07-20 — IndexNow deploy-config gaps return 503, empty URL sets 422** — a missing/malformed key and a non-public origin are properties of the deploy, not the request, matching `keepalive`'s existing 503; rejected the original 400s, which imply the caller can fix it by sending something different. [source](dev-journal/2026-07-20.md)
- **2026-07-20 — Deferred `requireAdminSession()` across all 12 admin routes** — middleware is currently the sole auth boundary; vendor guidance is against that and CVE-2025-29927 bypassed the pattern framework-wide (patched 14.2.25 / 15.2.3; repo is on Next 16.2.10). Judged its own piece of work rather than an IndexNow-branch change. [source](dev-journal/2026-07-20.md)
