# Rolling History — last 90 days (through 2026-07-27)

## Themes

- **Code-review-driven implementation cadence** — Established 2026-05-07 (daily review → phased implementation → commit-per-phase, `tsc`/lint/tests green at every boundary) and held as the default operating mode all quarter. May ran the heaviest volume — 2026-05-11 alone burned three full-codebase reviews into three implementation passes (24 commits, 980 tests). June's 2026-06-29 five-subagent review (data layer, FAQ, gallery/carousel, navigation, SEO/JSON-LD) fed directly into the JSON-LD hardening below. July ran nearly one review per session across 07-17 through 07-21 (guides feature → guides review → IndexNow feature → IndexNow review → review-of-the-review), each resolved same-day or next-day with explicit fix/defer/skip-with-reason dispositions rather than reflexive fixing. [source](dev-journal/2026-05.md) [source](dev-journal/2026-06.md) [source](dev-journal/2026-07-18.md)

- **Data freshness: scheduled publishing → cache-tag granularity → honest reporting** — 2026-05-11 first filtered future/draft posts by capturing `now` inside cached functions, accepting scheduled posts wouldn't auto-surface; reversed 2026-05-14 to a read-time filter with padded caches (`LIMIT + futureCount`) so a scheduled post surfaces on the first request after its `datetime`, no cron needed. 2026-06-28/29 exposed that direct-Prisma imports can't call `revalidateTag`, leaving `unstable_cache` stale until a manual `.next` clear. 2026-07-07 split the coarse `blog-{section}`/`projects` tags into per-slug detail tags after an ISR dashboard showed 8 blind writes on an unedited page; 2026-07-17 a real incident landed — a published post durably cached a pre-existing `null` and 404'd — fixed via `CacheMissError` throw-on-miss across all four detail lookups. The identical failure mode (a success report that doesn't reflect what was actually verified) then reappeared independently in IndexNow's submit-count reporting (07-20: "submitted: N" even when every batch 403'd), closed 07-21. [source](dev-journal/2026-05.md) [source](dev-journal/2026-07-07.md) [source](dev-journal/2026-07-17.md)

- **Manifest-driven project import pipeline** — Built 2026-06-08 (`project.json` + direct Prisma + direct Blob, chosen over an admin HTTP API needing a live server and random blob keys, and over raw-markdown parsing with no stable schema); hardened 06-10 (content-addressed SHA256 blob keys) and 06-13 (list pagination, bounded-concurrency uploads, post-import orphan pruning, a pure `blobSync.ts` DI extraction). 2026-06-28 exposed the structural gap this hardening left standing: `scripts/import-projects.ts`'s own untested `writeProject`/`referencedImageUrls` silently dropped new `cardImage`/`ogImage` fields because the pure `src/lib/import/projectImport.ts` core wasn't touched — and it's the reason 2026-07-17's guides design deliberately referenced projects by slug string rather than FK, since the importer's delete-then-create transaction would otherwise cascade-delete guides on every project reimport. [source](dev-journal/2026-06.md) [source](dev-journal/2026-06-28.md) [source](dev-journal/2026-07-17.md)

- **SEO / structured-data buildout** — June built the FAQPage + SoftwareApplication JSON-LD layer (flat `offers` array, manifest-driven `applicationCategory`, an always-in-DOM + `inert` FAQ accordion), then `robots.ts` (allow-all incl. AI-citation crawlers) and a DB-driven `/llms.txt`, then `BlogPosting` JSON-LD closing the projects-only structured-data gap — all converging 06-29/07-05 onto a single `JsonLdScript` embedding chokepoint. July extended the surface: guides (07-17) as an entirely new top-level SEO content type with prose-only product disclosure instead of a card; IndexNow (07-19) for direct search-engine submission; and feed autodiscovery + Atom-validity fixes (07-24, see below). [source](dev-journal/2026-06.md) [source](dev-journal/2026-07-17.md) [source](dev-journal/2026-07-19.md)

- **Admin security hardening** — 04-26's code review fixed a misapplied hex-format regex on `SESSION_SECRET` (traced to a stale CLAUDE.md usage note rather than the actual `TextEncoder().encode()` consumer) and added a typed `EnvConfigError` plus a module-load dummy-bcrypt timing defense. May extended this with `IP_HASH_SECRET`-HMAC-pseudonymized rate-limit buckets (GDPR *Breyer* rationale: plain SHA-256 of an IPv4 is brute-forceable in minutes), magic-byte upload MIME sniffing, and `sanitizeLogString` closing a log-injection vector. July closed the loop on the auth boundary itself: 07-17 fixed a latent `isAdminPage` prefix over-match; 07-20 flagged, and deliberately deferred, that middleware is the sole authorization boundary for all 12 admin routes — against Vercel's own guidance, with the `x-middleware-subrequest` CVE (2025-29927) as precedent; 07-26 turned that deferred risk into a fixed one when the matcher's unanchored extension-exclusion group turned out to let any path containing an excluded extension's substring (a `.json` path contains `.js`) bypass the gate — closed with an anchored matcher plus a `requireAdmin()` second lock on all 21 handlers, plus a 32-character `SESSION_SECRET` floor. [source](dev-journal/2026-04.md) [source](dev-journal/2026-05.md) [source](dev-journal/2026-07-26.md)

- **Gallery/lightbox UX and gesture engineering** — June lifted gallery position to `ProjectContent` (a single index drives dots, tabs, and the lightbox), fixed image rounding by sizing to the image's true aspect ratio instead of the letterboxed container, and progressively stripped navigation animations while adding Navigation-API-gated back/forward entrance suppression. July rebuilt the gallery as a continuous cross-section strip with a hand-rolled pointer-event lightbox zoom (rejecting `@use-gesture/react` and off-the-shelf lightboxes), shipping two framer-motion timing bugs the same day it launched (07-07) — corrected 07-08 once `onDragEnd`'s actual timing relative to the browser's `click` was understood, and once a `key`-driven remount of the carousel subtree on cross-section swipes was traced and removed. [source](dev-journal/2026-06.md) [source](dev-journal/2026-07-07.md) [source](dev-journal/2026-07-08.md)

- **Atom feed: quality build-out, then discoverability and validity fixes** — April built the feed's rendering quality: `stripMarkdown` via AST walk for `<summary>` blurbs, mdast-typed image alt-text extraction, a CDATA-terminator escape helper, and `updatedAt` normalized to an ISO string inside the cached function after a production 500 from calling `.getTime()` on a cache-hit string. Three months later, 2026-07-24 found the feed itself had regressed to invisible and invalid during the Express→Next migration: no `<link rel="alternate">` anywhere on the site, a missing feed-level `<author>` (RFC 4287 non-compliant), dropped `<subtitle>`/`<icon>`/`<rights>`, and a stale `<updated>` keyed off authoring-edit time rather than publish time. Fixed across four commits, then made static (`force-static` + `revalidate=3600`) to close a CDN-purge gap a hand-set `Cache-Control` header could never satisfy. [source](dev-journal/2026-04.md) [source](dev-journal/2026-07-24.md)

- **May engineering-quality sweep** — A concentrated week (05-11 through 05-18) invested in infrastructure the rest of the quarter built on: `useOptimisticMutation` extracted at its 2nd consumer (exposing a real unmount-after-resolve race, fixed by nulling the abort ref in cleanup), admin audit logging unified under a typed `AdminAuditTag` union with a `batchId` for bulk runs, an a11y sweep (carousel APG pattern, a skip-link, `<time dateTime>` corrected to real ISO 8601 after two prior reviews missed it, `<main>` hoisted to the root layout), a 47% test-suite speedup, and a `src/lib/` reorganization into six semantic buckets (`db/`, `auth/`, `api/`, `content/`, `client/`, `utils/`) in one 140-file commit. [source](dev-journal/2026-05.md)

## Decisions of note

- **2026-04-26 — `SESSION_SECRET` hex-regex reverted, `ADMIN_HASH_PASSWORD` kept it** — the CLAUDE.md note treated as a stale usage claim rather than a contract; actual consumption is `TextEncoder().encode()`, not `Buffer.from(hex)`. [source](dev-journal/2026-04.md)
- **2026-05-11 — `getPostBySlug` switched `findUnique` → `findFirst`** — adding a `published`+`datetime<=now` filter requires a non-unique-constraint query shape. [source](dev-journal/2026-05.md)
- **2026-05-12 — Posts PUT escalated to Serializable isolation** — closes a cross-section cache-invalidation race; the resulting `serialization_failure → 500` is accepted as non-client-retriable at single-admin volumes. [source](dev-journal/2026-05.md)
- **2026-05-14 — `IP_HASH_SECRET` HMAC-SHA256 for rate-limit buckets** — plain IP hashing is reversible (IPv4 keyspace ~4B); HMAC with a server-held secret blocks rainbow-table precomputation. [source](dev-journal/2026-05.md)
- **2026-05-14 — Scheduled publishing reversed to a read-time filter** — cache stores rows time-independently; the wrapper applies fresh `now` per request. Rejected keeping write-time filtering, which can't auto-surface a scheduled post without a cron. [source](dev-journal/2026-05.md)
- **2026-05-18 — `Post.summary` changed to `String NOT NULL`, no backfill committed** — a deliberate deploy-order risk: `db:push` must run only after every existing NULL row is backfilled. [source](dev-journal/2026-05.md)
- **2026-05-18 — `src/lib/` reorganized into 6 semantic buckets in one commit** (`8d8fa8b`, 140 files, 220 import paths) — atomic, to avoid intermediate broken-import states. [source](dev-journal/2026-05.md)
- **2026-06-08 — Manifest-driven importer: `project.json` + direct Prisma + direct Blob** — chosen over an admin HTTP API (needs a live server, random blob keys, slug-shift risk) and raw-markdown parsing (no stable schema). [source](dev-journal/2026-06.md)
- **2026-06-28 — FAQ render is an always-in-DOM accordion with `inert`, not `AnimatePresence` conditional-mount** — conditional-mount would exclude collapsed answers from SSR HTML, defeating the SEO/AI-citation goal. [source](dev-journal/2026-06-28.md)
- **2026-06-29 — JSON-LD origin moved to `siteBase()`, reversing 06-28's hardcoded `SITE_ORIGIN`** — aligns with the existing sitemap/feed/layout convention; accepted that preview deploys now emit the preview host (low-risk, previews are `noindex`'d). [source](dev-journal/2026-06.md)
- **2026-07-06 — `.md` blog-post route via a middleware rewrite to a separate route handler** — forced because Next dynamic segments can't carry a file extension and a `page.tsx`/`route.ts` can't coexist at one path. [source](dev-journal/2026-07-06.md)
- **2026-07-07 — Cut Vercel CPU by making content pages static** — `unstable_cache` spared the DB but not per-request compute; removing `cookies()` (theme → localStorage) and `headers()` (origin → env) let the Full Route Cache take over. [source](dev-journal/2026-07-07.md)
- **2026-07-17 — New `Guide` entity over `Post` reuse; guides live at top-level `/guides/:slug`** — `Post` carries a dated, frozen-after-publish lifecycle guides don't share; guides are maintained SEO pages, not a stream. [source](dev-journal/2026-07-17.md)
- **2026-07-17 — Catch-all `[slug]` stays in-memory, no DB fallback, even though DB awaits aren't Fluid-billed** — a DB fallback would re-expose Postgres to unbounded bot traffic (connection exhaustion / DoS amplification); reframed "I/O isn't billed" away from "move work to the DB." (Architecture originally built 2026-04-17 as part of the legacy-redirect rethink, reaffirmed here under CPU-optimization pressure.) [source](dev-journal/2026-07-17.md)
- **2026-07-19 — IndexNow submission runs from a session-gated admin endpoint, not a local script** — guarantees `getSiteUrl()` resolves the real prod origin and the DB is prod; a local script would need `vercel env pull` and risk announcing localhost. [source](dev-journal/2026-07-19.md)
- **2026-07-20 — `INDEXNOW_KEY` format validation moved out of the env schema** — reverses 07-19's choice: `readEnv()` aggregates every schema issue into one throw, so a regex on an optional single-feature var took down login, cron auth, and site-URL resolution over a typo. [source](dev-journal/2026-07-20.md)
- **2026-07-20 — Deferred `requireAdminSession()` across all 12 admin routes** — middleware is the sole auth boundary today; vendor guidance is against that and CVE-2025-29927 bypassed the same pattern framework-wide. Judged its own piece of work rather than an IndexNow-branch change. [source](dev-journal/2026-07-20.md)
- **2026-07-26 — `requireAdmin()` second lock added to all 21 admin handlers, plus a `SESSION_SECRET` 32-char floor** — closes the risk 07-20 had deferred; the floor lives in the accessor (`getSessionSecret()`), not the zod schema, following `isValidIndexNowKey`'s precedent. [source](dev-journal/2026-07-26.md)
