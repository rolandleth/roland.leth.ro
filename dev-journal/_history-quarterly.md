- **Scheduled-content correctness and revalidation, from incident to cron to escape hatch** — 2026-07-17 diagnosed a prod stale-404 to a durably-cached `null` and moved all four detail lookups to throw-on-miss (`CacheMissError`) instead of short-TTL caching, while leaving individual tag-bust reliability unproven. 2026-07-24 made the feed route static with hourly ISR, replacing a hand-set `Cache-Control` header a tag bust could never purge from the CDN edge. 2026-08-15 replaced hourly `revalidate=3600` on feed/archive/sitemap with a daily due-check cron and moved blog pagination to static path segments, which caused a production incident on 2026-08-17: a `loading.tsx` Suspense boundary let three routes serve HTTP 200 while streaming the 404 page underneath, found by diffing `.next/server/app/**/*.meta` files. September added a public, ungated `override-preview` escape hatch for previewing scheduled posts by URL and found guide topic hubs never received the due-guide cache bust the cron promised. [2026-07-17](dev-journal/2026-07-17.md), [2026-08-17](dev-journal/2026-08.md), [2026-09-15](dev-journal/2026-09-15.md)
- **Admin auth hardening, layer by layer, all quarter** — 2026-07-26 found the middleware matcher's unanchored asset-extension exclusion let `.json` requests (matching the `.js` substring) skip the admin gate entirely; not exploitable in practice since every admin `[id]` route parsed ids as plain integers, but closed by anchoring the pattern and adding a second lock, `requireAdmin()`, on all 21 handlers. August layered defense repeatedly without ever finishing in one pass: 2026-08-12 closed an unauthenticated DB read in edit-page `generateMetadata`, 2026-08-21 found the fix only guarded page `<title>`s while bodies still rendered unauthenticated data, and 2026-08-22 found the contract test meant to catch exactly that couldn't fail on an unawaited guard call. September closed the remaining gap at the request level: 2026-09-27's CSRF `Origin` check inside `requireAdmin` touched all 21 handlers, and 2026-09-28 found the one route the sweep missed — `/api/auth/login`, which could have let a cross-site page exhaust the admin's own rate-limit bucket. [2026-07-26](dev-journal/2026-07-26.md), [2026-08-21](dev-journal/2026-08.md), [2026-09-28](dev-journal/2026-09.md)
- **Project CTAs evolved into a full product-page and placement model** — 2026-09-13 added an explicit `isOwnApp` boolean on `Project` (rejected deriving it from the free-text `role` field or from hostname alone) plus badge-vs-pill CTA logic keyed on `bucket`. The next day's review found the importer silently reset `isOwnApp` to `false` on re-import (fixed via `assertRequiredFlags`), and that an own app with more than one storefront link rendered the wrong badge (changed to "Download on {label}" pills). By 2026-10-02 this had become a full product-page redesign: required section `kind`/`layout`, per-step galleries, a "Best value" offer flag, and a gallery grouped by featured/own-app flags. 2026-10-03 replaced `isFeatured` and the ownership-driven placement rules entirely with independent `prominence` (high/medium/low) and `pageLayout` (product/portfolio) enums, carried across by one-off SQL before the schema push dropped the old column. ## Decisions of note

- **2026-07-08 — Swipe-vs-tap arbitration** — moved to raw pointer events (`pointerdown`/`pointerup` travel distance) instead of framer's `onDragEnd`, which fires a frame after the browser's click via `postRender`; the prior fix's "deterministic" framing was backwards. [source](dev-journal/2026-07-08.md)
- **2026-07-16 — Slug source of truth** — `slug:` frontmatter made authoritative and self-healing via `createSlug` idempotency, instead of re-deriving from title on every import, which would silently move a retitled post's URL. [source](dev-journal/2026-07-16.md)
- **2026-07-17 — Guides as a new entity** — modeled as `Guide`, not a `Post` subtype; different lifecycle (maintained SEO pages vs. a frozen dated stream) would have added a permanent "not guides" filter to every post query. [source](dev-journal/2026-07-17.md)
- **2026-07-19 — IndexNow as an admin button** — session-gated `POST /api/admin/indexnow`, not a local script, so `getSiteUrl()` always resolves the real prod origin; rejected a local `tsx` script, which risked announcing localhost. [source](dev-journal/2026-07-19.md)
- **2026-07-24 — Feed `<id>` kept stable** — pinned to `/api/feed/:section` as the dedup key while `rel="self"` points at the pretty URL; rejected repointing `<id>`, which would orphan existing subscriptions. [source](dev-journal/2026-07-24.md)
- **2026-08-15 — OG card moved off a live route** — `/og` Satori route replaced by a build script (`yarn og:card`) producing a committed PNG, removing the font-CDN dependency and the unbounded WASM bundle the review flagged. [source](dev-journal/2026-08.md)
- **2026-08-21 — Reduced motion handled globally** — via Framer's `MotionConfig`, not a per-caller hook, which would have missed existing animated components and any future one. [source](dev-journal/2026-08.md)
- **2026-09-16 — Orphaned uploads swept manually** — dry-run-by-default, matching by UUID rather than parsing URLs; rejected a per-write delete and a daily cron. [source](dev-journal/2026-09-16.md)
- **2026-09-23 — Production credentials confirmed in `.env`** — not a separate production env file; new `scriptEnv.ts` centralizes the check across every import/prune script. [source](dev-journal/2026-09-23.md)
- **2026-09-26 — Post and project slugs frozen** — no rename path after creation; chosen over an editable-slug-with-cascade design, trading a hypothetical rename for guaranteed stable URLs into guides. [source](dev-journal/2026-09-26.md)
- **2026-10-02 — "Best value" badge computed, not authored** — a "Save N%" derived from the manifest's own prices; rejected typed savings copy that could drift from the prices. [source](dev-journal/2026-10-02.md)

## Incidents of note

- **2026-07-18 — Guide folder move silently dropped** — `planGuide` diffed content fields but not folder-derived topic membership, so moving a guide to a new topic with byte-identical content never re-resolved it. Fixed by comparing the resolved topic slug too; regression risk low, a test pins it. [source](dev-journal/2026-07-18.md)
- **2026-07-20 — Confidently wrong review finding** — a review subagent claimed the admin API redirects unauthenticated requests to the login page, contradicting its own paired gatherer's evidence; caught before it reached the review file. [source](dev-journal/2026-07-20.md)
- **2026-07-26 — Admin gate skippable via a dotted path** — the middleware matcher's extension exclusion was unanchored, so `.json` matched because it contains `.js`. Not exploitable in practice (admin `[id]` routes parse ids as plain integers); closed with anchored patterns and explicit `/admin*` entries. [source](dev-journal/2026-07-26.md)
- **2026-08-17 — Soft 404 live in production** — a `loading.tsx` Suspense boundary let three routes serve HTTP 200 while streaming the 404 page underneath, since React can commit before `notFound()` sets the status. Fixed by scoping skeletons into route groups; regression risk high and invisible, hence a filesystem guard. [source](dev-journal/2026-08.md)
- **2026-08-22 — Contract test couldn't fail for its own case** — it matched `source.includes("requireAdminPageSession(")`, which an unawaited call also satisfies. Fixed and verified by removing an `await` and confirming only that test failed. [source](dev-journal/2026-08.md)
- **2026-09-15 — Description writes disagreed across five paths** — the Published toggle wiped an authored description, and any body edit re-derived over one. Root-caused to five write paths disagreeing on what counts as "not sent"; fixed behind one resolver. [source](dev-journal/2026-09-15.md)
- **2026-09-26 — Late image upload reverted edits** — the async upload handler closed over a render-time list state and wrote it back, silently undoing a title edit or reorder made while the upload was in flight. Fixed with functional, keyed updates; a regression test holds an upload open across a title edit. [source](dev-journal/2026-09-26.md)
- **2026-09-29 — HEIC accepted as AVIF** — the `mif1` major brand was treated as sufficient AVIF evidence with no compatible-brand check, so a renamed HEIC stored with `contentType: image/avif` and couldn't render. Fixed; the old test pinning `mif1` as valid had been protecting the gap. [source](dev-journal/2026-09-29.md)
