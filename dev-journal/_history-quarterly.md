# Rolling History — last 90 days (through 2026-08-18)

## Themes

- **Project platform model: free text to structured enums** — Over three sessions (05-20 to 05-22), replaced `Project.platform: String` — which had three separate algorithms reverse-engineering structure from prose (regex keyword matching, comma-split membership, prefix/substring normalize) — with a `bucket: PlatformBucket` enum plus `platformTags: PlatformTag[]` enum array, deployed as an additive-then-final two-phase migration with a brief accepted broken window. A same-day incident (a `node:module` chunking failure pulling the full Prisma runtime into client bundles via `platforms.ts`) forced a fix importing enums from `@/generated/prisma/enums` instead of the main client export, cascading across 17 files. Follow-up reviews (05-21, 05-22) added schema-level bucket/tag coherence validation via `superRefine`, dropped a picker's inaccessible hidden sr-only input in favor of an explicit submit-handler guard, and split the gallery reader from the admin reader so caching intent can't drift by flag. - **Manifest-driven project importer, hardened over three sessions** — `scripts/import-projects.ts` progressed from deterministic blob keys (06-08) to content-addressed SHA256 keys (06-10) to paginated blob listing, a DI'd `blobSync.ts`, bounded-concurrent uploads, and post-import orphan pruning (06-13); Reckon and Continuum were imported to prod through it. A `.gitignore` line (`scripts/`) had silently kept the whole importer out of version control until narrowed to `scripts/imports/`, and the importer's hand-copied write logic later proved to diverge from the shared lib whenever a new field was added (surfaced 06-28, when `cardImage`/`ogImage` were dropped at import time). - **Gallery/lightbox gesture engineering** — The continuous cross-section gallery and hand-rolled pointer-event lightbox zoom shipped 07-07 with two gesture bugs fixed same day (swipe-vs-tap arbitration; trackpad pinch-vs-scroll via `ctrlKey`), both revisited 07-08 once the underlying assumption broke: framer-motion's `onDragEnd` fires a frame after the browser's click via `frame.postRender`, so gating suppression on it can never win — fixed by moving to raw `pointerdown`/`pointerup` capture. The same 07-08 session traced an "accelerated" cross-section swipe to a React `key` remounting the whole carousel subtree (resetting its `MotionValue`s). - **Recurring failure mode: success reports that didn't reflect what was verified** — A dual-cache staleness gap on `llms.txt` (later mirrored by the `.md` export route) and coarse `blog-{section}`/`projects` tags that regenerated every sibling page on any edit were split into per-slug plus aggregate tags on 07-07, with an admin RevalidatePanel added so import-script writes could still be busted by hand. The same imprecision resurfaced in guides — a tag-namespace collision fixed 07-18, then found on 07-19 review to still report requested slugs as "revalidated" without checking they matched a real row — and reappeared independently in IndexNow's submit-count reporting ("submitted: N" even when every batch 403'd), finally closed 07-21. - **Admin auth: from single gate to defense in depth** — 07-20's code review flagged, and deliberately deferred, that `src/proxy.ts` middleware was the sole authorization boundary for all 12 admin routes — correct on the framework version in use but against Vercel's own guidance, with a documented CVE class (`x-middleware-subrequest`) having bypassed exactly this pattern before. It became a real incident 07-26: the matcher's extension-exclusion regex was unanchored, so any path merely containing an excluded extension's substring bypassed the gate entirely with no handler re-check as backstop; closed from both sides with an anchored explicit-namespace matcher and `requireAdmin()` added to all 21 handlers, plus a 32-char `SESSION_SECRET` floor. The gap resurfaced 08-12 in the page namespace — `generateMetadata` on admin edit pages ran an unauthenticated DB read since `requireAdmin` only covers API routes — closed with a shared `adminEditMetadata()` helper, and 08-13 added bypass logging with a correlating `bypassId`, still unverified against a real request as of 08-15. ## Decisions of note

- **2026-05-20 — Project platform storage** — replaced `Project.platform: String` with `bucket: PlatformBucket` enum + `platformTags: PlatformTag[]` enum array; rejected an entity-table version as over-engineering for zero added buckets in the project's lifetime. [source](dev-journal/2026-05-20.md)
- **2026-05-20 — Two-phase deployment** — additive schema + backfill deployed first, final schema (drop `platform`, NOT NULL `bucket`) second; brief broken window between them explicitly accepted. [source](dev-journal/2026-05-20.md)
- **2026-05-21 — Shared coherence validation** — a single `superRefine` for bucket/tag coherence, shared across create and update schemas via a common `projectFields` map, so the rule can't drift between the two paths. [source](dev-journal/2026-05-21.md)
- **2026-06-08 — Importer architecture** — `project.json` + direct Prisma + direct Blob, over an admin HTTP API (needs a live server, random blob keys) or raw-markdown parsing (no stable schema). [source](dev-journal/2026-06-08.md)
- **2026-06-10 — Content-addressed blob keys** — `SHA256[:12]` of file content; identical bytes reuse the key, changed bytes get a CDN-clean URL. [source](dev-journal/2026-06-10.md)
- **2026-06-13 — Orphan pruning after import** — sweeps unreferenced blob keys post-write with a `--no-prune` escape hatch, avoiding monotonic growth on the 1GB free tier. [source](dev-journal/2026-06-13.md)
- **2026-06-28 — FAQ rendering** — kept always-in-DOM with `inert`, not `AnimatePresence` conditional-mount, so collapsed answers stay in SSR HTML for crawlers and AI citation. [source](dev-journal/2026-06-28.md)
- **2026-06-29 — `robots.ts` policy** — allow-all with no bad-bot blocklist (robots is advisory; the edge is the real boundary); `Disallow: /api/` carved back to `Allow: /api/feed/`. [source](dev-journal/2026-06-29.md)
- **2026-06-29 — `/llms.txt` as a dynamic route** — reuses `getProjectsGalleryCached()` so it can't drift from the gallery; Next only special-cases `robots`/`sitemap` filenames, so a static file wasn't an option. [source](dev-journal/2026-06-29.md)
- **2026-07-07 — Admin RevalidatePanel** — a session-gated dashboard panel over a secret-gated endpoint, so import-script writes (which bypass Next's cache API) can still be busted by hand. [source](dev-journal/2026-07-07.md)
- **2026-07-17 — Guides as a top-level entity** — `/guides/:slug`, project referenced by slug rather than FK, so a project reimport can't cascade-delete a guide. [source](dev-journal/2026-07-17.md)
- **2026-07-19 — IndexNow via an admin dashboard button** — not a local script, so submission runs in the deploy with the real prod origin and no risk of announcing localhost. [source](dev-journal/2026-07-19.md)
- **2026-07-26 — Admin auth second lock** — `requireAdmin()` added to all 21 admin handlers; `SESSION_SECRET` gets a 32-char floor in the accessor, not the zod schema, so a short secret fails only session auth rather than every DB-backed page. [source](dev-journal/2026-07-26.md)
- **2026-08-12 — Shared admin metadata guard** — `adminEditMetadata()` extracted so the session check is structural across all four admin edit pages, instead of four separately-remembered inline checks. [source](dev-journal/2026-08-12.md)
- **2026-08-15 — Routing moved to config** — legacy redirects/rewrites relocated from middleware to `next.config.ts`; the unconditional hourly `revalidate=3600` backstop replaced with a due-check cron that busts tags only when a post or guide actually came due. [source](dev-journal/2026-08-15.md)
- **2026-08-15 — OG card generation** — `/og` Satori route replaced with `scripts/generate-og-card.tsx` producing a committed static PNG, since the route 404'd in production anyway while bundling Satori+resvg WASM. [source](dev-journal/2026-08-15.md)
- **2026-08-17 — Route groups over deleting all loading boundaries** — `(list)`/`(gallery)` scope list-page skeletons to their own routes, preserving two skeletons while removing the two `loading.tsx` files that caused soft 404s. [source](dev-journal/2026-08-17.md)

## Incidents of note

- **2026-05-20 — Prisma client leaked into client bundles** — `platforms.ts` imported enums from the full Prisma client, pulling the Prisma runtime into `"use client"` bundles and failing Turbopack chunking with a `node:module` error; cascaded into an `/admin/posts/bulk` prerender crash and a project-detail-page 500. Fixed by importing from `@/generated/prisma/enums`. [source](dev-journal/2026-05-20.md)
- **2026-06-08 — Importer silently uncommittable** — root `.gitignore`'s `scripts/` line kept `import-projects.ts` out of version control entirely; narrowed to `scripts/imports/`. [source](dev-journal/2026-06-08.md)
- **2026-06-10/06-13 — Blob listing pagination gap** — `list({ prefix })` walked only the first page, silently missing blobs past 1000 per project; fixed with a pagination loop. [source](dev-journal/2026-06-10.md)
- **2026-06-26 — Lightbox corner halo misdiagnosed** — attributed first to backdrop opacity, then to a `backdrop-filter` fringe; actual cause was `object-contain` letterboxing under a rounded container that never touched the visible image. [source](dev-journal/2026-06-26.md)
- **2026-06-28 — Import script dropped new fields** — `scripts/import-projects.ts` duplicated the lib's write logic instead of sharing it, so `cardImage`/`ogImage` were never written and their uploaded blobs got orphan-swept. [source](dev-journal/2026-06-28.md)
- **2026-07-08 — Swipe still opened the lightbox** — the 07-07 fix assumed framer-motion's `onDragEnd` beats the browser's click; it actually fires a frame later via `frame.postRender`. Fixed via raw pointer capture. [source](dev-journal/2026-07-08.md)
- **2026-07-17 — Duplicate `offers` key in the Reckon manifest** — masked by JSON's last-key-wins, surfaced a real price mismatch (manifest said 4.00, actual 3.99). [source](dev-journal/2026-07-17.md)
- **2026-07-20 — A review subagent produced a confidently wrong finding** — claimed unauthenticated `/api/admin/*` redirects to the HTML login page; `proxy.ts` actually returns 401 JSON for the API arm. Dropped before reaching the review file. [source](dev-journal/2026-07-20.md)
- **2026-07-26 — Admin auth gate skippable via a dotted path** — the matcher's extension-exclusion alternative was unanchored, so any path merely containing an excluded extension's substring bypassed the gate entirely; not exploitable in practice since admin `[id]` routes reject non-integer segments before DB access. [source](dev-journal/2026-07-26.md)
- **2026-07-26 — `SESSION_SECRET` accepted any non-empty string** — brute-forceable offline once encoded into the HS256 key; the project's own `.claude/CLAUDE.md` had documented it as "any string" — both code and doc corrected. [source](dev-journal/2026-07-26.md)
- **2026-08-12 — Unauthenticated DB read in admin edit metadata** — nested `generateMetadata` runs independently of the protected layout, and `requireAdmin` only covers API routes, so an unauthenticated request reaching an edit page leaked its title. [source](dev-journal/2026-08-12.md)
- **2026-08-13 — OG card rendered with a hard seam** — Satori failed to parse an 8-digit hex color, rendering a radial gradient near-solid; fixed with `rgba()`. [source](dev-journal/2026-08-13.md)
- **2026-08-13 — OG route exported invalid fields** — `size`/`contentType` are valid for the `opengraph-image` file convention but not a route handler; `tsc --noEmit` couldn't catch it because route-export validation only runs during `next build`, so it would have failed at deploy, not locally. [source](dev-journal/2026-08-13.md)
- **2026-08-15 — ESLint flat-config silently retained cleared options** — a block meant to clear `no-restricted-syntax` exemptions kept the prior rule's options instead, since flat config retains options when a later block sets severity only. Diagnosed with `yarn lint --print-config`. [source](dev-journal/2026-08-15.md)
- **2026-08-17 — Soft 404 across three routes in production** — `loading.tsx` Suspense boundaries let React commit a 200 status and stream the shell before `notFound()` could run, so guessed slugs and future-dated scheduled posts served 200s. [source](dev-journal/2026-08-17.md)
- **2026-08-17 — Scheduled content stranded behind a pinned 404** — prerendered detail routes carry no time-based cache expiry, and the revalidation helpers busted none of their per-post tags, so a post fetched while still future-dated stayed 404 until its next admin save. [source](dev-journal/2026-08-17.md)
