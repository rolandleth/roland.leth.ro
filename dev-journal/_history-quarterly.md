# Rolling History — last 90 days (through 2026-10-19)

## Themes

- **Admin auth: layered defenses added, gapped, and closed, repeatedly** — July 26 found and fixed an unanchored-regex matcher bypass (any path containing `.js`, so also `.json`, skipped the admin gate entirely) and a validation-less `SESSION_SECRET`, then added `requireAdmin()` to all 21 admin handlers rather than trusting middleware alone. August narrowed the matcher further and added a second defensive layer (`adminEditMetadata`/`requireAdminPageSession`) after an unauthenticated DB read surfaced in `generateMetadata` on 08-12 — then found a sibling gap on the same pages' bodies on 08-21, and an unawaited-guard blind spot in the contract test on 08-22. September ran a 121-issue full-codebase review (09-26), froze authored slugs, and added a CSRF `Origin` check across all write handlers (09-27) — closing a final hole in the login route the same day that session's own review found it (09-28). The throughline, stated independently on three separate days across two months: a guard that has never been seen to fail is a guard nobody has tested, and each fix tends to miss a sibling instance. [2026-07-26](dev-journal/2026-07-26.md), [Aug rollup](dev-journal/2026-08.md), [2026-09-27](dev-journal/2026-09-27.md)
- **Scheduled-content correctness: redesigned, broke production once, then hardened** — July 24 fixed feed autodiscovery (missing entirely since the Express→Next migration) and closed scheduled-post gaps on the archive and sitemap with `revalidate=3600` backstops. August 15 replaced that hourly bust with a daily due-check cron and moved blog pagination off `?page=` to static path segments — which caused a real production incident on 08-17: `loading.tsx` Suspense boundaries let three routes serve HTTP 200 while streaming the 404 page, found by diffing `.next/server/app/**/*.meta` files and fixed with route groups plus per-item tag busts. September 15 found the cron never busted guide topic hubs' cache tag, a documented "known gap" that was live, not latent; fixed via `revalidateGuideTopicHubs`. [2026-07-24](dev-journal/2026-07-24.md), [Aug rollup](dev-journal/2026-08.md), [Sep rollup](dev-journal/2026-09.md)
- **Project placement model, rebuilt three times in three months** — August 12-13 introduced `isOwnApp` and a discontinued-but-reachable state. September 13-14 made `isOwnApp` an explicit schema field with badge-vs-pill CTA logic, closing an importer bug that silently reset it on re-import. October rebuilt the model twice more: a `prominence`/`pageLayout`/`isDiscontinued`/`isOwnApp` four-field split (Oct 2-3), then a `ProjectStatus` enum (`comingSoon`/`live`/`discontinued`) replacing `isDiscontinued` to support Digest's pre-launch listing (Oct 11), ending with the status moved into the store-button slot via a shared `StoreLinks` component (Oct 17-19). Each rebuild kept the model additive, migrated by hand-written SQL ahead of `db:push`. [Aug rollup](dev-journal/2026-08.md), [Sep rollup](dev-journal/2026-09.md), [2026-10-11](dev-journal/2026-10-11.md)
- **Post media: images only, then video, with a resolver fix chain in between** — August 24 fixed an excerpt-truncation bug that broke reference-style links in blog list cards. September 14-23 renamed `Post.summary` to `Post.description` and spent six days chasing disagreeing write paths (the Published toggle wiping an authored description, an uncapped title fallback, raw values from import/bulk upload) before every path was unified behind one `postDescription.ts` resolver. October 3 added video support end to end (image syntax rewritten to `<video>`, signed browser-to-Blob upload, delete-time cleanup), merged Oct 5; the Oct 6 review closed nine issues, but no real Blob call had run against any of it as of Oct 19. [Aug rollup](dev-journal/2026-08.md), [Sep rollup](dev-journal/2026-09.md), [2026-10-06 review](code-reviews/2026-10-06.md)
- **Digest's medical-claims pivot and the site's legal pages** — a medical-claims/liability review drove Digest's October 11 pivot (no guided tests shipped, no labels, counts not rankings), followed by a product-page rebuild from journal-only copy and a new `/privacy/digest` (Oct 15), a disclaimer moved to an FAQ (Oct 17), and its own terms page under a new in-app-purchases rule that also made every legal page on the site speak as "we" (Oct 19). [2026-10-11](dev-journal/2026-10-11.md), [2026-10-19](dev-journal/2026-10-19.md)

## Incidents of note

- **2026-07-24 — Feed autodiscovery missing entirely** since the Express→Next migration, plus invalid Atom (no feed-level `<author>`) and a stale `<updated>` keyed off edit time rather than publish time. Fixed; all three restored. [source](dev-journal/2026-07-24.md)
- **2026-07-26 — Admin auth gate skippable via a dotted path** — not exploitable as it stood (integer-only route ids reject a dotted segment first), but the whole authorization story for `/api/admin/*` rested on one unanchored regex. Fixed with anchored patterns, explicit `/admin*`/`/api/admin*` entries, and per-handler guards. [source](dev-journal/2026-07-26.md)
- **2026-08-12 — Unauthenticated DB read in admin edit pages' `generateMetadata`** — it runs independently of the protected layout. Fixed via a shared `adminEditMetadata` guard; a sibling gap in the same pages' bodies surfaced again on 08-21. [source](dev-journal/2026-08.md)
- **2026-08-17 — Soft 404 across three live routes** — a `loading.tsx` Suspense boundary let React commit a 200 and stream the shell before `notFound()` could set the status. Fixed by scoping list skeletons into route groups and deleting the three detail-page loading states; regression risk judged high and invisible, hence a filesystem guard test. [source](dev-journal/2026-08.md)
- **2026-08-24 — Reference-style links rendered as literal brackets** in blog list excerpts — `truncateBody` sliced posts mid-body, dropping link-reference definitions authored at the bottom, affecting 11 tech posts. Fixed by appending the definitions back onto the excerpt. [source](dev-journal/2026-08.md)
- **2026-09-16 — HEIC files accepted and stored as AVIF** — `detectImageMime` treated the `mif1` major brand as AVIF with no compatible-brands check; such files couldn't render once stored. Fixed; the pre-existing test that pinned the bug as "valid" was corrected. [source](dev-journal/2026-09.md)
- **2026-09-26 — Project rename orphaned guides** — the PUT handler re-derived the slug from the project name while guides/topics kept the old `projectSlug` by value. Fixed by freezing slugs outright. [source](dev-journal/2026-09-26.md)
- **2026-09-27 — Fused Tailwind utility silently dropped the invalid-field border** on the loan calculator — a missing space merged two class tokens into one Tailwind never generates. Fixed; a class-token test now catches the fused form. [source](dev-journal/2026-09-27.md)
- **2026-10-06 — Video-in-link produced doubly-invalid HTML** (`<video>` inside `<a>`, with a nested fallback `<a>`) — a click on the player controls could follow the outer link. Fixed by lifting the video out of the link. [source](code-reviews/2026-10-06.md)
- **2026-10-19 — Plans with no offers rendered priceless pricing cards** under a "US prices" note that was true of nothing — `pricingFor` returned a truthy `kind` whenever plans existed and `[].every(...)` vacuously passed. Fixed to return null with no offers. [source](dev-journal/2026-10-19.md)
