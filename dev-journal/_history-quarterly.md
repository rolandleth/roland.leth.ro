# Rolling History — last 90 days (through 2026-11-02)

## Themes

- **Scheduled-content correctness, built then hardened in three waves.** 2026-08-15 moved legacy routing from middleware into `next.config.ts` (zero function invocation) and replaced an hourly `revalidate=3600` backstop on the feed/archive/sitemap with a due-check cron plus path-based blog pagination. 2026-08-17 found and fixed a regression the same move exposed: a `loading.tsx` Suspense boundary let three routes (`/blog/:section/:slug`, `/blog/:section/p/:page`, `/projects/:slug`) commit a 200 status under rendered 404 content — any guessed slug, including a not-yet-due scheduled post, served as a real page; fixed by scoping list skeletons into route groups, deleting the detail-route boundaries, and switching the cron to bust each due post's/guide's own detail tag. 2026-08-21 flagged the guide-topic-hub cache-bust gap as a deliberate YAGNI; 2026-08-31 added a 200 "coming soon" notice to replace the pinned 404 for not-yet-due posts. 2026-09-01 collapsed two independent clock reads into one `resolvePost` union, closing a microseconds-wide race; 2026-09-03 added the public `override-preview` route; 2026-09-15 closed the guide-topic-hub gap flagged three weeks earlier, via `revalidateGuideTopicHubs`. [source](dev-journal/2026-08-17.md), [source](dev-journal/2026-09-01.md), [source](dev-journal/2026-09-15.md)
- **Admin-page auth hardened in three separate passes, each finding the previous one's gap.** 2026-08-12 closed an unauthenticated-DB-read leak in admin edit pages' `generateMetadata` with a shared `adminEditMetadata` guard. 2026-08-21 (an external review, mid-session) found that guard protected only the `<title>`, not the page body, and extended `requireAdminPageSession` to all six data-reading pages plus a contract test. September's full-codebase review (09-26/09-27) added a CSRF `Origin` check across all 21 write handlers, an unsaved-changes guard, and sniffed-byte `contentType` on uploads; the 09-28 follow-up found the one route the sweep missed — `/api/auth/login` runs neither check, letting a cross-site page exhaust the admin's own rate-limit bucket — still open at month-end.
