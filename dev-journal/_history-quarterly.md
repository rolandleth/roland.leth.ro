## Themes

- **Caching and revalidation as the site's central design problem** — the quarter's spine. June ended with imports that bypass Next's cache (`scripts/import-projects.ts` cannot call `revalidateTag`, and `getProjectBySlug`'s TTL-less `unstable_cache` served the pre-import snapshot). 07-07 split coarse `blog-{section}`/`projects` tags into per-slug detail tags plus `*-pages` aggregates and added an admin RevalidatePanel; 07-17 fixed a production stale-404 (`unstable_cache` durably cached a `null`) by throwing `CacheMissError` on a miss across all four detail lookups; 08-15 replaced hourly `revalidate=3600` with a daily due-check cron (window 50h) and moved pagination to `/blog/:section/p/:page` so no list reads `searchParams`; 08-17 found three routes serving a soft 404 (HTTP 200 rendering the 404 page) because `loading.tsx` let React commit a status before `notFound()` ran, fixed with route groups `(list)`/`(gallery)`; the cron now busts each due item's own detail tag and, from 09-15, each due guide's topic hub. A recurring failure mode ran through it: reports that say more than was verified (revalidate endpoints "revalidated" slugs matching no row, IndexNow "submitted: N" when every batch 403'd).
