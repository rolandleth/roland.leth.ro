# Rolling History — last 90 days (through 2026-09-08)

## Themes

- **Admin auth: from single gate to defense in depth** — The quarter's most persistent thread. 2026-07-20 flagged (and deliberately deferred) that Next's middleware was the sole authorization boundary for all 12 admin routes; 2026-07-26 converted the watch-out into a real incident when the matcher's extension-exclusion regex turned out unanchored (any path merely *containing* an excluded extension's substring, e.g. `.json` containing `.js`, skipped the gate) — fixed with `requireAdmin()` added to all 21 handlers plus a 32-char floor on `SESSION_SECRET`. August reopened the same class from the page-render side: 2026-08-12 closed an unauthenticated DB read in edit-page `generateMetadata` via a new `adminEditMetadata` helper; 2026-08-21 found — via an external review — that the helper guarded only the `<title>`, not the page body, on the dashboard root and four edit pages, and extended a real session guard to all six; 2026-08-22 then found the contract test proving that guard couldn't itself fail (it string-matched the guard call, which an unawaited/floating-promise call also satisfies). Every fix narrowed the gap; every follow-up review found the fix's own blind spot. - **Project import tooling and JSON-LD/structured-data hardening** — June built the manifest-driven importer (`scripts/import-projects.ts` + per-project `project.json` + the `app-copy-to-project` skill) for Reckon and Continuum, over parsing raw marketing markdown or driving the admin HTTP API; direct Prisma + direct Blob writes with deterministic, later content-addressed, blob keys made re-imports idempotent. The same window built a full project FAQ feature and SEO/JSON-LD layer (offers, applicationCategory, FAQPage/SoftwareApplication), which then needed its own security pass: 2026-06-29 built `safeJsonLdString` escaping, closed a multi-currency `AggregateOffer` mislabeling, and by session 7 consolidated every JSON-LD embed through one `<JsonLdScript>` chokepoint with a lint rule banning `dangerouslySetInnerHTML` everywhere else. August's OG-card rework (see below) extended the same "make the structured data honest" instinct to social cards. - **Static rendering push, cache precision, and the soft-404 incident** — 2026-07-07 split coarse `blog-{section}`/`projects` cache tags into per-slug detail tags plus `*-pages` aggregates (fixing 8 unnecessary ISR regenerations per single edit) and cut Vercel CPU by removing `cookies()`/`headers()` dynamic-rendering forcers. 2026-08-15 pushed further: legacy redirects/rewrites moved into `next.config.ts`'s routing layer, the middleware matcher narrowed to admin-only, blog pagination became path-based, and hourly `revalidate=3600` busts were replaced by a due-check cron. 2026-08-17 found the static push's blind spot: a `loading.tsx` Suspense boundary lets React commit a 200 and stream before `notFound()` can run, so three routes were silently serving soft 404s in production — fixed by route-grouping list skeletons, deleting detail-page ones, and having the cron bust per-item detail tags instead of only list tags. 2026-09-08 found the push's other blind spot, milder: a prerendered 404 costs no invocation but is still a full page carrying the root layout's `<SpeedInsights />` island, so junk paths file real Web Vitals under themselves. "Zero server compute" is not "no cost". [source](dev-journal/2026-07.md) [source](dev-journal/2026-08-15.md) [source](dev-journal/2026-08-17.md) [source](dev-journal/2026-09-08.md)
- **Scheduled content: from pinned 404 to notice, preview, and hardening** — 2026-08-31 replaced the 404 a future-dated post's URL served with a 200 `ScheduledPostNotice` (`robots: { index: false }`, a matching `.md` stub), reusing the existing pin-and-bust lifecycle exactly: `getPostBySlug`'s fetch split into a private `fetchPostRow` so live and scheduled views share one cached row and tag set. 2026-09-01's review found six issues in the day-old code and fixed five, the sharpest being two independent clock reads that could pin a 404 at a post's exact publish minute — collapsed into one `resolvePost` returning a `live`/`scheduled`/`missing` union from a single read. 2026-09-02 verified those resolutions and found only second-order consequences (an uncached exported twin of the production path, orphaned docblocks, test coverage that didn't follow its subject's change in shape). 2026-09-03 added `/blog/:section/:slug/override-preview`, deliberately public because the URL itself is the override, and the only surface that overrides the schedule. - **Reporting honesty: "success" that didn't reflect what was verified** — A recurring July bug class, three independent instances of the same shape. The revalidate endpoint reported requested slugs as "revalidated" without checking they matched a real row, and discarded partial progress on a mid-batch throw; the identical defect reappeared independently in IndexNow's submit-count reporting (`"submitted: N"` even when every batch 403'd), closed by splitting `attempted`/`accepted`. - **Gallery/lightbox gesture engineering** — 2026-06-26 misdiagnosed a lightbox "corner halo" twice (backdrop opacity, then `backdrop-filter` fringe) before finding the real cause: galleries never rounded the visible, letterboxed image, only its container — fixed via aspect-true `next/image` sizing. 2026-06-29 built swipe/drag navigation via Framer, then removed all navigation animations per user direction, then added back/forward animation suppression through the Navigation API's `currententrychange` event (rejecting a `history.pushState` monkey-patch). - **Test-quality discipline: verify a guard can actually fail** — The quarter's clearest cross-cutting learning, recurring in June's JSON-LD work, July's slug-tooling review, and repeatedly in August (source-text contract tests, vacuous JSX-construction assertions, the floating-promise-blind contract test). The standing fix is always the same: deliberately break the thing a new test claims to guard and confirm it goes red before trusting it. September added both poles of the pattern: 2026-09-02 caught the inverse failure — a test whose *name* still claimed coverage the assertions no longer provided — and 2026-09-03 applied the discipline preventively, running the new route's load-bearing tests against a deliberately broken implementation before calling the code done. ## Decisions of note

- **2026-06-13 — Content-addressed blob keys widened 48-bit → 64-bit with a byte-size assert** — the dedupe contract is "same key ⇒ same bytes"; a collision would silently serve wrong content. Paired with prune-after-import to stop monotonic growth on the 1GB Blob free tier. [source](dev-journal/2026-06-13.md)
- **2026-06-29 (session 7) — Single `<JsonLdScript>` chokepoint for all JSON-LD embeds** — replaced three hand-written `<script>` blocks; lint rule switched from banning `JSON.stringify` inside the attribute to banning the `dangerouslySetInnerHTML` attribute itself everywhere else, closing an aliased-serialization gap. [source](dev-journal/2026-06-29.md)
- **2026-07-07 — Per-slug cache tags replace coarse section tags** — `blog-{section}`/`projects` split into detail tags plus `*-pages` aggregates; added an admin RevalidatePanel since import-script writes bypass Next's cache API entirely. [source](dev-journal/2026-07.md)
- **2026-07-17 — Guides feature built end-to-end in one day**, including a `CacheMissError`-throw-on-miss pattern across all four detail lookups after a prod stale-404 traced to `unstable_cache` durably caching `null`. [source](dev-journal/2026-07.md)
- **2026-07-26 — `requireAdmin()` added as a second lock to all 21 admin handlers**, plus a 32-char floor on `SESSION_SECRET` in the accessor (not the zod schema, to avoid taking every DB-backed page down over a session-only problem). [source](dev-journal/2026-07.md)
- **2026-08-15 — Legacy routing and scheduled-content revalidation moved off middleware and off unconditional hourly busts** — `next.config.ts` redirects/rewrites resolve with zero function invocations; a due-check cron replaces `revalidate=3600` on the feed, archive, and sitemap. [source](dev-journal/2026-08-15.md)
- **2026-08-21 — `requireAdminPageSession` extended to all six data-reading admin pages** after a review found `adminEditMetadata` guarded only the page title, not the body render. [source](dev-journal/2026-08-21.md)
- **2026-09-03 — Scheduled-post preview as a sibling route, not a query param** — reading `searchParams` anywhere in a page opts the whole route into dynamic rendering, costing an invocation on every hit rather than the param'd ones; a `has`-query rewrite in `next.config.ts` is the middle option when the param itself is required. [source](dev-journal/2026-09-03.md)
- **2026-09-08 — Broken-feed junk URLs redirected rather than left to 404** — a 308 in `LEGACY_REDIRECTS` returns no HTML, so nothing reports Web Vitals and the visit lands on the real post; rejected a `410 Gone` route handler, which would put billed compute back on scanner traffic. Declined re-adding the seven removed `LEGACY_POST_SLUG_ALIASES` in the same file: free to run, but the 404 report confirmed no hits, and "cheap" is not "worth it". [source](dev-journal/2026-09-08.md)
