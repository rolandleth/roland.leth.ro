## Incidents of note

- **2026-04-26 — scripts/ wholly gitignored** — `.gitignore` had `scripts/` entry; import scripts were never tracked. Fix: narrowed to `scripts/imports/` (output artifacts), source files now tracked. [source](dev-journal/2026-04.md)
- **2026-05-01 — Blob list pagination gap** — `list()` returns max 1000 blobs per page; large blob stores silently dropped orphans beyond page 1 during pruning. Fix: paginated loop. [source](dev-journal/2026-05.md)
- **2026-06-26 — Lightbox corner halo (misdiagnosed twice)** — first diagnosis: CSS `overflow: hidden` on container; second: `border-radius` on `<img>` not clipping. True cause: `object-contain` letterboxes the image inside the element box, `border-radius` applies to the element box (which extends past the visible image). Fix: `width={0} height={0}` + `w-auto h-auto` makes the element box match the visible image. [source](dev-journal/2026-06-26.md)
- **2026-06-29 — to-transparent = transparent black on iOS Safari** — CSS `transparent` keyword resolves to `rgba(0,0,0,0)` (transparent black); gradient from a color to `transparent` creates a visible dark band on iOS Safari. Fix: `--color-background-transparent` CSS var using zero-alpha of the background color. [source](dev-journal/2026-06-29.md)
- **2026-07 — s-maxage dual cache layer** — `.md` route has `s-maxage=3600` that outlives the `post-<slug>` data cache tag bust by up to an hour; CDN could serve stale content. Either drop `s-maxage` or set `s-maxage=0, stale-while-revalidate=86400`. [source](dev-journal/2026-07.md)
