# Rolling History — last 90 days (through 2026-09-14)

## Themes

- **Cache/revalidation granularity and scheduled-content correctness, quarter-long** — July opened with a known dual-cache staleness gap (`llms.txt`, later the `.md` export route) and coarse `blog-{section}`/`projects` tags regenerating every sibling page on one edit; 2026-07-07 split these into per-slug + aggregate `*-pages` tags, and reviewing a similar guides-tag fix on 2026-07-19 found the revalidate endpoint reporting requested slugs as "revalidated" without checking they matched a real row — the same false-success-report class then reappeared independently in IndexNow's submit-count reporting, closed 2026-07-21 ([source](dev-journal/2026-07-07.md), [source](dev-journal/2026-07-19.md)). August replaced hourly `revalidate=3600` on feed/archive/sitemap with a daily due-check cron (2026-08-15), which broke production two days later — a `loading.tsx` Suspense boundary let three routes serve soft 404s under HTTP 200, fixed via route groups and per-item cron busts ([source](dev-journal/2026-08-17.md)). September continued the same lineage: 2026-08-31's `ScheduledPostNotice` (200 instead of a pinned 404) exposed a two-clock-read race, fixed 2026-09-01 by collapsing to one `resolvePost` resolver, then extended 2026-09-03 into a public `/override-preview` route built on the same resolver ([source](dev-journal/2026-09-01.md), [source](dev-journal/2026-09-03.md)).

- **Admin auth: from single gate to defense in depth, narrowed repeatedly** — 2026-07-20 flagged (and deliberately deferred) that Next's middleware was the sole authorization boundary for all 12 admin routes, against Vercel's own guidance; it converted into a real incident 2026-07-26 when the matcher's extension-exclusion was found unanchored (`.json` contains `.js`), fixed with an anchored matcher plus a `requireAdmin()` second lock in all 21 handlers ([source](dev-journal/2026-07-26.md)). August tightened the same layered guard almost weekly: 2026-08-12 closed an unauthenticated DB read in `generateMetadata`; 2026-08-21 found the four `[id]/edit` pages and the dashboard root logged a bypass but never stopped rendering, extending `requireAdminPageSession` to all seven data-reading pages; 2026-08-22 closed the last hole, a contract test that couldn't fail because it matched source text on an unawaited guard call ([source](dev-journal/2026-08-21.md), [source](dev-journal/2026-08-22.md)). Each fix was correct and narrow, and each missed a sibling instance — a pattern both the 2026-07-26 and 2026-08-21/22 journals name explicitly, restating the same lesson: a guard that has never been seen to fail is a guard nobody has tested.

- **Gallery/lightbox gesture engineering, June into July** — 2026-06-26 lifted gallery position state to `ProjectContent` for a single shared index driving dots, tabs, and lightbox, and traced a recurring corner-halo bug (misdiagnosed twice as backdrop opacity/blur) to the gallery never rounding the visible letterboxed image itself — fixed via aspect-true `next/image` sizing ([source](dev-journal/2026-06-26.md)). 2026-06-29 added measured-ratio carousel sizing and Framer-drag swipe shared via `src/lib/client/swipe.ts`, then stripped nearly all navigation animation per user direction, dropping the now-dead `slideDirection` plumbing ([source](dev-journal/2026-06-29.md)). The continuous cross-section gallery shipped in July (2026-07-07) with two gesture bugs fixed same day, both revisited 2026-07-08 once framer-motion's `onDragEnd` was found to fire a frame after the browser's click (`frame.postRender`) — too late to gate a swipe-vs-click suppression flag — moving the fix to raw `pointerdown`/`pointerup` capture ([source](dev-journal/2026-07-08.md)).

- **Guides section: build, review, fix-the-fixes** — 2026-07-17 built the entire guides feature end to end in one day across five sessions — schema, importer, admin CRUD, public pages — and fixed a production stale-404 incident (`unstable_cache` had durably cached a `null`) with a throw-on-miss pattern across all four detail lookups ([source](dev-journal/2026-07-17.md)). The 2026-07-18 review (~39 findings) was resolved the same day in 8 phases, with 8 findings deliberately deferred or skipped with recorded reasons; the 2026-07-19 follow-up review, auditing the fix commits themselves for regressions, found the remediation had introduced its own issues — an over-widened login exemption, and a repeating pattern of "sweeps that stopped short" (an `@apply` extraction missing one button, an `aria-describedby` pass wired to one help text of eight) ([source](dev-journal/2026-07-18.md), [source](dev-journal/2026-07-19.md)).

- **Structured data (JSON-LD) hardened to a single escaping chokepoint** — 2026-06-29 built `BlogPosting` JSON-LD, `robots.ts`, and a DB-backed `llms.txt` route in session 4, then across sessions 5–7 closed the embedding-boundary risk incrementally: `safeJsonLdString` escaping `<`/`>`/`&`/U+2028/U+2029 at the two projects-page `<script>` sites (session 5), extraction into a shared `src/lib/content/jsonLd.ts` plus an ESLint rule banning raw `JSON.stringify` inside `dangerouslySetInnerHTML` (session 6), and finally a single `<JsonLdScript>` component made the only one allowed to use `dangerouslySetInnerHTML` at all, with the lint rule widened to ban the attribute itself rather than the lexical call ([source](dev-journal/2026-06-29.md)).

- **OG/social card generation moved from a live route to a build script** — Started 2026-08-13 as a dev-only `/og` Satori route (Google Fonts CDN dependency, an 8-digit-hex color bug producing a visible seam); the 2026-08-14 review flagged an unbounded WASM bundle shipped to serve a 404 and no caching contract. 2026-08-15 replaced the route with `scripts/generate-og-card.tsx` (`yarn og:card`), a committed PNG, and single-sourced image descriptors/alt text, verified byte-identical to the prior output ([source](dev-journal/2026-08-13.md), [source](dev-journal/2026-08-15.md)).

- **Vercel compute optimization** — 2026-07-07 cut CPU by removing two dynamic-rendering forcers (`cookies()` for theme, `headers()` for canonical origin), flipping most pages to static/ISR; 2026-07-17 added a bot-probe short-circuit in middleware (a narrow extension-`Set` + path-prefix match, not a blanket dotfile rule) after diagnosing a middleware/function CPU split from an analytics screenshot; 2026-07-24 extended the same push to the Atom feed (`force-static` + `revalidate=3600`, replacing a `Cache-Control` header `revalidateTag` couldn't purge) ([source](dev-journal/2026-07-07.md), [source](dev-journal/2026-07-17.md), [source](dev-journal/2026-07-24.md)).

- **Sandbox/local-verification constraints** — A consistent ceiling recurred through July: the sandbox can't reach Google Fonts so `next build` fails at font optimization, local Postgres.app rejects `trust` auth so DB-backed dry-runs fail locally, and the sandbox forbids binding a listening socket at all. The response stayed consistent — verify via `tsc` + full suite + lint, treat build/browser verification as deploy-time concerns — and 2026-07-24 closed part of the gap by adding `.claude/launch.json` so the integrated preview panel can launch the dev server outside the sandbox ([source](dev-journal/2026-07-24.md)).

## Decisions of note

- **2026-06-28 — `cardImage` field naming** — chose `cardImage` over the user's shorthand "thumb"/"thumbnail"; rationale: the `app-copy-to-project` skill's generated manifest already used `cardImage`/`ogImage` as keys, and a mismatch would make the import silently drop the field. [source](dev-journal/2026-06-28.md)
- **2026-06-29 — Multi-currency offers as an `Offer` array** — a USD+EUR mix emits an array of `Offer` nodes rather than a mislabeled `AggregateOffer`, since `AggregateOffer.priceCurrency` asserts a single currency across the price range; rejected silently picking `offers[0]`'s currency. [source](dev-journal/2026-06-29.md)
- **2026-07-17 — Guides as a top-level entity, project referenced by slug not FK** — `/guides/:slug`, not `/blog/guides/:slug`; an FK would cascade-delete guides on project reimport. [source](dev-journal/2026-07-17.md)
- **2026-07-19 — IndexNow submission via an admin dashboard button, not a local script** — runs in the deploy so `getSiteUrl()` resolves the real prod origin; no `vercel env pull`, no risk of announcing localhost. [source](dev-journal/2026-07-19.md)
- **2026-07-24 — Feed `<id>` pinned permanently at `/api/feed/:section`** — only `rel="self"`/autodiscovery moved to the pretty URL; repointing `<id>` would orphan existing subscriptions. [source](dev-journal/2026-07-24.md)
- **2026-08-12 — Discontinued projects keep a bare storefront label, no repeated CTA** — rejected hiding the link outright; "Get on" asserts availability that's no longer true. [source](dev-journal/2026-08-12.md)
- **2026-08-15 — Blog pagination moved to `/blog/:section/p/:page`, off `?page=N`** — reading `searchParams` was what forced the whole list to render per request instead of statically. [source](dev-journal/2026-08-15.md)
- **2026-08-21 — No rotation for `IP_HASH_SECRET`** — rejected; Vercel has no native rotation mechanism, and rotating closes only the weaker of two joinable paths — Vercel's own request logs hold the raw IP regardless. [source](dev-journal/2026-08-21.md)
- **2026-08-24 — Excerpt definitions sliced by source node offset, not rebuilt from parsed fields** — removes a whole class of escaping bugs (quoting, whitespace) instead of handling instances one at a time. [source](dev-journal/2026-08-24.md)
- **2026-09-03 — 307, not 308, on the preview route's live redirect** — once a post's `datetime` passes, `/override-preview` redirects to the canonical post; a permanent redirect would be cached by the browser and break the URL for the next post scheduled at that slug. [source](dev-journal/2026-09-03.md)
- **2026-09-08 — Did not re-add `LEGACY_POST_SLUG_ALIASES` as static rules** — the cost premise (zero function invocation) was right, but the seven dirty slugs showed zero hits in the 404 report; cheap isn't the same as worth it. [source](dev-journal/2026-09-08.md)
- **2026-09-13 — `isOwnApp` explicit boolean on `Project`** — chosen over deriving "creator" from the free-text `role` field or from storefront hostname alone; both proxies were accidentally wrong (DeinDeal/MyTherme were excluded only because of a legacy `itunes.apple.com` host). [source](dev-journal/2026-09-13.md)

## Incidents of note

- **2026-06-26 — Lightbox corner halo** — misdiagnosed twice (backdrop opacity, then `backdrop-filter` fringe) before the real root cause: the gallery never rounded the visible, letterboxed image itself. Fixed via aspect-true `next/image` sizing + rounding the image element. Regression risk low, isolated to gallery components. [source](dev-journal/2026-06-26.md)
- **2026-06-28 — Import script silently dropped new image fields** — `scripts/import-projects.ts` duplicates the tested `projectImport.ts` core with its own write logic; a new `cardImage`/`ogImage` field landed in the lib alone and the orphan-sweep would have deleted the uploaded blobs. Fixed both spots; regression risk recurs on the next `Project` image field unless the duplication is extracted. [source](dev-journal/2026-06-28.md)
- **2026-07-05 — Offer NaN guard missed `Number("") === 0`** — an empty/whitespace price passed the finite check as `0`, emitting an empty-string `lowPrice`; tightened to reject blank strings first. Regression risk low, one validation function. [source](dev-journal/2026-07-05.md)
- **2026-07-17 — Production stale-404** — a published, listed post 404'd on its own detail page; root cause a `null` durably cached by `unstable_cache` from before the row existed. Fixed via throw-on-miss across all four detail lookups. [source](dev-journal/2026-07-17.md)
- **2026-07-26 — Admin auth gate skippable via a dotted path** — the middleware matcher's extension-exclusion was unanchored, so any path merely containing an excluded extension's substring (`.json` contains `.js`) bypassed the gate entirely. Not exploitable in practice — every admin `[id]` route already rejects non-integer segments before DB access — but fixed with an anchored matcher plus a handler-level second lock. [source](dev-journal/2026-07-26.md)
- **2026-08-17 — Soft 404 live in production across three routes** — root cause: a `loading.tsx` Suspense boundary lets React commit HTTP 200 and stream the shell before `notFound()` can set the status, which can't change after the first byte. Fixed by scoping list skeletons into route groups and deleting the three detail-route boundaries. Regression risk high and invisible, hence a filesystem guard test. [source](dev-journal/2026-08-17.md)
- **2026-09-01 — Scheduled-post resolver race** — `getPostBySlug` and `getScheduledPost` each read the clock independently, so a post crossing its `datetime` between the two calls could answer "not yet" to both and pin a fresh 404 at the exact publish minute. Fixed by a single-read `resolvePost` resolver; boundary tests pin `datetime === now` under fake timers. [source](dev-journal/2026-09-01.md)
- **2026-09-08 — `/api/feed/undefined/blog/:section/:slug` 404s in Speed Insights** — root cause: the original April 2026 feed route built entry URLs from an unset `NEXTAUTH_URL`, fixed within two days, but crawl memory outlived the fix by five months. Repaired with a 308 redirect instead of leaving the static 404 (which still mounts the root layout's `<SpeedInsights />`). [source](dev-journal/2026-09-08.md)
