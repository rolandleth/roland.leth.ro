# Rolling History — last 90 days (through 2026-08-24)

## Themes

- **Admin auth: single gate to defense-in-depth.** The middleware-only admin gate was flagged as a documented risk on 2026-07-20 (Vercel's own guidance, a real CVE class for exactly this pattern) and deliberately deferred. It converted into a real incident 2026-07-26: `src/proxy.ts`'s extension-exclusion regex was unanchored at both ends, so any path merely *containing* an excluded substring (`.json` contains `.js`) skipped the gate entirely — not exploitable in practice only because every admin `[id]` route parses its segment as a plain integer. Fixed with an anchored, explicit-namespace matcher plus a `requireAdmin()` second lock in all 21 handlers, and a `SESSION_SECRET` 32-char floor (it had accepted any non-empty string, and the project's own docs said so). August closed the same gap in the page namespace across four sessions: 08-12 found unauthenticated `generateMetadata` DB reads on the four edit pages; 08-13 added bypass logging; 08-15 narrowed the middleware matcher itself to `/admin*` + `/api/admin*` with no catch-all backstop; 08-21 found the page-side guard only logged-and-fell-through rather than blocking the render, so all six admin data-reading pages — including the `/admin` dashboard root — needed a real `requireAdminPageSession` plus a contract test tying every page body to an actual guard call. [dev-journal/2026-07-26.md](dev-journal/2026-07-26.md), [dev-journal/2026-08-12.md](dev-journal/2026-08-12.md), [dev-journal/2026-08-21.md](dev-journal/2026-08-21.md)
- **Cache/revalidation granularity, honest reporting, and the incident it caused.** July opened with a known dual-cache staleness gap and coarse `blog-{section}`/`projects` tags regenerating every sibling page on any edit; 07-07 split these into per-slug + aggregate `*-pages` tags and added an admin RevalidatePanel. The same imprecision resurfaced in guides (tag-namespace collision fixed 07-18), then as a reporting defect: the revalidate endpoint reported requested slugs as "revalidated" without checking they matched a real row and discarded partial progress on a mid-batch throw (07-19), and the identical failure mode reappeared independently in IndexNow's submit-count reporting — "submitted: N" even when every batch 403'd — closed 07-20/07-21. August redesigned the mechanism itself: 08-15 replaced a blanket hourly `revalidate=3600` (a guaranteed ~72 regenerations/day given constant crawler traffic) with a due-check cron, and moved blog pagination to path-based `/blog/:section/p/:page` so both prerender. Static prerendering then surfaced a pre-existing bug 08-17: `loading.tsx` Suspense boundaries let `notFound()` commit under HTTP 200 on three production routes, fixed via route groups plus per-item cron busts. Friction continued into 08-21/08-22 with a nested-cache staleness race (`makeBlogPageCache` reading `getSectionPageCount` from inside its own callback) that required restoring a previously-removed empty-page guard. ## Decisions of note

- **2026-06-08 — Manifest-driven importer architecture** — `project.json` + direct Prisma + direct Blob writes, over an admin HTTP API (needs a live server, random blob keys) or raw-markdown parsing (no stable schema). [source](dev-journal/2026-06-08.md)
- **2026-06-10 — `IP_HASH_SECRET` missing → global-bucket fallback, not fail-open** — some rate limiting beats none; the constant `"global"` key carries no PII. Accepted a reintroduced admin-lockout DoS risk as the tradeoff. [source](dev-journal/2026-06-10.md)
- **2026-06-28 — Flat `offers` price-points array for JSON-LD** — single `Offer` for one entry, `AggregateOffer` for 2+; free is explicit `"0"`, absent means unknown. [source](dev-journal/2026-06-28.md)
- **2026-06-29 — `robots.ts` allow-all, no bad-bot blocklist** — robots is advisory and scrapers spoof UAs; the edge is the real boundary. Welcomes AI-citation crawlers deliberately. [source](dev-journal/2026-06-29.md)
- **2026-07-07 — Continuous cross-section gallery + hand-rolled pointer-event zoom** — rejected `@use-gesture/react` and off-the-shelf lightbox libraries; pure geometry lives in a unit-tested `zoom.ts`. [source](dev-journal/2026-07-07.md)
- **2026-07-07 — Cut Vercel CPU by making pages static** — resolved canonical origin from env instead of `headers()`; moved theme to client-side localStorage, dropping `cookies()` from the root layout. [source](dev-journal/2026-07-07.md)
- **2026-07-17 — Guides as a new top-level entity, project referenced by slug not FK** — `/guides/:slug`, not nested under blog; an FK would cascade-delete guides on project reimport. [source](dev-journal/2026-07-17.md)
- **2026-07-17 — `CacheMissError` thrown on cache miss, not short-TTL negative caching** — direct fix for the prod stale-404 incident where `unstable_cache` had durably cached `null`. [source](dev-journal/2026-07-17.md)
- **2026-07-20 — Split IndexNow `submitted` into `attempted`/`accepted`** — stops reporting success when every batch actually 403'd. [source](dev-journal/2026-07-20.md)
- **2026-07-26 — `requireAdmin()` second lock on all 21 admin handlers** — closes the matcher-bypass incident from both sides; middleware stays the outer layer, not the only layer. [source](dev-journal/2026-07-26.md)
- **2026-08-12 — Discontinued projects stop selling but stay reachable** — bare storefront label, no repeated CTA; a "Discontinued" badge next to a "Get on" button reads as a mixed message regardless of technical accuracy. [source](dev-journal/2026-08-12.md)
- **2026-08-15 — Legacy routing moved to `next.config.ts`, not tightened middleware** — Vercel compiles `redirects()`/`rewrites()` into its routing layer with zero function invocation and they run ahead of middleware entirely; rejected a tighter matcher as the same unanchored-extension shape that caused the 07-26 bypass. [source](dev-journal/2026-08-15.md)
- **2026-08-15 — `/og` route deleted for `scripts/generate-og-card.tsx`** — the route 404'd in production yet bundled Satori + resvg WASM and gated only on `NODE_ENV`; output verified byte-identical. [source](dev-journal/2026-08-15.md)
- **2026-08-21 — Admin pagination gets its own parser with no probe-cost ceiling** — `parseAdminPageParam` diverges from the public `parsePageParam`/`MAX_PAGE` because that ceiling exists to bound a public crawler's probe surface, which doesn't apply to an authenticated, single-user admin. [source](dev-journal/2026-08-21.md)
- **2026-08-21 — Reduced motion handled globally via `MotionConfig`, not a per-caller hook** — a hook shape would leave several call sites (chevron rotate, accordion height, `ThemeToggle`'s `layoutId`) unprotected and forgettable. [source](dev-journal/2026-08-21.md)
- **2026-08-21 — `IP_HASH_SECRET` rotation rejected** — Vercel has no native rotation mechanism, epoch-salting with a retained base secret changes nothing for the secret-holder, and Vercel's own request logs hold the raw IP regardless, joinable on timestamp. [source](dev-journal/2026-08-21.md)
- **2026-08-24 — Definition lines sliced from source by mdast offset, not rebuilt from parsed fields** — rebuilding `[label]: url "title"` from `node.label`/`url`/`title` needed escaping for a `"` inside a single-quoted title and angle-brackets for a URL containing whitespace; slicing `markdown.slice(start.offset, end.offset)` removes the class rather than handling the instances. [source](dev-journal/2026-08-24.md)
- **2026-08-24 — `truncateBody` relocated to `src/lib/content/markdown.ts`** — making the truncation cut code-block-aware needs the parser, and `src/lib/utils/format.ts` is imported by a `"use client"` component (`PostForm.tsx`), so the smaller-diff option of importing an offset helper into `format.ts` would have shipped `unified` and Shiki into a client bundle. Code-block detection walks mdast `code` nodes rather than scanning fence delimiters, covering tilde fences, indented fences, info strings, four-space blocks, and fences nested in lists or blockquotes. [source](dev-journal/2026-08-24.md)

- **2026-07-17 — Prod stale-404** — a published, listed post 404'd on its detail page; root cause a durably cached `null` in `unstable_cache` predating the row. Fixed via throw-on-miss across all four detail lookups. [source](dev-journal/2026-07-17.md)
- **2026-07-24 — Invalid Atom feed and no autodiscovery at all** — the Express→Next migration had dropped `<link rel="alternate">` entirely; the feed was also missing a feed-level `<author>` (RFC 4287) and had dropped `<subtitle>`/`<icon>`/`<rights>`. All restored. [source](dev-journal/2026-07-24.md)
- **2026-07-26 — Admin auth gate skippable via a dotted path** — `config.matcher`'s extension-exclusion group was unanchored at both ends, so a path merely containing an excluded substring bypassed the gate entirely. Not exploitable in practice (integer-only `[id]` routes reject a dotted segment before DB access), but the whole authorization story for `/api/admin/*` rested on that incidental fact. [source](dev-journal/2026-07-26.md)
- **2026-08-13 — First OG card rendered with a hard horizontal seam** — Satori doesn't parse 8-digit hex colors, so a radial gradient rendered near-solid; misdiagnosed by eye as a geometry problem before the color-parsing root cause was found. [source](dev-journal/2026-08-13.md)
- **2026-08-17 — Soft 404 across three production routes, serving HTTP 200** — a `loading.tsx` Suspense boundary let React commit a 200 and stream the shell before `notFound()` could run, and a status can't be revised after the first byte. Fixed by scoping list skeletons into route groups and deleting the three detail-route boundaries; regression risk judged high and invisible, hence a filesystem guard test. [source](dev-journal/2026-08-17.md)
- **2026-08-21 — Second-layer admin defense gap, found by an external review mid-session** — `adminEditMetadata` logged and fell back on an unauthenticated request but never stopped the page body from rendering; a prior session's fix had covered two pages and missed that the same class extended to four edit pages plus the `/admin` dashboard root. [source](dev-journal/2026-08-21.md)
- **2026-08-22 — `errorDetails`' JSON-safety hole introduced by the prior session's own remediation** — the 08-21 widening from `{message, stack}` to a full property spread silently voided the function's "JSON-safe" guarantee; no live defect existed yet, found by reviewing the fix itself rather than the original bug. [source](dev-journal/2026-08-22.md)
- **2026-08-24 — Reference-style links rendered as literal brackets in every blog list excerpt** — `truncateBody` slices the raw body at ~700 chars while link reference definitions are authored at the bottom of a post, so remark parsed `[the opener][series]` as a `linkReference` with no matching definition and fell back to the source text. Affected 11 tech posts including the four most recent; inline code and fenced blocks were unaffected, being self-contained. Fixed by appending `extractDefinitions(post.body)` to a truncated preview in `PostCard`. A latent sibling — the paragraph cut landing inside a fenced block whose blank line precedes the 700-char mark — was fixed in the same pass despite no post triggering it. [source](dev-journal/2026-08-24.md)
