# Rolling History — last 90 days (through 2026-09-28)

## Themes

- **Admin auth: from single gate to layered, then CSRF-hardened** — July opened with Next's middleware as the sole admin authorization boundary, correct on the framework version but against Vercel's own guidance; it converted into a real incident 07-26 when the matcher's unanchored extension exclusion let any path merely containing an excluded substring (`.json` contains `.js`) skip the gate — closed by a `requireAdmin()` second lock on all 21 handlers plus a `SESSION_SECRET` 32-char floor. August tightened the same boundary almost weekly: 08-12 closed an unauthenticated DB read in `generateMetadata`, 08-15 narrowed the middleware matcher to `/admin*`+`/api/admin*` with no catch-all, 08-21 found the second-layer guard covered only page `<title>`s and extended `requireAdminPageSession` to all seven data-reading pages, and 08-22 fixed a contract test that couldn't fail for an unawaited guard call. September closed the last gap: 09-27 added a CSRF check inside `requireAdmin()` itself across all 21 write handlers, with `adminAuthContract.test.ts` now pinning every one to a 403 on a cross-site request, plus a `parseJsonBody` content-type check as a second layer. [source](dev-journal/2026-07.md) [source](dev-journal/2026-08.md) [source](dev-journal/2026-09-27.md)
- **Cache/revalidation precision and honest reporting** — July split coarse `blog-{section}`/`projects` tags into per-slug detail tags plus aggregate `*-pages` tags (07-07), then found the same "success report that doesn't reflect what was verified" defect class independently in the guides revalidate endpoint (07-19) and IndexNow's submit-count reporting (07-20), closing both by returning what was actually confirmed. August redesigned scheduled-content revalidation from hourly `revalidate=3600` to a daily due-check cron (08-15) — which surfaced a production soft-404 incident (08-17: `loading.tsx` Suspense boundaries served three routes as 200 while rendering the 404 page, found by diffing `.next/server/app/**/*.meta` files) and was then hardened (`Promise.allSettled`, wider `WINDOW_HOURS`, missing indices). September extended the same "each due item busts its own tag" discipline to guide topic hubs (09-15: `revalidateGuideTopicHubs`) and to the new `getRecentPosts` cache backing `llms.txt`'s Posts section. [source](dev-journal/2026-07.md) [source](dev-journal/2026-08.md) [source](dev-journal/2026-09-15.md)
- **Guides: built in a day, reviewed hard, extended two months later** — 07-17 built the entire feature end to end across five sessions — schema, importer, admin CRUD, public pages — and fixed a live incident in the same session (a durably-cached `null` in `unstable_cache` causing stale 404s on published posts) by throwing on cache miss instead of negative-caching. The 07-18 review (~39 findings) was resolved same day in 8 phases with 8 items deliberately deferred or skipped with recorded reasons; 07-19's regression audit of those fixes found the remediation had introduced its own issues (an over-widened login exemption) and a repeating "sweeps that stopped short" pattern, several of which were never revisited. September reopened guides twice: 09-14 added a markdown twin and `BreadcrumbList` JSON-LD, and 09-15 routed the cron to bust each due guide's topic hub, fixing a bug where due guides never appeared on their hub despite rendering at the right route. [source](dev-journal/2026-07.md) [source](dev-journal/2026-09-14.md) [source](dev-journal/2026-09-15.md)
- **Scheduled-post lifecycle: notice, single-resolver, public preview** — Aug 31 shipped `ScheduledPostNotice`, a 200 response reusing the 404's design (`noindex`) instead of a pinned 404, sharing `getPostBySlug`'s cached row so live and scheduled views can't disagree. Sep 1 found a real race (two independent `currentDatetimeString()` reads let a post crossing its `datetime` pin a 404) and fixed it by collapsing both detail routes onto one `resolvePost` call, deleting three now-dead accessors. Sep 3 added a public `/override-preview` route (session-gating added then reversed mid-session on Roland's call) with its own narrowing wrapper, a 307 (not 308) live-redirect, and a tagged hit log distinguished from admin audit logging. [source](dev-journal/2026-08-31.md) [source](dev-journal/2026-09-01.md) [source](dev-journal/2026-09-03.md)
- **Post/guide description pipeline: rename and the drift bugs it exposed** — Sep 14 renamed `Post.summary` to `Post.description` end to end and added frontmatter `description:`, routing every write through a planned resolver. Sep 15's review found three ways the PUT route silently lost an authored description (toggle-only payload, any body edit, `imageUrl: undefined` skipped) and fixed all three same day, plus a 161-char off-by-one and unvalidated bulk-upload descriptions. Sep 16 unified the rules into `descriptionRules.ts` and briefly reintroduced the unsaveable-post bug via an uncapped title fallback (fixed same session). Sep 23 closed the last gap — a paste that bypassed live-typing validation — with a collapsed-count, no-`maxLength`, Save-gated field, and fixed titles/descriptions reaching the DB with un-collapsed whitespace because file-write paths stored the parsed field rather than the schema's normalized output. - **Store CTAs, own-app flag, and frozen slugs** — August's discontinued-project CTA work (08-12: bare storefront label, no repeated CTA once an app stops selling) set the precedent September's `isOwnApp` flag followed: Sep 13 added an explicit boolean (rejected deriving "creator" from the free-text `role` field or a hostname-only rule that accidentally excluded `itunes.apple.com`-linked apps), with badge artwork keyed by `bucket`. Sep 26's full-codebase review (121 issues, six partitions) then froze slugs for posts and projects entirely — create schemas require `canonicalSlug`, update schemas drop `slug`, post files need an explicit `slug:` line — closing the class of bugs a title-derived or editable slug could cause against guide/topic references. - **Gallery/lightbox gesture engineering and Vercel compute cuts (July)** — the continuous cross-section gallery and hand-rolled pointer-event lightbox zoom shipped 07-07 with two gesture bugs same day; both were revisited 07-08 because framer-motion's `onDragEnd` fires a frame after the browser's click (via `frame.postRender`), so click-vs-drag suppression moved to raw `pointerdown`/`pointerup` capture, and an "accelerated" swipe bug traced to a `key` change remounting the carousel's `MotionValue`s. The same week, 07-07 cut Vercel CPU by removing `cookies()`/`headers()` dynamic-rendering forcers (theme moved to client localStorage, canonical origin resolved from env), and 07-17's session 5 added a narrow bot-probe short-circuit in middleware after diagnosing a middleware/function CPU split from an analytics screenshot. [source](dev-journal/2026-07.md)
- **Sandbox/local-verification constraints, a running limitation** — a consistent ceiling recurs every month: the sandbox can't reach Google Fonts (`next build` fails at font optimization — 07-06, 07-07, 07-24, and again 09-16 with `yarn build`), can't bind a listening socket, and unattended scheduled-task sessions can't start a dev server at all (09-15, 09-26 — `preview_start` refuses even mid-conversation). The response has stayed the same: verify via `tsc` + the full suite + lint on touched files, hand build/browser verification to Roland, and rely on `.claude/launch.json` (added 07-24) so the integrated preview panel can launch what the sandbox can't bind directly. Bash hook constraints compounded this in September: no pipe chains, `rg -g`/`--glob` and `rg --files -g` are blocked, and any command shape containing ` .env ` is blocked outright (09-23), including inside commit messages.
