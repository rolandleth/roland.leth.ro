- **2026-06-10 — Content-addressed blob keys** — `SHA256[:12]`: same bytes = same key (reuse), changed bytes = new key (CDN cache-bust); overwriting stable URLs with new content was the defect. [source](dev-journal/2026-06-10.md)

Gracefully degrades on Firefox/older Safari. [source](dev-journal/2026-06-29.md)
- **2026-07-05 — `llms.txt` filters discontinued projects** — LLMs can't cite dead apps as live; cost is discontinued apps absent from the agent overview. Reversibility: easy. [source](dev-journal/2026-07-05.md)
- **2026-07-05 — `JsonLdScript` prop → `Record<string, unknown> | null`** — `undefined` now throws via `safeJsonLdString`; aligns with no-silent-suppression rule. [source](dev-journal/2026-07-05.md)
