## Session 1

### Decisions

- **Guard disarm after a successful save** — `useAdminResource` returns `hasSucceeded`, set just before `goBackToAdmin()`, and each form passes `(dirty terms) && !hasSucceeded` to `useUnsavedChangesGuard`. Rejected: moving the guard into `useAdminResource`, which would force every form to reorder its hooks (the `isDirty` value comes after the resource hook) and tie the two hooks together; re-baselining `useFormState`, which would also mark the state clean on a later failure path.
- **Return target after a save or delete (user's call)** — a create goes to the tab's first page with no search, and an edit or delete keeps the remembered search and page (`adminListUrlFor(tab, { isAfterCreate })`). Rejected: always dropping the search, which undoes the 09-27 "back to page 3 of a search" feature; fixing only the comment.
- **Login gets both new checks** — `refuseCrossSiteWrite` before the rate limiter, so cross-site POSTs can't spend the admin's per-IP bucket, then the new `refuseNonJsonBody` (extracted from `parseJsonBody`). Login keeps its own parse and its "Missing email or password" message rather than switching to `parseJsonBody`.
- **Upload key extension from the sniffed type** — `adminUploadKey(filename, mime)` strips the last extension and appends the one mapped from `ImageMime`; `detectImageMime` now returns that union. Chosen over keeping the client filename: a downloaded copy opens by its extension.
- **One CLI contract for every script** — `flagsProblem(parsed, knownFlags, valueFlags)` in `src/lib/import/cliArgs.ts` covers unknown and repeated flags; each script keeps its own positional-count check because those differ (one folder, any filters, none). `resolveSectionArg` in `src/lib/import/sectionArg.ts` returns `{ section } | { problem }` instead of throwing, which removes the `simplified:` copy in `init-post-slugs.ts`. `prune-uploads` now refuses bare words as "Unexpected argument(s)".
- **`isMissingPathError` in `src/lib/import/fsErrors.ts`** — `discoverProjectDirs` shows "No staging directory" only for `ENOENT` and reports any other `readdir` error as it is. Kept out of `src/lib/utils/`, which reaches the client bundle.

### Tradeoffs

- **Contract test lists which handlers read JSON (`jsonBodyMethods`)** — gained a 415 check per JSON-body handler that catches a raw `request.json()`, at the cost of one more field to keep in step when a route is added (the route-list test still fails on a new file). Reversibility: easy.
- **Each cross-site header tested on its own** — the contract now sends `Sec-Fetch-Site` alone and `Origin` alone, so a handler that checks only one fails; this doubles the run count of that block. Reversibility: easy.

### Incidents / Bugs

- **Unsaved-changes prompt fired after a successful save** — `useFormState.isDirty` never resets, so the guard stayed on until the list rendered. A click or tab close in that gap warned about stored edits, and after a full-page-load fallback, clicking Stay left Save disabled for good. Fixed with `hasSucceeded`. To prove the `PostForm` test, the fix was removed and the test failed.
- **Stray file created in the project root** — a mistaken Write created `private/tmp/placeholder`; removed right away and never staged.

### What did I, Claude Code, or my agents learn from this

- **Check a subagent finding against the code before writing it down** — one analyzer reported that a delete could strand the admin on an empty page past the end; `AdminPagination` already redirects when `page > totalPages`. The two analyzers disagreed, and one `rg` settled it.
- **To prove a test with a mutation, remove only the fix** — the first attempt appended `&& false`, which turns the guard off completely and proves nothing. The right mutation removes only `&& !hasSucceeded`.
- **sonarjs flags `/tmp/...` literals even in pure path tests** — `sonarjs/publicly-writable-directories` fired on a path that never touches the disk; use a neutral relative path in tests.
