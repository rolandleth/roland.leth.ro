## Learnings

- **Measure copy in a browser, not character estimates** — headline-width estimates were off by a line at 1,040px. [source](dev-journal/2026-10-02.md)
- **Lines from an app's `marketing/copy/` files are generated, not necessarily Roland's** — provenance notes mark them adopted. [source](dev-journal/2026-10-02.md)
- **The browser pane lies about motion and hit targets** — frozen transitions, smooth scroll that never moves, pending scrolls that finish when the page grows. [source](dev-journal/2026-10-02.md) [source](dev-journal/2026-10-09.md)
- **Target a database by env, not by file** — `dotenv/config` won't override a set variable, so `env DATABASE_URL=… yarn db:push` hits dev. [source](dev-journal/2026-10-03.md)
- **Limits come from the docs, not from memory** — the 4.5 MB body cap and Blob's 10 GB transfer cap both shaped the storage choice and were first stated from memory. [source](dev-journal/2026-10-03.md)
- **Keep script logic testable** — `scripts/` can't run in a session (they read `.env`), so the post import moved into `postMediaRun.ts` with injected reader and store. [source](dev-journal/2026-10-03.md)
- **Check `node --version` before reading a startup stack trace as a dependency fault.** [source](dev-journal/2026-10-05.md)
- **Prove a working copy equals a commit** — `git diff --stat <commit>` for tracked files; `git hash-object` against `git rev-parse <commit>:<path>` for untracked ones. [source](dev-journal/2026-10-05.md)
- **Framer MotionValue semantics** — `animate` stops the value's running animation; a stopped one calls `onStop`, never `onComplete`. [source](dev-journal/2026-10-09.md)
- **Validate a manifest with the import's dry run** — no database or Blob credentials needed. In the sandbox tsx's CLI fails on its IPC pipe (`listen EPERM`); `node --import tsx scripts/import-projects.ts <name> --dry-run` runs the same script. [source](dev-journal/2026-10-11.md) [source](dev-journal/2026-10-15.md)
- **Env-dependent suites in a worktree** — pass `NEXT_PUBLIC_SITE_URL` and a dummy `DATABASE_URL` on the command line. [source](dev-journal/2026-10-11.md)
- **A worktree session can't write into the main checkout** — a hook blocks Write and Edit there, even in gitignored `scripts/imports/`; Bash `cp` slips past it and shouldn't be used to go around it. [source](dev-journal/2026-10-15.md)
- **Check claims about what a screen shows against the app's source before flagging copy.** [source](dev-journal/2026-10-15.md)
