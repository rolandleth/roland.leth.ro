## Learnings

- **Measure copy in a browser, not with character estimates** — a line-count estimate was off by a whole line at 1,040px; a real test page settled it. [source](dev-journal/2026-10-02.md)
- **Target a database by env, not by file** — `prisma.config.ts` loads `.env` via `dotenv/config`, which doesn't override an already-set variable, so `env DATABASE_URL=… yarn db:push` can hit dev without touching `.env`. [source](dev-journal/2026-10-03.md)
- **Staging around another session's uncommitted work** — a filtered `git apply --cached` where hunks separate; otherwise build HEAD plus the new changes in the scratchpad and stage with `git hash-object`/`git update-index --cacheinfo`. [source](dev-journal/2026-10-03.md)
- **Limits come from the docs, not from memory** — the 4.5 MB body cap was named from memory and checked only later; Blob's 10 GB transfer cap surfaced only when Roland asked. [source](dev-journal/2026-10-03.md)
- **A worktree can borrow the main checkout's tools by absolute path** (`node_modules/.bin`) for tsc/ESLint/Vitest; only env-dependent suites fail. [source](dev-journal/2026-10-03.md)
- **Check `node --version` before reading a startup stack trace as a dependency fault** — an `ERR_REQUIRE_ESM` error named Vite/Vitest, but the cause was Node 18 on the path. [source](dev-journal/2026-10-05.md)
- **Proving a working copy equals a commit** — `git diff --stat` for tracked files; `git hash-object` vs `git rev-parse <commit>:<path>` for untracked ones. [source](dev-journal/2026-10-05.md)
- **Framer MotionValue semantics** — a stopped animation calls `onStop`, never `onComplete`; `useTransform` over multiple MotionValues recomputes on any `set`. [source](dev-journal/2026-10-09.md)
- **The dev database isn't reachable from the sandbox** — Postgres.app rejects the sandboxed dev server with "trust" auth; database-backed checks need Roland's own `yarn dev`. [source](dev-journal/2026-10-11.md)
- **Validate a manifest with the import's dry run**, not a hand-rolled `tsx` check — no database or Blob credentials needed. [source](dev-journal/2026-10-11.md)
- **`scripts/imports/` is gitignored and lives only in the main checkout** — a worktree has none; Bash `cp` can slip past the write-blocking hook but shouldn't be used to route around it. [source](dev-journal/2026-10-15.md)
- **tsx's CLI can't run in the sandbox** (opens an IPC pipe, `listen EPERM`) — `node --import tsx` runs the same script with no socket. [source](dev-journal/2026-10-15.md)
- **A day's open threads go stale** — a thread already closed on 10-15 was quoted on 10-17 as if still open; `_history.md` had the current state. [source](dev-journal/2026-10-17.md)
- **Dummy env vars run the env-gated suites in a worktree** — every such test mocks Prisma; all 208 files passed that way. [source](dev-journal/2026-10-19.md)
- **Check the sibling repo before acting on a cross-repo answer** — Digest's own `brief.md` recorded the opposite of the owner's first answer on terms; raising it produced a principled rule instead. [source](dev-journal/2026-10-19.md)
- **A hook blocks `git worktree add`** — use EnterWorktree, then fast-forward it to local `release`. [source](dev-journal/2026-10-19.md)
