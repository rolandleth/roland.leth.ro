## Learnings

- **Measure copy in a real browser, not character estimates** — line-wrap estimates were off by a whole line at 1,040px. [source](dev-journal/2026-10-02.md)
- **Lines pulled from an app's generated `marketing/copy/` files aren't automatically Roland's own wording** — mark provenance as adopted vs. his. [source](dev-journal/2026-10-02.md)
- **The browser pane lies about motion and hit targets** — frozen transitions, stale screenshots right after a click, scaled-emulation artifacts. [source](dev-journal/2026-10-02.md)
- **Target a database by env var on the command line, not by file** — `prisma.config.ts`'s `dotenv/config` won't override an already-set variable. [source](dev-journal/2026-10-03.md)
- **Staging around another session's uncommitted work**: a filtered `git apply --cached` where hunks separate; `git hash-object` + `git update-index --cacheinfo` where they don't. [source](dev-journal/2026-10-03.md)
- **Limits belong in docs, not memory** — the 4.5 MB body cap and Blob's 10 GB transfer cap were each initially misremembered or raised too late. [source](dev-journal/2026-10-03.md)
- **A script that reads `.env` directly can't run from a session** — inject a reader/store instead so it's testable. [source](dev-journal/2026-10-03.md)
- **A worktree inside the main checkout can call `node_modules/.bin` by absolute path** for tsc/ESLint/Vitest; only env-dependent suites fail. [source](dev-journal/2026-10-03.md)
- **Check `node --version` before reading a startup stack trace as a dependency fault.** [source](dev-journal/2026-10-05.md)
- **Proving a working copy equals a commit**: `git diff --stat` for tracked files, `git hash-object`/`git rev-parse` for untracked ones. [source](dev-journal/2026-10-05.md)
- **Framer's `animate()` stops an animation already on that value and calls `onStop`, never `onComplete`, for the stopped one.** [source](dev-journal/2026-10-09.md)
- **Check a fresh browser tab after multi-edit hot reloads** — a stale tab can throw on an undefined reference a fresh load doesn't. [source](dev-journal/2026-10-09.md)
- **The dev database isn't reachable from the sandbox** (Postgres.app rejects sandboxed trust auth) — database-backed checks need Roland's own `yarn dev`. [source](dev-journal/2026-10-11.md)
- **Validate a manifest with the import script's own `--dry-run`**, not a hand-rolled check. [source](dev-journal/2026-10-11.md)
- **`scripts/imports/` is gitignored and exists only in the main checkout** — Bash `cp` can slip media there past a Write/Edit hook; don't use it to bypass the hook. [source](dev-journal/2026-10-15.md)
- **tsx's CLI can't run in the sandbox** (opens an IPC pipe) — `node --import tsx` runs the same script with no socket. [source](dev-journal/2026-10-15.md)
- **A day's open threads go stale** — quoting an old one gave a wrong answer; `_history.md` had the current state. [source](dev-journal/2026-10-17.md)
- **A hidden Browser pane pauses CSS animations mid-frame** — `tabs_select` before screenshotting. [source](dev-journal/2026-10-17.md)
- **Dummy env vars run env-gated test suites in a worktree** when every such test mocks Prisma. [source](dev-journal/2026-10-19.md)
- **A synchronous loop can outrun the test timeout** — assert elapsed time to pin a loop bound instead. [source](dev-journal/2026-10-19.md)
- **Check the sibling app repo before acting on a cross-repo answer** — Digest's `brief.md` recorded the opposite of the owner's first answer on terms. [source](dev-journal/2026-10-19.md)
- **A hook blocks `git worktree add`** — use EnterWorktree, then fast-forward to local `release`. [source](dev-journal/2026-10-19.md)
- **Git in another repo is the owner's to run from here** — the Bash hook refuses `git -C` outside `.claude/worktrees/`. [source](dev-journal/2026-10-19.md)
