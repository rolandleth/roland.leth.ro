## Learnings

- **Measure copy in a browser, not character estimates** — the writer agent's headline-width estimates were off by a whole line at 1,040px; a test page in the real font settled it. [source](dev-journal/2026-10-02.md)
- **Lines from an app's `marketing/copy/` files are generated, not necessarily Roland's own** — Continuum's old headline was wrongly attributed; provenance notes now mark such lines adopted. [source](dev-journal/2026-10-02.md)
- **The browser pane lies about motion and hit targets** — frozen transitions, smooth scroll that never moves, stale screenshots right after a click, scaled emulation drawn into a corner. [source](dev-journal/2026-10-02.md)
- **Target a database by env, not by file** — `prisma.config.ts`'s `dotenv/config` won't override an already-set variable, so `env DATABASE_URL=… yarn db:push` hits dev without touching `.env`. [source](dev-journal/2026-10-03.md)
- **Staging around another session's uncommitted work** — a filtered `git apply --cached` where hunks separate; otherwise build HEAD plus only the new changes in the scratchpad and stage via `git hash-object -w` + `git update-index --cacheinfo`. The working tree stays untouched. [source](dev-journal/2026-10-03.md)
