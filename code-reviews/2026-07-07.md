# Code Review — 2026-07-07

## Issues and Observations

- **[src/app/api/blog/[section]/[slug]/md/route.ts — GET]** — `Cache-Control: public, s-maxage=3600, stale-while-revalidate=86400` is set at the response layer, but `loadPost` is the only cache-tagged path in this route. A post edit revalidates the `post-<section>-<slug>` tag inside Next's data cache; the CDN-cached `.md` response outlives that bust by up to an hour. Same shape as the `llms.txt` open thread in `dev-journal/2026-07-05.md` (dual cache layers). Either drop the route cache in favour of the tag, or set `s-maxage=0, stale-while-revalidate=86400` so the CDN only serves stale while it refreshes from the tag-backed origin.
- **[src/lib/content/postMarkdown.ts — buildPostMarkdownFile]** — The frontmatter round-trip guarantee is documented for "any body with no leading blank lines" but `PostDetail.body` is arbitrary DB content — nothing in `route.ts` or the writer trims a leading `\n` before emission. A stored body that begins with a blank line would silently break re-import (`parseFrontmatter` strips `^[\r\n]+` from the body it returns, so `parsed.body !== post.body`). Low probability (importer already strips), but the round-trip claim is stronger than the code enforces.

## Architecture & Coupling

- **[src/lib/content/postMarkdown.ts — import from lib/import/frontmatter]** — Introduces a `content → import` dependency to share `escapeYamlDoubleQuoted`. Already recorded as a watch-out in `dev-journal/2026-07-06.md`; noting here so it doesn't slip past the next reviewer. Fine while `frontmatter.ts` stays pure of `next/*`/IO deps.
- **[src/proxy.ts — matchLegacyRedirect]** — Extraction is clean (each pattern independent, hoisted regexes, `search` appended by the caller), but the helper now silently owns the invariant that patterns are mutually exclusive. A future pattern that overlaps another (e.g. someone adds a `/tech/feed` rule and forgets `/(tech|life)?/feed` already covers it) would win by declaration order with no test to notice. A single "no two patterns match the same path" property test would lock this in.

## Observability

- **[src/app/api/blog/[section]/[slug]/md/route.ts — notFoundResponse]** — Invalid-section and missing-post cases return the same generic `Not Found` body with no log line. Consistent with the feed-route shape (intentional per the module comment), but a spike of `.md` 404s (e.g. a renamed post whose old `.md` URL is being crawled) would be indistinguishable from ordinary bot noise in production logs. Minor — the feed route inherits the same gap.

## Missing Tests

- **[src/app/api/blog/[section]/[slug]/md/route.test.ts]** — No coverage that the `.md` route honours `loadPost`'s draft (`published: false`) and future-`datetime` filters. `loadPost` is mocked to `null` for the miss case, which proves the 404 path but not that the *route* actually asks for the published-and-past view. A cheap regression backstop: assert `loadPost` was called (any args) on the happy path, so a future refactor that bypasses `loadPost` in favour of a raw prisma call can't silently expose drafts.
- **[src/app/api/blog/[section]/[slug]/md/route.test.ts]** — No test for a body that byte-for-byte round-trips through `parseFrontmatter` (the writer's central claim is a round-trip; the unit test in `postMarkdown.test.ts` covers it, but the route test is where an integration regression would surface). Also no test for a body containing `---` (thematic breaks) to prove non-greedy frontmatter parsing on the read side isn't fooled by content inside the body.
- **[src/proxy.test.ts — blog markdown rewrite]** — No coverage that a `.md` request under `/blog/:section/:slug.md` still hits the admin-auth gate branches correctly *for admin paths* (i.e. that adding the new rewrite didn't reorder the guard). The suite covers admin protection in isolation and `.md` rewrite in isolation, but not the interaction; unlikely to break, but the ordering comment ("Rewrites don't re-run middleware, so the target skips the auth gate above harmlessly") is the exact kind of invariant a targeted test could pin.

## Risk Assessment

**Low.** The `.md` export is additive — a new route + a new alternate `<link>`, no shape change to the existing HTML post view. Middleware widened its contract (new rewrite branch, `matchLegacyRedirect` extraction) but the test suite already asserts the previously-passing paths plus a solid set of new edge cases (empty cookie, case sensitivity, dotted slugs, cron pass-through, `/api/adminx` boundary). Featured-projects 3-up grid is a two-line change with an aligned `sizes` hint. The only latent concern with real teeth is the CDN cache mirroring the `llms.txt` staleness pattern that already sits open on the journal.
