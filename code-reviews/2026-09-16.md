## Issues and Observations

- [x] **src/lib/content/postDescription.ts — `derivedDescription`** — The title fallback returns `post.title` verbatim: uncapped, while `postCreateSchema` allows a 200-char title and caps `description` at 160. A prose-less body (lone code fence, bare image) with a 161–200-char title stores an over-cap description, and every later save of that post 400s. This is the exact failure `9627860` and `22ee713` were written to remove, reintroduced one commit later by `02da64f`. **Resolved 2026-09-16** (`aef0665`): the fallback runs through `collapseWhitespace` then `capDescription`, the same helper `deriveDescription` uses.
- [x] **src/lib/content/markdown.ts — `deriveDescription` docblock (L258-263)** — It states the result "never exceeds `DESCRIPTION_MAX_CHARS`" and explains why that matters for the edit form. True of this function, false of the value actually stored, because `derivedDescription` wraps it and the title escapes the guarantee. **Resolved 2026-09-16** (`aef0665`): the guarantee now lives on `capDescription`, where both branches reach it, and `deriveDescription`'s doc points at the fallback.
- [x] **src/lib/import/frontmatter.ts — `quotedFrontmatterLine` / `escapeYamlDoubleQuoted`** — Escapes `\` and `"` but not newlines, while `parseFrontmatter` reads line by line. `439ef56` closed this for descriptions via `collapsedWhitespace`; `postCreateSchema.title` and `guideFields.title` are *not* collapsed, and all three writers put the title through this helper. One newline in a title corrupts `/blog/:section/:slug.md` and `/guides/:slug.md` — public routes. **Resolved 2026-09-16** (`aef0665`): titles collapse at input like descriptions, per the 2026-09-15 "fix at input, not export" call, and `quotedFrontmatterLine` collapses too for rows written before that rule.
- [x] **src/lib/content/postDescription.ts — `derivedDescription`** — Same fallback also bypasses `collapsedWhitespace`, so it is the delivery path for the newline above. **Resolved 2026-09-16** (`aef0665`).

That branch fires precisely when there is no space in the first 160 chars — CJK prose, emoji runs. **Resolved 2026-09-16** (`aef0665`): `sliceCodePoints` drops an unpaired high surrogate; tested with an emoji run and space-free CJK.
