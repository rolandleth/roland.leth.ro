# Code Review — 2026-06-30

## Issues and Observations

- **src/lib/content/projectJsonLd.ts — `buildOfferNode` sort** — `Number(a.price) - Number(b.price)` silently yields `NaN` for non-numeric prices (future `"free"` sentinel, accidental whitespace, locale-formatted `"1,99"`), and `NaN` comparators leave the sort undefined — `lowPrice`/`highPrice` can be wrong with no warning. Validate numerically at the boundary or fall back to the array-of-Offers shape on parse failure.
- **src/lib/content/projectJsonLd.ts — `buildOfferNode` AggregateOffer count** — `offerCount` is raw `offers.length`; no dedupe by `(price, priceCurrency, billingPeriod)`. Two App Store rows with identical price/currency would inflate the count. Minor; flag if the manifest path ever produces near-duplicates.
- **src/lib/content/projectJsonLd.ts — `buildOfferNode` priceCurrency** — In the single-currency multi-offer branch, `priceCurrency` is read from unsorted `offers[0]` rather than `sorted[0]`. Correct by construction today, but reads as fragile and obscures intent.
- **src/lib/content/postJsonLd.ts — `absoluteImageUrl`** — `startsWith("http")` does not treat `//cdn.example/img` (protocol-relative) or `data:` URLs as absolute, so both would be wrongly re-prefixed with `base`. Anchor to `^https?://` or `URL`-parse.
- **eslint.config.mjs — `no-restricted-syntax` JSXAttribute selector** — Catches the JSX attribute form; the file-scoped exception is narrowly scoped to `JsonLdScript.tsx`. Residual gaps: `React.createElement("script", { dangerouslySetInnerHTML: … })` and `<script {...props} />` with `dangerouslySetInnerHTML` inside `props` would slip through. Exotic for this codebase but the inline comment claims "the chokepoint can't be bypassed" — either tighten the selector (e.g. `Property[key.name="dangerouslySetInnerHTML"]`) or soften the claim.
- **src/app/llms.txt/route.ts — `GET`** — Iterates `getProjectsGalleryCached()` which includes `isDiscontinued: true` projects (ordered last, not filtered). The file header pitches itself as "actually live"; discontinued apps will be cited by LLMs as current. Filter or document.
- **src/app/robots.ts — CCBot disallow** — `["/about", "/life"]` is a *prefix* match, so any future path starting with `/life` (e.g. `/lifestyle`) is also blocked. Tighten to exact paths or document.
- **src/lib/client/navigationType.ts — event type cast** — `(event as { navigationType?: string }).navigationType` widens to `string`. A typo of `"traverse"` elsewhere would silently make `cameFromBackForward` always `false`. Narrow to the `'reload' | 'push' | 'replace' | 'traverse'` union.
- **src/lib/client/navigationType.ts — listener stacking** — Idempotency relies on a module-level `isInstalled` flag; removing the guard would stack listeners since no removal hook captures the reference. Defensive `console.warn` on second call (dev only) or capture-and-skip would harden it.
- **scripts/import-projects.ts — Serializable abort surface** — Blob uploads (`resolveImageUrls`) and `pruneOrphans` run *outside* the Serializable transaction; tightening isolation raises `P2034` abort probability with no retry/backoff. On abort, freshly uploaded blobs become orphans until a future run's `pruneOrphans`. Admin routes carry an explicit "no retry — single-admin" comment; the script copies the isolation choice without copying the rationale.
- **scripts/import-projects.ts — `prisma!` non-null at call site** — `await writeProject(prisma!, slug, data)` (≈line 420) leans on an earlier dry-run early-return for soundness. Reordering or adding a non-dry-run exit would silently allow null in. Pass via a typed guard or split the dry-run branch.
- **src/app/projects/[slug]/page.tsx — `renderedDescriptions` still `Promise.all`** — The FAQ-render fallback uses `Promise.allSettled`, but section descriptions are still `Promise.all`. One bad section description 500s the whole project page — the same risk the FAQ patch addressed, asymmetrically applied.
- **src/components/projects/ProjectSectionCarousel.tsx — stale aspect ratio on invalid image** — `setAspectRatio` is never reset when `index`/`current.url` changes, so navigating from a valid to an invalid image keeps the previous aspect ratio instead of dropping to the `h-120` fallback the new comment claims. Reset on image change.

## Architecture & Coupling

- **src/lib/content/postJsonLd.ts vs src/lib/content/projectJsonLd.ts — image absolutization** — `absoluteImageUrl` lives in `postJsonLd.ts` as a private helper. Project JSON-LD pipes `resolveOgImage(project)` straight into `jsonLd.image` with no absolutization, so any legacy `/images/...`-relative `ogImage` would emit a relative URL in `SoftwareApplication.image` (invalid for Rich Results). Hoist into `jsonLd.ts` and use from both, or document the Blob-absolute invariant.
- **src/app/llms.txt/route.ts — dual cache layers** — Route sets `Cache-Control: public, s-maxage=3600, stale-while-revalidate=86400` while the underlying `getProjectsGalleryCached()` is tagged `projects`. Tag busts on project mutation don't reach the CDN-cached route response for up to an hour. Drop the route cache or wire `revalidate` so a tag bust surfaces immediately.
- **scripts/import-projects.ts vs src/lib/import/projectImport.ts — bifurcated import core** — `listManifestImagePaths` is in the pure module, but `referencedImageUrls` (same intent, different input shape) and the DB write live in the script. The session widened the gap (Serializable wrap + FAQ create) without extracting. A symmetric `referencedImageUrls(parsedData)` in the pure module would let the test suite catch the drift the dev-journal flagged on 2026-06-28.

## Observability

- **scripts/import-projects.ts — no log on `P2034`** — `processProject`'s `catch` flattens everything via `formatError`. A serialization_failure during a manual import is indistinguishable from a manifest typo. A one-line "txn aborted, rerun the import" branch would save triage time on real batch conflicts.
- **src/app/projects/[slug]/page.tsx — FAQ fallback log payload** — `console.error` gets `{ projectSlug, faqId, reason }`; `reason` is whatever `markdownToReact` threw (likely a `unified` parse error). Bare-object logging means stringification quality depends on the log pipeline. Normalize: `reason instanceof Error ? reason.message : String(reason)` plus stack as a separate field.

## Missing Tests

- **src/lib/content/projectJsonLd.test.ts — `buildOfferNode` non-numeric prices** — No coverage for `price: "free"`, `price: ""`, or any value that yields `NaN` from `Number(...)`. Combined with the sort issue above, malformed offers could silently corrupt `lowPrice`/`highPrice`. Add at least one negative case asserting a defined fallback.
- **src/components/JsonLdScript.test.tsx — `null` vs `undefined` contract** — The test asserts `data={undefined}` renders nothing, but the page-level builders return `null`, never `undefined`. Tighten the prop to `T | null` or pin the `undefined` contract — currently the type and the tested behaviour disagree on which is supported.
- **src/app/robots.test.ts — AI-bot guard** — Asserts the literal rules array but not that bots like `GPTBot`/`ClaudeBot`/`PerplexityBot`/etc. fall through to `*`. A future commit adding a more specific `userAgent: "GPTBot"` block above wouldn't trip a test. Add a guard test that no rule names any of those bots, so adding one becomes a deliberate, test-breaking change.
- **src/components/NavigationTypeTracker.test.tsx — re-mount + Strict-Mode** — Asserts install fires once on mount but no test for re-mounting (idempotent guard) and no Strict-Mode double-invoke check. React 19's dev double-fire means the install path's idempotency contract should be pinned.
- **src/components/projects/ProjectImageLightbox.test.tsx — focus/scroll edge cases** — Tab-trap test omits the `canNavigate: false` case (close button only — trap must wrap to itself). Scroll-lock asserts `auto → hidden → auto` but not per-mount capture (start from `hidden`, assert restore to `hidden` not `""`). Focus-restore doesn't cover `previouslyFocused === null`/`document.body`.
- **src/app/projects/[slug]/page.test.tsx — FAQ fallback assertion strength** — Asserts `consoleError.toHaveBeenCalled()` but not payload shape (`projectSlug`, `faqId`, `reason`). A future refactor that drops or renames the structured fields wouldn't be caught.

## Risk Assessment

**Medium.** The JSON-LD work is the largest landing in this batch and touches user-facing structured data + a security boundary (`safeJsonLdString` is correct; the eslint guard has known residual gaps). The new crawler-discoverability surface (`robots.ts`, `/llms.txt`) ships with two correctness gaps that will quietly mis-publish content (discontinued projects cited as live; CCBot prefix-blocking future `/life*` paths) — visible to external crawlers and AI clients but not to local tests. The Serializable-isolation change in `scripts/import-projects.ts` raises abort probability with no retry path and a silent failure mode that leaks blobs; manual-import operations are now less robust than before. The two most actionable correctness items are `renderedDescriptions` still using `Promise.all` (one bad section description 500s the page — same class of bug the FAQ patch just fixed) and the carousel aspect-ratio state not resetting on image change.
