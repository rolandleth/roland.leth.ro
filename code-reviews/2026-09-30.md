## Observability

- [x] **`src/components/admin/useAdminResource.ts` — `save` and `remove` catch blocks** — neither logs. The main admin write path is the odd one out. Pre-existing; surfaced by the new failed-save tests. **Resolved 2026-10-03**: both catch blocks go through `reportFailure`, which warns under `[admin:<resource>]` and traces a superseded request's failure at debug level.
