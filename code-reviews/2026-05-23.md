## Issues and Observations

- **[src/lib/db/projects.test.ts — `cacheWrapsAtLoad`]** — pins module-load `unstable_cache(...)` registrations only; a regression that wraps `getProjectsForAdmin` lazily (per-call, like the existing `getProjectBySlug` pattern in `src/lib/db/projects.ts`) would not drift the snapshot. The mock is identity-passthrough, so a behavioral fallback (two calls / two Prisma hits) also wouldn't catch it. Coverage is "no module-load wrap", not "never wrapped"; acceptable given the existing pattern is module-load, but worth knowing if a future cache helper hides admin reads behind a per-call wrapper.
- **[src/lib/db/projects.test.ts — `unstable_cache` options cast]** — `(call[2] as { tags?: string[] } | undefined)?.tags` hardcodes Next's `unstable_cache` options shape. If Next's signature ever shifts (e.g. tags move under a nested key), the cast silently yields `undefined` for every row and the snapshot still matches `tags: undefined` across the board. Low likelihood, but a structural test relying on a structural cast deserves a `satisfies`-style guard or an import of Next's actual options type.
