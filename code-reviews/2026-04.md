## Recurring flags

- **Indexing / clamp boundaries on user-facing inputs** — `PlatformPicker` cross-bucket initial values locked rows (fixed 2026-04-15 via `spannedBuckets` guard); `ProjectSortOrderInput` rendered raw 0-indexed DB `sortOrder` in a UI clamped to `[1, totalCount]`, silently swapping the top project on blur (fixed 2026-04-17 via 1-indexed UI translation + Zod `.min(0)` defence-in-depth); `ProjectForm` `sortOrder` input had no bounds (fixed same commit with `min={0}`). Pattern: UI inputs for ordinal data need explicit bounds matched to the storage contract. [source](code-reviews/2026-04-15.md), [source](code-reviews/2026-04-17-review-2.md)
- **Silent cache-serialization traps with `unstable_cache`** — `unstable_cache` JSON-serializes return values; `DateTime` fields come back as strings on cache hits, methods like `.getTime()` explode only after first revalidation. Production 500 on `/api/feed/:section` (fixed 2026-04-20 via ISO normalization inside cached fn). Same review found wrapper-per-call anti-pattern across `legacySlug.ts`, `posts.ts`, `projects.ts`; fixed via module-scope lift (legacy) or `Map<slug, wrapper>` memoization (posts/projects, where per-slug tags are actively revalidated). [source](code-reviews/2026-04-20.md)
- **False-positive string-prefix matching** — `defaultProto` first fix (2026-04-17) was `host.startsWith("localhost")`, which matched `localhostapp.example.com`; fixed 2026-04-19 by splitting on `:` and comparing hostname exactly (`hostname === "localhost" || hostname === "127.0.0.1"`). Same class of bug: port-based dev detection mis-downgrading explicit-port HTTPS hosts like `example.com:8443` (fixed 2026-04-17, commit `5994371`). [source](code-reviews/2026-04-17-review-2.md), [source](code-reviews/2026-04-19.md)
- **Implicit single-writer invariants without DB enforcement** — `Project.sortOrder` has no `@@unique` constraint; `$transaction` assumes dense 0-indexed sequence; concurrent PUTs under READ COMMITTED can produce duplicates with no error (Postgres order-by silently tie-breaks on name). Chose documentation (option D, commit `2c2199e`) over `@@unique` (would need `DEFERRABLE INITIALLY DEFERRED`, not expressible in Prisma DSL) or `SERIALIZABLE` escalation. Escalation triggered when second admin account is added. [source](code-reviews/2026-04-17-review-2.md)
- **UX regressions at routing boundaries** — legacy-redirect API route returned raw JSON 404 for unknown slugs because `notFound()` from an API route doesn't render the styled page. Fixed 2026-04-17 Session 3 by moving lookup into `src/app/[slug]/page.tsx` catch-all; `KNOWN_ROUTES` allowlist (unenforceable drift) dissolved as a class-of-bug. [source](code-reviews/2026-04-17.md)
