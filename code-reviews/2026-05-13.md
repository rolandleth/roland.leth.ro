## Concurrency & Thread Safety

- [x] **[src/app/api/admin/posts/[id]/route.ts — Serializable retry semantics]** — Prisma's `$transaction` does NOT auto-retry on `40001 serialization_failure`. The doc comment notes "essentially impossible at single-admin volumes," but a GET-and-revalidate (cached fetcher) can run concurrently with an admin PUT. A serialization failure surfaces to the admin as an indistinguishable 500. Acknowledged trade per the journal; worth making the doc explicit that the 500 is also not client-retriable (admin must retry manually). **Resolved 2026-05-13**: Phase 2 expanded the doc comment to spell out non-retriable + audit-log idempotency concern; Phase 7 added a test pinning the `P2034 → 500` path with audit-tag NOT emitted.
