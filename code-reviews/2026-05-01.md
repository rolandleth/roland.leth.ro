# Code Review — 2026-05-01

## Issues and Observations

- **src/proxy.test.ts — privacy redirect location assertion** — `toContain("/privacy")` would also pass if the target were `/privacy-policy` (since the source URL contains that string). All other redirect tests follow the same `toContain` pattern, so this is a consistency call rather than a regression risk, but a tighter `toBe` or `toMatch(/\/privacy$/)` would make the assertion non-trivially falsifiable.

Every other redirect in the file has at least one query-string passthrough test. The behavior is correct in the implementation; it's just uncovered.
