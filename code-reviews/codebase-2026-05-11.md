## Risk Assessment

**Medium-Low.** The codebase has improved materially since the prior `--all` sweep on 2026-05-07: most input-validation, observability, and concurrency findings from that review closed cleanly. The current sweep surfaces four themes worth acting on, in priority order:

1. **Draft/future-dated post leakage** — `getPostBySlug`, `sitemap`, and `generateStaticParams` all skip the `published: true` + `datetime <= now` filter; the canonical URL serves drafts to anyone with the slug, and search engines see future content via sitemap. The watch-out has been carried for two cycles; it's the most user-visible correctness gap. Tightening at `getPostBySlug` is one filter clause.
2. **Security tests for the auth surface are still mostly absent** — the per-IP login rate-limit, fail-open, and key-derivation are unverified; the proxy has no 401 contract test for `/api/admin/*` or `/api/upload`. The handlers themselves don't authenticate, so without proxy tests, the load-bearing security gate is unverified end-to-end. Same status as 2026-05-07; the fix is a small batch of route tests.
3. **Two genuinely new findings worth fixing this week** — `cron/ping` returns `{ error: "CRON_SECRET not configured" }` to unauthenticated probes when the env var is unset (move auth above the config check; 3 lines); upload's MIME allowlist trusts client `file.type` so an authed-but-hijacked session can write `text/html` to a public Blob (sniff magic bytes; one library call).
4. **Architecture debt is stable** — admin auth still split across three layers (open thread from 2026-05-07); `posts.ts`/`projects.ts` wrapper-cache template still duplicated; `format.ts` still mixed-concern. None block work but they're now four cycles old. Worth bundling into one architecture-refactor session.

Nothing landed that touches load-bearing plumbing destructively. Contract surface has narrowed since the prior review (parsing got stricter, env validation tightened, `<ErrorMessage>` consolidated 7 callers). The error-boundary tests added 2026-05-09 close a regression-watch gap. The remaining surface is concentrated in (a) the small auth + content-visibility holes above, (b) test coverage for paths whose behavior is documented but unverified.
