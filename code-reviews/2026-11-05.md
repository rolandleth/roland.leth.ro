# Code Review — 2026-11-05

## Issues and Observations

- [ ] **src/lib/import/recentPosts.ts — `parseRecentPostFiles`** — the guard against "a new file reuses an old file's slug" works only because `parsePostFiles` keeps the first file by name (`sortedMarkdownNames` in `scripts/import-posts.ts`) and name order matches datetime order. They diverge on one day: `2026-11-05-Old.md` (00:00) sorts after `2026-11-05-0930-New.md`. If the window cuts between such a pair (for example `--last=1`), the new file parses clean, matches the old post's row and `--overwrite` replaces it — the case the full-folder parse exists to stop. This is a narrow case. To fix it, make the duplicate check prefer the oldest file by datetime, or skip both files of a pair that crosses the window.
- [ ] **scripts/import-posts.ts — `scope` log line** — "importing the newest 10 of N file(s)" undercounts when undated files exist: `recentFilenames` always keeps those as well, so the run acts on 10 + undated files. Count from `kept.size` (return it from `parseRecentPostFiles`) instead of `lastArg.count`.
- [ ] **src/lib/import/recentPosts.ts — `resolveLastArg` problem text** — `valueFlagPlaceholder(LAST_FLAG)` renders `--last=<last>`. The usage comments and CLAUDE.md say `--last=N` / `--last=<n>`. The copy should name a count. Fix the placeholder input or pass an explicit `<n>`.
