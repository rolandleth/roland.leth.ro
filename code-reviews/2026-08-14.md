## Risk Assessment

**Medium.** Two behaviour changes reach broad surfaces: `buildPageMetadata`'s image fallback now touches every page's social metadata, and `buildOfferNode` touches every project's structured data. The metadata contract widened from "emit images only when truthy" to "always emit one", and the `??` swap opens an empty-string path that resolves the site root as a social card — a live regression, reachable through any DB row that skipped Zod validation. `projectJsonLd`'s `.trim()` on an untyped Json column can 500 a project page on a malformed row, in a server component, with no fallback. The `/og` route is the largest new surface and the least verified: no caching contract, no coverage, a WASM dependency bundled to serve a 404, and a `NODE_ENV`-only production gate this project has already seen misbehave locally. The auth work is additive logging and carries no behavioural risk on its own, but coverage landed asymmetrically — two of four call sites got tag assertions and the protected layout got none — and the page-namespace invariant remains prose where the API side is machine-enforced. The ESLint additions are a net gain and disable nothing; the extraction of `restrictedSyntax` is the right shape.
