Pass both values through `sanitizeLogString`; the line stays diagnosable.

## Missing Tests

- **`src/app/api/admin/upload/route.test.ts` — `hasCompatibleAvifBrand` clamp** — no test fails if `Math.min(boxSize, bytes.length)` is removed. "scans up to the header end when the box is longer than the bytes seen" finds `avif` at offset 20 before the scan leaves the buffer, and the route-level offset-64 test also passes without the clamp, because a read past the end gives four NUL characters, never a brand. The clamp does not protect the type; it bounds the loop. A `mif1` box with no AVIF brand and a declared size of `0xFFFFFFFF`, expecting null, pins it (without the clamp the scan runs about 10⁹ iterations and the test times out).
