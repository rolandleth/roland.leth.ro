## Risk Assessment

**Medium.** Auth gating holds: all 21 admin handlers call `requireAdmin` first and a contract test ties the list to the route tree; the cron bearer check is constant-time; there is no XSS path. Static rendering, real 404s and the scheduled-content holdback all hold, and the public routes alone rate Low. The rating comes from integrity and data loss in the content write paths, which are load-bearing: a project rename orphans its guides and blocks their edits; `import-posts` can overwrite an unrelated post and its skip message tells the operator to do it; `import-projects` runs a real import on a mistyped flag; the image-field list that gates permanent blob deletes exists in three copies, one untested; and two admin paths lose edits with no warning (the SectionManager upload race, no unsaved-changes guard). On the public side, one keystroke crashes the loan calculator, stored descriptions and previews can render wrongly, and visitors without JS see blank animated content. It is not High because every data-loss path needs an admin or script action, and the two security findings (CSRF via SameSite=Lax only, upload content type) are PLAUSIBLE, not confirmed.
